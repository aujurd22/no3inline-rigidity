# Signed NAE → Ising / MaxCut 重述：m=37 rot4-NTIL 方向子问题

> 核心主张：固定一个 2-因子后，取向子问题**不是真正的三次 3-SAT**，而是
> 一个 37 顶点的**带符号加权 MaxCut / Ising 基态问题**。互补对称消去所有线性项
> 与三次项。这一化简已对三个配置**数值严格验证**，并立刻改变搜索目标与理论路线。

---

## 1. 化简（数学）

对固定的 2-因子（37 条边 e₀…e₃₆），每条禁用模式是某个三元组
(a,b,c) 的一个具体取向赋值 `bits=(t_a,t_b,t_c)∈{0,1}³`。
由 180° C4 旋转不变性（共线在旋转下保持，且旋转把 `(t_a,t_b,t_c)→(1-t_a,1-t_b,1-t_c)`），
**禁用集对全反模式成闭包**：若 `(a,b,c,bits)` 被禁，则 `(a,b,c,bits⊕111)` 也被禁。

把方向变量写成自旋 `s_i = 2 t_i − 1 ∈ {±1}`。对一个互补对子
`a=(a_i,a_j,a_k)∈{±1}³`（其中 `a_i=2 bits_i−1`），其违例指示函数恰为

```
1_{s=a} + 1_{s=−a}
   = 1/4 ( 1 + a_i a_j s_i s_j + a_i a_k s_i s_k + a_j a_k s_j s_k ).
```

对全部 `P_E = 子句数/2` 个互补对子求和，得到总违例能量

```
V_E(s) = P_E/4 + 1/4 Σ_{i<j} J^E_{ij} s_i s_j ,
```

其中 `J^E_{ij} = Σ_{对子 p ∋ {i,j}} a_i a_j`。**所有一次项与三次项因互补对称而消失**——
这正是它与 3-SAT 的本质区别。

> 实现注记：本仓库 `ising_reduction.py` 的 `build_J` 对**全部子句**（而非对子）累加，
> 故代码里的 `J_code = 2 · J^E`。对应能量公式写为
> `V_E = 子句数/8 + (1/8) Σ_{clauses} (a_i a_j s_i s_j)`，二者等价。

于是固定 2-因子的剩余问题 = 在 37 顶点上求 Ising 基态（等价于带符号图的 MaxCut）：
最小化 `Σ_{i<j} J^E_{ij} s_i s_j`。受挫 = 基态能量 `> −Σ|J^E|`（即不能把所有边通过
顶点切换变为铁磁）。

## 2. 数值验证（严格）

用 `solver_2factor_sat_pipeline.enumerate_clauses` 枚举子句，独立计算
`V_E(s)`（Ising）与暴力枚举违例数（3-SAT），在最优取向与 8 个随机取向下比对。

| 配置 | 子句数 | closure 缺失 | V_E == 暴力 | min 违例 | 已证最优 |
|------|-------|-------------|------------|---------|---------|
| m=37-408（最佳） | 408 | **0** | **True (16=16.0)** | 16 | 否 (FEASIBLE) |
| m=37-448（已证） | 448 | **0** | **True (17=17.0)** | 17 | **是** |
| m=36 解（SAT）   | 670 | **0** | **True (0=0.0)**   | 0  | 是 (SAT) |

- **互补闭包在所有三配置均为 0** → 化简无条件成立，方向子问题确为纯二次 Ising。
- 这把原先"MaxSAT / 三次 3-SAT"的求解框架，整体替换为 **Ising / MaxCut / SDP** 框架。

## 3. m=36 vs m=37 受挫核对比（核心结果）

对每个配置计算：`E_min = 8·min_viol − 子句数`（Ising 基态能量），
`Σ|J| = Σ|J_code|`，`frustration_index = (Σ|J| − E_min)/2`，
以及 Rayleigh 谱下界 `min_viol ≥ 子句数/8 + (n/2)·λ_min(J_mat)/8`。

| 量 | m=37-408 | m=37-448 | m=36 (SAT) |
|----|---------|---------|-----------|
| min 违例 | 16 | 17 | 0 |
| E_min | −280 | −312 | −670 |
| Σ\|J\| | 856 | 932 | 1162 |
| frustration index | 568 | 622 | 916 |
| 谱下界 λ_min(J_mat) | −10.01 | −10.21 | −70.22 |
| **谱下界 on min_viol** | **≥ 4.72** | **≥ 8.80** | **≥ −232.2** |
| **SDP 对偶下界 on min_viol** | **≥ 12.52** | **≥ 15.18** | **= 0.00（紧）** |
| 受挫核（边） | 30 / 37 | 29 / 37 | 0 |

**关键解读：**

1. **可平衡性（balanceability）才是真正不变量，不是 frustration index 的大小。**
   m=36 的 frustration index（916）比 m=37 还大，但它**可平衡**（存在顶点切换使所有边铁磁）
   → 故 0 违例、SAT。m=37 的切换无法消除全部受挫 → 基态仍留 ≥16 违例。
   区分 m=36/m=37 的不是"受挫量"，而是"是否存在使图平衡的切换"。

2. **第一个严格符号证据**：m=37 的谱下界**为正**（≥4.72 / ≥8.80），m=36 为**负**
   （−232）。谱下界是 Rayleigh 商给出的**严格下界**——它证明这两个具体 2-因子
   确实"卡在"正受挫（不能切换到 0），而 m=36 没有这种正障碍。这是 route 2
   （signed-graph switching 不变量）的第一个量化支撑。

3. **受挫核是全局的，不是小局部模板。**
   m=37-408 的 16 违例分布在 **30/37** 条边，m=37-448 的 17 违例分布在 **29/37** 条边；
   两者受挫核交集仍有 **22/37** 条边。这与"小 5–10 边普遍受挫模板"的设想**不符**——
   障碍是**弥散在几乎整个 2-因子上**的。因此"第二方向"应重新定位为：
   **证明任意 37 阶 2-因子都不可平衡（普遍正下界）**，而非寻找可局部修复的小核。

4. **带符号短圈计数不是不变量**：三个配置的受挫三角形数都很大
   （m=37-408: 2604/8658；m=37-448: 3336/10980；m=36: 3192/14574），
   但 m=36 仍可平衡。故"原始几何符号下的受挫圈数"可经切换消除，**不能作为障碍证据**；
   真正的不变量是切换后的最小割（=min_viol）。

## 4. 搜索目标必须改变

原长扫最小化"子句数"，但数据证明这是**错误代理量**：

- m=36 有 **670** 子句却能**完全满足**（0 违例）；
- m=37 只有 **408** 子句仍有**至少 16** 已知违例（448 子句 17 违例已证最优）。

正确目标应是最小化 `V_E(s)`（即基态受挫 / min_viol），或其谱下界、SDP 下界、
frustration index——**而非子句数**。否则会错过"子句较多但符号兼容"的真正解，
也可能在"子句少但符号受挫"的盆地里空转（408/16 正是后者）。

## 5. 三条理论路线具体状态

**路线 1 — 切多面体 / SDP 对偶证书（✅ 已收口：证 408/448 最优）**
- Rayleigh 谱下界（对所有三配置严格可算）：m=37 为正证书（≥4.72 / ≥8.80），m=36 负（≥−232）。
- **GW MAX-CUT SDP 对偶证书（`sdp_frustration_cert.py`）**：
  m=37-408 ⇒ **min_viol ≥ 12.52**；m=37-448 ⇒ **≥ 15.18**；m=36 ⇒ **= 0.00（紧）**。
- **★★ 收口：triangle-SDP（`cutpolytope_sdp.py` / `focused_triangle_sdp.py`，加 cut-polytope
  三角形不等式，CLARABEL）给出更紧的严格下界：**
  - m=37-408：**SDP_min=−280.0218 ⇒ min_viol ≥ 15.9973 [optimal]** ⇒ 整数下界 ≥16，
    且 16 已知可达 ⇒ **408 的 16 违例已证最优**（此前 CP-SAT 仅 FEASIBLE）。
  - m=37-448：**min_viol ≥ 17.0000 [optimal_inaccurate]** ⇒ **448 的 17 精确最优**。
  - m=36：**min_viol ≥ 0.0000** ⇒ 确认 SAT（方向验证：下界≈0，未出现负/错误正值）。
- 公式方向经 m=36 验证无误（见 `ising_optimality_proof_m37.md` §0 与 §3）。
- 含义：这两个具体 2-因子被锁定在 16/17 违例，单靠 2-因子 switch 微调该 basin 无法得 0 解。

**路线 2 — 带符号图规范变换（switching 不变量）**
- 已量化：三个配置的 `J^E`、frustration index、可平衡性；谱下界正负区分 m=36/m=37。
- 下一步：提取最小符号翻转集（=min sign-flip 使图平衡）、受挫圈的几何模板；
  比较 m=36 平衡切换与 m=37 最优切换的结构差异。
  真正要解释的或许不是"36 合数、37 素数"，而是为何前者的符号系统可经 switching
  消除受挫、后者暂时不行（见 §6 更正 4）。

**路线 3 — 联合松弛（终极不可能性证明）**
- 外层变量选 2-因子（2-因子多面体），内层变量是 cut/Ising（cut polytope），联合 LP/SDP。
- 若对所有 2-因子都得到严格正的对偶下界 → 真正的 m=37 不可能性证明；
  若松弛给出零点 → 反过来指示构造方向。尚未实现，是 route 1 的自然推广。

## 6b. 路线 2 决定性负结果：跨**多样** 2-因子无共同受挫模板

§3.3 仅凭 408 与 448（二者共享 31/37 条边，属近邻变异）的受挫核交集 22/37 边，
推断"障碍全局化"。为排除"只是这两个构型巧合相似"，现做**结构不同**的对照实验：

`diverse_template_sweep.py`：对 m=37 生成 **8 个随机 2-因子**（由随机置换的环分解得到，
结构互异），对每个计算其带符号图 G_J 的全部**受挫三角形**（长度-3、负边数为奇），
把每条边映射回几何 `(u,v)` 坐标后求交集。

| 配置 | 受挫三角形数 |
|------|------------|
| 0 | 838 |
| 1 | 521 |
| 2 | 732 |
| 3 | 671 |
| 4 | 673 |
| 5 | 469 |
| 6 | 849 |
| 7 | 822 |

**结果：8 个构型的几何受挫三角形全集交集 = 0；任意两两交集也为 0**（Jaccard=0）。

**结论（强于 §3.3）：** 不存在跨 2-因子的固定几何受挫模板——每个 2-因子有数百个受挫
三角形，但它们是完全不同的集合，没有哪怕一个三角形在所有构型中持续受挫。这**证伪了**
"第二方向"的字面目标（提取一个 5–10 边的普遍受挫模板，再证其不可避免）。

**理论含义：** m=37 的障碍是**全局/弥散的**，由整个带符号图的受挫结构决定，而非锚定在
某个固定几何子结构上。因此：

- 局部修复（删几条边消除受挫核）**不可行**——没有这样的局部核。
- 普遍下界**不能**通过"找固定模板"得到；只能走 **路线 3（联合松弛 / 全局不变量）**：
  证明"任意 37 阶 2-因子，其带符号图都不可平衡（min_viol ≥ 1）"。
- 结合扫掠 16650 构型全卡 ≥16、且无任何共同模板，这构成"m=37 很可能无解"的强经验证据，
  但仍**非证明**。

> 注：408 与 448 的几何受挫三角形交集为 144（Jaccard 0.17），见 `template_intersection.json`；
> 那只是近邻变异的持久结构，不代表普遍模板。
