# C₄ 存在性：概率方法 / LLL 可行性分析

## 1. 模型回顾

n = 2m 的 C₄（rot4）解 ⇔ 顶点集 {0,…,m−1} 上的 **2-因子**（2-正则图）。
每条边 {i,j}（i<j，排除 i=j 的退化 2-轨道）对应一个 4-轨道

```
O(i,j) = {(i,j), (n−1−j,i), (n−1−i,n−1−j), (j,n−1−i)},   n = 2m
```

解合法（无三点共线 ⇔ missing-center / 合法 NTIL）⇔ **任意两个轨道的并都不含共线三点**。

## 2. 坏的事件的计数

对每个 m，枚举全部 N = C(m,2) 个轨道，检查所有轨道对（共 C(N,2) 对）是否冲突
（并集中存在共线三点）。记冲突对比例为 r(m)。

## 3. 幂律拟合

```
r(m) = 0.308 · m^(−1.144)
```

于是随机 2-因子中冲突边数对的期望

```
E[#conflicts] ≈ C(m,2) · r(m)  ≈  0.31 · m^(+0.856)   →  随 m 增大而增长
```

（注：此前某些笔记里提到的"轨道对冲突率 ∝ m^−1.68"指的是"每个轨道的冲突邻居数"，
不是这里用于 LLL 界的两两冲突**概率**；以本文件的严格两两测量为准。）

## 4. 结论：朴素概率方法 / 普通 LLL **失败**

- 一阶矩法：P(存在冲突) ≤ E[#conflicts] ≈ 0.31·m^0.856，**随 m 增大而 >1**，
  无法给出存在性。
- 普通 Lovász 局部引理同样失败：依赖度 d ~ N ~ m²，而 p = r(m) ~ m^−1.14，
  e·p·(d+1) ~ m^(0.86) ≫ 1，条件完全不满足。
- 这与**实证**完全吻合：此前 `c4_universality.py` 随机 2-因子在 m≥5 时 **0/100 命中** ——
  合法 C₄ 2-因子是 2-因子空间中的**稀疏子集**，随手抽样几乎必撞共线。

## 5. 这对"方向1"意味着什么

- **存在性本身是真的**（Flammenkamp 缓存在 n∈[6,72] 连续 29 个偶数全部含 rot4 解），
  但**"随手一个概率论论证就证出来"这条路走不通**。
- 障碍在于冲突具有**结构相关性**：好的 2-因子（真实解）靠特定的圈结构避开冲突，
  而非随机独立地避开。要证"对所有偶数 n 存在 C₄ 解"，必须：
  1. 利用真实解展现的圈结构（单 m-圈对几乎所有 m 成立，除 m=6 特例）；或
  2. 把冲突图的有独立集性做成**构造性**论证（依赖度需按真实冲突图而非全 N 来界）；或
  3. 转去正面攻击 **n=74（m=37）缺口**（设备不足时暂不做大规模搜索）。

> 一句话：**朴素 LLL 证伪，存在性仍需构造性/结构化论证；这与"合法解稀疏"的实证一致，
> 不构成对存在性的反例，只说明证明需要更锋利的工具。**
