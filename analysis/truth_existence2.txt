TRUTH B (refined): the scaling that kills the naive LLL proof
==============================================================================

p_consec(n) = Pr(consecutive rows 0,1,2 contain a collinear triple)
If p_consec ~ c/n, then LLL product e*p*d ~ e*(c/n)*(1.5 n^2) = O(n) -> inf.

        n     p_consec        p*n   interpretation
       50 7.825750e-02      3.913   -> p ~ 3.91/n
      100 3.972250e-02      3.972   -> p ~ 3.97/n
      300 1.337250e-02      4.012   -> p ~ 4.01/n
     1000 4.085000e-03      4.085   -> p ~ 4.08/n
     3000 1.330000e-03      3.990   -> p ~ 3.99/n

If E_bad grows with n (not shrinks), random configs are ALWAYS bad ->
the probabilistic method cannot certify a zero-collinearity config.
