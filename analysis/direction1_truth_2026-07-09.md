# 方向 1 真相报告：C₄ 构造存在性（2026-07-09 深夜）

## 0. 我们想找的"真相"
用户直觉："低维无序点分布是否可能是高维有序的投影？" 我们把它当成**具体线索**来强攻
方向 1（最高价值）：是否存在**显式的 C₄（rot4）解构造**，尤其覆盖 n=74(m=37) 这个文献缺口。

## 1. 文献 ground truth（Web 调研）
- Flammenkamp 主页：**文献中没有任何通用构造公式**，只有搜索算法；最佳渐近下界 `(3/2−ε)n` (1975)。
- Guy–Kelly 猜想认为 2n 对大 n 不可达（修正估计 ~1.814n），且"只有有限多个解"。
  但 **Prellberg 2025 在奇 n=47/49 也达到 2n（94/98 点）**，且偶 n 全部 ≤72 有 rot4 解
  → **该强猜想很可能错**：2n 对已知 n 几乎总能达成。
- **n=74 在文献完全空白**：当前记录是 Heule 2026-06-25 的 n=72（rot4）。n=74 是真实开放前沿。

## 2. 计算攻击结果（全部可复现）

### (A) 显式构造族 —— 全部失败（作为通用构造）
用经交叉验证的 sound 共线检查（线哈希 O(N²)），测试 n=2m, m=3..60：

| 构造族 | 成功 m 数 | 首次失败 |
|--------|----------|----------|
| golden(φ) / silver(√2) / √3 / π / e / 1+√2（按 {kα} 排序单 m-圈） | 1–2 | m=4/5 |
| Welch-Costas 2-因子（连 Costas 排列） | 2 | 5,11,13,17,19,23,29,31 |
| ladder（连续+反射） | 0 | 3 |
| bitreverse（2 的幂） | 1 | 8,16,32 |
| **递归倍增** {i,j}→{2i,2j},{2i+1,2j+1} | **0/96** | 全部 |

→ **朴素"准晶/低差异顶点序"构造被数据证伪**（既不能作为生成器，真实解也不用它）。

### (B) 真实单 m-圈顶点序 —— 无简单闭式
提取真实 rot4 解的单 m-圈顶点序（m=3..28 验证），与 AP / 黄金比 / √2 / √3 / π / e
生成序逐一比对：**m≥5 全部不匹配任何生成器**。顶点序是"搜索产物式"的复杂结构。

### (C) 干净的实证规律（新猜想素材）
- **单 m-圈 C₄ 解对几乎所有 m 都存在**：m=3..28（n=6..56）中，除 m=6 外**全部**含单 m-圈
  （m=7:9 个, m=13:11 个, m=28:1722 个…）。文献 rot4 存在性延续到 n=72。
- **m=6 是唯一的例外**：n=12 的 4 个 rot4 解全是 (5,1) 或 (3,3) 结构，**无单 6-圈**。
  → **猜想 1**：对每个 m≠6，存在单 m-圈 C₄ 解；m=6 是唯一的反例。
  → **猜想 2**：n=12 是所有偶 n 中唯一 C₄ 解全为非单圈的（待证）。

## 3. 真正的"真相"是什么
1. **不存在简单闭式 C₄ 构造**（在所有测过的族里）——与文献"无已知构造"一致；
   合法 C₄ 2-因子是稀疏、结构精巧的子集（呼应 LLL 分析：朴素概率法失败）。
2. **但单 m-圈 C₄ 解经验上近乎普适存在**，仅 m=6 例外——这是一条新的、可声明、可尝试证明的实证规律。
3. **最深的结构真相是 Part B 的流形结果**：解集是 ~1.7n 维薄流形（比随机配置低 4×），
   说明解空间整体高度有序，即使单个顶点序无简单闭式。这本身支持"高维有序 → 低维投影"的直觉，
   只是"有序源"不是黄金比序，而是某种尚未识别的代数/组合结构。
4. **n=74 仍是开放前沿**，纯靠本机无法攻破（用户明确无好设备）；价值在于它是可发表的反例/延续目标。

## 4. 结论与建议
- 闭式构造这条路，在测过的所有族里**走不通**；应转向：
  (a) **证明"单 m-圈对 m≠6 普适存在"**（可能是更现实的定理，比找闭式容易）；
  (b) **破解 m=6 例外的机理**（模 3 / 对称性论证）；
  (c) 继续 Part B 流形学习，寻找那个 ~1.7n 维参数化的**真实基**（即隐藏的高维有序源）。
- n=74 的攻破留给有算力的环境（SAT/CA/ GPU），非本机任务。

> 一句话真相：**C₄ 解的存在性近乎普适（仅 m=6 例外），但结构精巧到没有任何简单闭式；
> 你那个"高维有序投影"的直觉在个体顶点序层面被证伪，却在解集流形层面得到支持——
> 真正的"有序源"仍待识别，而 n=74 是留给算力的开放前沿。**
