# 大素数互斥超饱和定理

日期：2026-07-19

## 1. 定理

设

\[
S\subseteq\{0,\ldots,n-1\}^2,\qquad |S|=2n,
\]

且每一行、每一列恰有两个点。若素数 \(p\ge n\)，把 \(S\) 注入
\(\mathbb F_p^2\)，记 \(T_p(S)\) 为模 \(p\) 共线的三元组数量。

则

\[
\boxed{
T_p(S)\ge
\max\left\{0,\left\lceil
\frac{2n(2n-p-2)}3
\right\rceil\right\}.
}
\tag{1}
\]

若 \(S\) 在整数平面中无三点共线，则不同素数

\[
n\le p<2n-2
\]

所计数的三元组集合两两不交。因此 \(S\) 至少含有

\[
\boxed{
B(n)=
\sum_{\substack{n\le p<2n-2\\p\ {\rm prime}}}
\left\lceil\frac{2n(2n-p-2)}3\right\rceil
}
\tag{2}
\]

个彼此不同的三元组，其非零整数行列式含有一个不小于 \(n\) 的素因子。

由素数定理，

\[
\boxed{
B(n)=\left(\frac13+o(1)\right)\frac{n^3}{\log n}.
}
\tag{3}
\]

这把旧的“对一个特定 \(p=n+1\) 至少有 \(\Theta(n^2)\) 个模三点组”
加强为“跨全部大素数至少有 \(\Theta(n^3/\log n)\) 个不同三点组”。

注：单个 \(p\) 的公式也可由 `DETERMINANT_PRODUCT_BARRIER.md` 中的一般
方向分盒定理取 \(N=2n\) 直接得到；这里的新内容是利用行列饱和给出更短证明、
把它与旧 \(p=n+1\) 结果对齐，并证明整个大素数区间可以无重复地求和。

## 2. 单个素数的证明

\(\mathbb F_p^2\) 有 \(p-1\) 个非横、非竖方向，每个方向含 \(p\) 条线。
令 \(r_\ell=|S\cap\ell|\)，其中 \(\ell\) 遍历这些非轴线。

每个点在每个非轴方向恰落在一条线上，所以

\[
\sum_\ell r_\ell=2n(p-1)=:I.
\tag{4}
\]

全部点对有 \(\binom{2n}{2}\) 个。恰有 \(n\) 个横点对和 \(n\) 个竖点对，
故非轴点对数为

\[
\sum_\ell\binom{r_\ell}{2}
=\binom{2n}{2}-2n
=n(2n-3)=:K.
\tag{5}
\]

对每个非负整数 \(r\)，

\[
\binom r3\ge
\frac{2\binom r2-r}{3},
\tag{6}
\]

因为两边之差恰为

\[
\frac{r(r-2)(r-3)}6\ge0.
\]

于是

\[
\begin{aligned}
T_p(S)
&=\sum_\ell\binom{r_\ell}{3}\\
&\ge\frac{2K-I}{3}\\
&=\frac{2n(2n-p-2)}3.
\end{aligned}
\]

左边为整数，得到 (1)。

这也修正了上一轮较弱的逐线不等式。特别地，当 \(n=p-1\) 时，新下界为

\[
\boxed{
T_p(S)\ge
\left\lceil\frac{2(p-1)(p-4)}3\right\rceil,
}
\]

而不是原来的 \((p-1)(p-5)/2\)。例如 \(p=37\) 的下界由 \(576\)
提高到 \(792\)。

## 3. 不同大素数为什么互斥

三个棋盘点的整数行列式 \(D\) 满足

\[
|D|\le(n-1)^2.
\tag{7}
\]

若同一个非共线三元组同时模两个不同素数 \(p,q\ge n\) 共线，则

\[
pq\mid D.
\]

但

\[
pq\ge n^2>(n-1)^2\ge|D|,
\]

与 \(D\ne0\) 矛盾。因此不同大素数对应的三元组集合严格不交。

还可注意到：这样的模三点组不可能含有同一行的两个点。否则

\[
|D|=|\Delta x\,\Delta y|
\]

是两个绝对值均小于 \(p\) 的非零整数之积，不可能被素数 \(p\) 整除；
同列情形相同。所以所有被 (2) 计数的三元组都使用三个不同的行和三个不同的列。

## 4. 渐近计算

忽略只贡献低阶项的取整和常数 \(-2\)，由素数定理及分部求和，

\[
\begin{aligned}
B(n)
&\sim
\frac{2n}{3}
\sum_{n\le p\le2n}(2n-p)\\
&\sim
\frac{2n}{3}
\int_n^{2n}\frac{2n-t}{\log t}\,dt\\
&\sim
\frac{2n}{3\log n}\cdot\frac{n^2}{2}
=\frac{n^3}{3\log n}.
\end{aligned}
\]

## 6. 理论意义与当前边界

这个定理首次严格实现了“多个模数的代价可以相加”，因为大素数区间内不存在
重复计数。但它还没有产生矛盾：

\[
B(n)=\Theta(n^3/\log n)
\]

仍小于全部 \(\Theta(n^3)\) 个三元组。

下一步若想形成反证，至少需要下列一种加强：

1. 证明每个被大素数标记的三元组还强迫许多相关三元组；
2. 对同一行三元组的八种点选择建立不可同时满足的行列式因子约束；
3. 把大素数标记与小素数的零进位空洞连接起来，而不是再次独立求和；
4. 证明行列饱和结构能容纳的大素数标记三元组上界小于
   \((1/3-o(1))n^3/\log n\)。

单纯把 (2) 代入行列式乘积仍只贡献 \(\Theta(n^3)\) 的对数，不能补上
\(\Theta(n^3\log n)\) 的完整尺度预算。
