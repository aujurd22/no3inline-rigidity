# 为什么“先在 \(\mathbb Z_n^2\) 做一个 \(2n\) 点弧”不能证明全偶数阶

## 1. 看似自然的充分条件

把普通 \(n\times n\) 网格识别为 \(\mathbb Z_n^2\)。如果能找到 \(2n\) 个剩余类，
使任意三点在离散环面上都不共线，那么同一批标准代表元在普通欧氏网格中当然也
无三点共线。

这会把整数几何问题变成模 \(n\) 的代数弧构造，看上去很适合有限域、CRT 和置换
多项式。

## 2. 一个无限子列上的严格否定

Stępień 与 Szymaszkiewicz 研究了 \(\mathbb Z_{2p}^2\) 中的弧，其中 \(p\) 为
奇素数。他们证明

\[
\tau(\mathbb Z_{2p}^2)\le 2p+2.
\]

令普通网格边长 \(n=2p\)。目标点数是

\[
2n=4p,
\]

而环面弧最多只有

\[
2p+2=n+2<2n\qquad(p>1).
\]

因此在无限多个偶数阶 \(n=2p\) 上，目标大小的环面弧根本不存在。任何要求
“所有三元组的行列式模 \(n\) 非零”的统一构造都过强，不可能证明全偶数阶。

对平方自由模数 \(2p\)，同一论文的判据还说明三点在环面共线当且仅当其行列式
模 \(2p\) 为零，所以这里不是定义差异造成的假障碍。

## 3. 这不否定模提升正规形

本项目的 `MODULAR_LIFT_NORMAL_FORM.md` 做的是另一件事：对边长 \(2m\) 的真实
整数解降模 \(m\)，允许同一个模胞元带不同高位标签出现多次。模 \(m\) 共线只是
真实共线的必要条件，标签负责把模冲突拆开。

所以应区分：

- **已否定主线：** 在 \(\mathbb Z_n^2\) 中直接找 \(2n\) 点环面弧；
- **仍然有效：** 在模 \(m=n/2\) 的四正则多重图上选择高位标签，消除真实
  行列式零点。

后者没有要求模冲突消失，因而不受环面上界直接限制。

## 4. 对代数构造的具体裁决

以下构造靶点应停止：

1. 一个模 \(n\) 多项式图或若干图的并，使所有三元行列式模 \(n\) 非零；
2. 通过 CRT 把若干环面弧乘起来，期望在每个偶数 \(n\) 得到 \(2n\) 点；
3. 把普通解的存在归结为同阶方环面达到其平凡上界 \(2n\)。

仍值得研究的是：

1. 模 \(m\) 的四正则基图加四种高位标签；
2. 不同模数只负责筛掉部分斜率，而由整数区间或提升位处理剩余冲突；
3. 长方形环面构造作为局部模块或吸收器，而不是直接充当同阶完整解。

这个边界说明，有限域/环方法若要成功，必须显式利用“模上共线但整数上不共线”
的提升自由度；只做模弧没有足够容量。
