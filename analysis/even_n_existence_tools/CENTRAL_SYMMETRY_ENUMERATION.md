# 中心对称饱和候选的精确枚举

令 \(n=2m\)。本文件不加无三点约束，只计数所有满足：

1. 每行每列恰有两点；
2. 绕棋盘中心旋转 \(180^\circ\) 不变

的点集。结果给出一般饱和空间、\(C_2\) 中心对称空间与 \(C_4\) 四重对称空间
之间的精确熵层级。

## 1. 压缩成 2-正则二部多图

一个旋转轨道恰有一个点在上半棋盘、一个点在下半棋盘，所以配置由上半 \(m\)
行中的 \(2m\) 个点唯一决定。

把左右镜像的两列

\[
\{j,2m-1-j\}
\]

压成一个“列对”顶点。建立二部多图：

- 左侧是 \(m\) 个上半行；
- 右侧是 \(m\) 个镜像列对；
- 每个上半点给一条边；
- 边再带一位，记录它落在列对的左列还是右列。

每个上半行有两个点，所以左度为二。若某列在上半的负载为 \(t_j\)，其下半
负载等于镜像列的上半负载 \(t_{2m-1-j}\)。列饱和恰给

\[
t_j+t_{2m-1-j}=2,
\]

所以每个右侧列对的度也为二。宏观对象因此是一张两侧各 \(m\) 个标号顶点的
2-正则二部多图，重边数至多二。

## 2. 连通分量权重

每个连通分量是一个交替偶圈。

- \(k=1\)：一个左顶点与一个右顶点之间的双边。为了得到两个不同格，边位必须
  一左一右，所以权重为
  \[
  c_1=1.
  \]
- \(k\ge2\)：在给定的 \(k\) 个左标号与 \(k\) 个右标号上，交替 Hamilton
  圈数为
  \[
  \frac{k!(k-1)!}{2}.
  \]
  它有 \(2k\) 条边，每条边的左右列位可独立选择，所以
  \[
  c_k=2^{2k}\frac{k!(k-1)!}{2}.
  \]

## 3. 生成函数与渐近

对两侧标号结构应用指数公式：

\[
\begin{aligned}
\sum_{m\ge0}\frac{C_m}{(m!)^2}z^m
&=\exp\left(
z+\sum_{k\ge2}\frac{c_k}{(k!)^2}z^k
\right)\\
&=\exp\left(
z+\sum_{k\ge2}\frac{4^k}{2k}z^k
\right)\\
&=\frac{e^{-z}}{\sqrt{1-4z}}.
\end{aligned}
\]

在主奇点 \(z=1/4\) 作标准系数提取得

\[
C_m\sim
\frac{e^{-1/4}4^m(m!)^2}{\sqrt{\pi m}}.
\]

代入 \(m=n/2\) 并用 Stirling 公式，

\[
\log C_{n/2}=n\log n-n+O(\log n).
\]

所以中心对称饱和候选的主熵系数是 \(1\)。

## 4. 与另外两个空间比较

本项目已经精确得到：

\[
\begin{array}{c|c|c}
候选空间&渐近数目&\log\text{ 的主项}\\
\hline
一般饱和&
\displaystyle
\frac{e^{-1/2}(n!)^2}{\sqrt{\pi n}}&
2n\log n\\[2mm]
C_2\text{ 中心对称}&
\displaystyle
\frac{e^{-1/4}4^{n/2}((n/2)!)^2}{\sqrt{\pi n/2}}&
n\log n\\[2mm]
C_4\text{ 四重对称}&
\displaystyle
\frac{e^{-1/8}2^{n/2}(n/2)!}{\sqrt{\pi n/2}}&
\tfrac12n\log n
\end{array}
\]

这给出严格的

\[
2:1:\tfrac12
\]

熵系数层级。

## 5. 对“所有偶数阶存在”的含义

随机候选在每个二进方向尺度产生 \(\Theta(n)\) 个三点冲突，跨尺度累计
\(\Theta(n\log n)\)。中心对称没有改变一般位置三元组的密度阶，只把可用熵
从 \(2n\log n\) 压到 \(n\log n\)；\(C_4\) 又压到一半。

因此，对称性是一把双刃剑：

- 它能制造强相关，已知极值解确实大量落在其中；
- 但若没有额外确定性结构，单靠随机计数时，对称类比一般空间更早进入
  “冲突成本超过熵”的区域。

后续若做严格容器或熵压缩证明，应分别以这里三个精确计数作归一化，不能把
\(C_2\) 或 \(C_4\) 当成与一般两置换空间同量级。
