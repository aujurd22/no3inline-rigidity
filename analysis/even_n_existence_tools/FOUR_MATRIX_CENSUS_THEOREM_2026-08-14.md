# C4 轨道四矩阵分解与六类普查恒等式（2026-08-14，PROVED + VERIFIED）

## 0. 摘要

上一轮曾尝试把 `tr(K_t^3)` 简化成 `16·tr(A^3) + 48·tr(A·B^2)` 并失败（数值误差
~1e2..2e3）。本备忘录给出**正确**的四矩阵展开：16 项按循环等价归并为 6 类，
并在 t 均值下得到一条**精确整数恒等式**（census identity），把 C4 对称配置的
共线三元组总数 `C_col` 与六个二次型的零点计数联系起来。由此推出：

**定理（六类刚性）**：对偶数棋盘 `n = 2m` 上任意 C4 对称的 `2n` 点配置，
无三点共线 ⟺ 六个零点计数恰好落在其"对角片下界"上：

```
N1 = 3m^2 - 2m,   N2 = N4 = 0,   N3 = N5 = N6 = m^2
```

其中 `N_i` 是六个三元二次型在 m 个轨道代表上的精确零点数
（取素数 Q > 6(n-1)^2，零点 ≡ 0 mod Q ⟺ 整数零）。

验证：n = 6..20 的 21 个 rot4 解全部精确落在下界上；n = 74 解（m=37）同样
精确满足；随机 C4 非解与满棋盘应力测试精确满足恒等式且超出下界的量恰好等于
`(3/2)·C_col`。全部恒等式误差 ≤ 1e-13。

## 1. 设置

中心化加倍坐标 `X = 2x - (n-1), Y = 2y - (n-1)`（X,Y 均为奇数，
`|X|,|Y| <= n-1`）。`omega(p,q) = det(p,q) = X Y' - Y X'` 在
`rho(X,Y) = (-Y, X)`（90° 旋转）下不变。C4 对称配置的 `2n` 个点构成
`m = n/2` 个四元轨道；选代表 `p_1..p_m`。

`K_t(i,j) = zeta^{t omega(r_i,r_j)}`，`zeta = exp(2πi/Q)`，Q 素数
`> 6(n-1)^2`。块矩阵

```
K_t^j(p,q) = Σ_{h=0..3} i^{-jh} zeta^{t omega(rho^h p, q)}    (j = 0..3)
```

已知（README 4.5，机器精度验证）：`tr(K_t^3) = Σ_j tr((K_t^j)^3)`。

## 2. 四矩阵展开（正确版本）

四个相位族（中心化加倍坐标下精确成立）：

| h | omega(rho^h p, q) | 矩阵 |
|---|---|---|
| 0 | det(p,q) | a(p,q) = zeta^{t det(p,q)} |
| 1 | -⟨p,q⟩ = -(XX'+YY') | c(p,q) = zeta^{-t⟨p,q⟩} |
| 2 | -det(p,q) | ā(p,q) = conj(a(p,q)) |
| 3 | +⟨p,q⟩ | c̄(p,q) = conj(c(p,q)) |

于是 `K_t^j = a + i^{-j} c + i^{-2j} ā + i^{-3j} c̄`（逐项精确验证）。

立方展开（对每个 t 精确）：

```
tr(K_t^3) = 4 · Σ_{h1+h2+h3 ≡ 0 (mod 4)} tr(Φ_{h1} Φ_{h2} Φ_{h3})
```

其中 `Φ_0 = a, Φ_1 = c, Φ_2 = ā, Φ_3 = c̄`。共有 16 项；按循环等价
（迹的轮换不变性）归并为 6 类：

```
tr(K_t^3) = 4·[ tr(a^3)
                + 3·tr(ā c^2)        # 类 (2,1,1)
                + 3·tr(a ā^2)        # 类 (0,2,2)
                + 3·tr(ā c̄^2)        # 类 (2,3,3)
                + 3·tr(a c c̄)        # 类 (0,1,3)
                + 3·tr(a c̄ c) ]      # 类 (0,3,1)
```

上一轮的 `16·tr(A^3) + 48·tr(A B^2)` 错在：混合 h 项（如 `h1≠h2≡h3`）并不
约化为单一 A/B 积，必须保留全部五个混合类。

结构性质（全部机器精度验证）：

- `a` 厄米、`|a(p,q)| = 1`、对角全 1；
- `c` 对称，`c̄ = conj(c)`，`c = cᵀ`；
- 六个迹值中 `tr(a^3), tr(a ā^2), tr(a c c̄), tr(a c̄ c)` 为实数，
  `tr(ā c^2) = conj(tr(ā c̄^2))`（共轭对）；
- `a` 的行列式相位在轨道代表上取值 `zeta^{t·det(p,q)}`，`det` 有界
  `|det| ≤ 2(n-1)^2`，内积 `|⟨p,q⟩| ≤ 2(n-1)^2`。

## 3. 六类普查恒等式（census identity）

对 t 取均值 `(1/Q)Σ_t`，根单位滤波把每个类的迹变成代表三元组的精确零点计数：

```
F1 = det(p,q) + det(q,r) + det(r,p)                    # 类 a^3       (面积)
F2 = ⟨p,q⟩ + ⟨q,r⟩ + det(r,p)                          # 类 ā c^2
F3 = det(p,q) - det(q,r) - det(r,p)                    # 类 a ā^2
F4 = ⟨p,q⟩ + ⟨q,r⟩ - det(r,p)                          # 类 ā c̄^2
F5 = det(p,q) - ⟨q,r⟩ + ⟨r,p⟩                          # 类 a c c̄
F6 = det(p,q) + ⟨q,r⟩ - ⟨r,p⟩                          # 类 a c̄ c
```

令 `N_i = #{(p,q,r) ∈ O^3 : F_i(p,q,r) ≡ 0 mod Q}`，则

```
4·( N1 + 3·(N2 + N3 + N4 + N5 + N6) ) = 6·C_col + 12 n^2 - 4 n
```

（对任意 C4 不变点集成立；若点数为 N = 4M 则右端为 `6·C_col + 3N^2 - 2N`。）
证明：逐 t 的 16 项展开 → j 求和筛选 `h1+h2+h3 ≡ 0` → t 均值根滤波。
每个类内部三个循环排列的计数相同，故权重 3。

## 4. 对角下界与刚性定理

六个零点计数有**配置无关的通用下界**（由退化的 p=q 切片恒为零给出）：

```
N1 ≥ 3m^2 - 2m    (p=q, q=r, r=p 三个切片, 排除重叠)
N3 ≥ m^2          (p=q 切片: F3(p,p,r) = 0)
N5 ≥ m^2          (p=q 切片)
N6 ≥ m^2          (p=q 切片)
N2 ≥ 0, N4 ≥ 0
```

代入 census identity 得**精确公式**：

```
6·C_col = 4·[ (N1 - 3m^2 + 2m) + 3·(N2 + (N3 - m^2) + N4 + (N5 - m^2) + (N6 - m^2)) ]
```

方括号内各项均非负，因此：

**定理（刚性）**：C4 对称配置无三点共线 ⟺ 六个计数全部等于其对角下界。

（⟸ 方向由恒等式直接给出 `6C_col = 0`；⟹ 方向因所有超出项非负且总和为零。）

验证数据：

- n=6..20 共 21 个 rot4 解：全部精确 `(3m²-2m, 0, m², 0, m², m²)`；
- n=74（m=37）：`(4033, 0, 1369, 0, 1369, 1369)` ✓；
- 随机 C4 非解（n=8, C_col=12）：`(40, 0, 16, 0, 22, 16)`，超出仅出现在
  N5（+6），且 `(3/2)·C_col = 18 = 3·6` ✓；
- 满棋盘应力测试（n=8, 全部 16 个轨道, C_col=1544）：恒等式精确成立，
  超出总量 2316 = (3/2)·1544 ✓。

## 5. 几何解释：六类 = 旋转轮廓共线

把点 `ρ^h p` 的"旋转轮廓"记为 h。六个类恰好对应六种旋转轮廓的三点共线
（代表 p,q,r 不同时）：

| 类 | 条件 F_i = 0 等价于 | 轮廓 |
|---|---|---|
| F1 | p,q,r 共线 | (0,0,0) |
| F3 | p,q,ρ²r 共线（反演对） | (0,0,2) |
| F4 | p,ρ²q,ρ³r 共线 | (0,2,3) |
| F5 | p,q,ρ³r 共线 | (0,0,3) |
| F6 | p,q,ρr 共线 | (0,0,1) |
| F2 | ⟨q,p+r⟩ = -⟨r,ρ³p⟩（垂直于 p+r 的直线条件） | — |

其中 F2 不直接是单点三共线，而是"q 落在线 `{q : ⟨q,p+r⟩ = -⟨r,ρ³p⟩}`"型
条件（垂直于 p+r 的直线）；F4 也可写成 `⟨q,p+r⟩ = ⟨r,ρ³p⟩`。
这意味着"无三点共线"被拆成六个显式二次型回避条件——每一条都是可精确检验的
整数条件。

## 6. 奇偶恒等式与解的"4-紧"观测（PROVED + VERIFIED DATA）

**引理（奇偶）**：中心化加倍坐标下 X,Y 均为奇数，则对任意奇奇三元组
(p,q,r)，六个类的取值恒 ≡ 0 (mod 4)：

```
F1 = det+det+det ≡ 0；F2 = ⟨⟩+⟨⟩+det ≡ 0；F3 ≡ 0；F4 ≡ 0；F5 ≡ 0；F6 ≡ 0
```

证明分两层：

```
- F1 = det(q−p, r−p)，而 q−p, r−p 为偶向量，偶向量行列式 ≡ 0 (mod 4)；
- F3 = F1 − 2·det(q−p, r)，det(偶, 奇) 为偶数，故 2·det ≡ 0 (mod 4)；
- F2, F4, F5, F6 的模 4 值只依赖六个坐标的 mod-4 残差（∈ {1,3}⁶，共 64 种
  模式）：在 n=12 全奇网格上穷举全部 36³ = 2985984 个有序三元组（覆盖全部
  64 种残差模式），六个类的取值无一例外 ≡ 0 (mod 4)。此为有限但完全的证明。
```

（注意：单个对形式的 ⟨p,q⟩ 与 det(p,q) 各自只保证为偶数，即 ≡ 0 或 2
(mod 4)，两个分量的残差是关联的；三个对形式的特定线性组合才恒 ≡ 0。）

即**六个类的非零最小绝对值自动 ≥ 4**（对所有 C4 配置成立，与是否解无关）。

对 n=14,20,58,74 的解，六个类的 `min|F_i|`（非零最小值）**恰好都等于 4**：
解在每一类中都达到奇偶下界，即"4-紧"。这不是平凡事实（配置完全可以取
min ≥ 8），且与 m=38 E=5 种子半径 ≤ 8 无解的孤立性一致：单格交换把二次型
值改变 4 的倍数，解的"贴地"位置使任何小扰动立即触发零点。

注意：代表的选择（每个轨道取哪一点）不唯一；六计数与六形式依赖该选择，
但 census identity 与刚性定理对任意一致的选择成立。上表数据用轨道首点
（解文件顺序首现点）作为代表。

**m=38 E=5 近邻种子的普查诊断（VERIFIED DATA）**：该候选
（`direct_truth_lift_m38_best.json`，n=76）六计数为

```
N1..N6 = (4256, 1, 1446, 1, 1446, 1448)，下界 (4256, 0, 1444, 0, 1444, 1444)
超出 = (0, 1, 2, 1, 2, 4)，加权和 30 = (3/2)·C_col = (3/2)·20 ✓
```

关键：**N1 恰好在下界**——20 个坏三元组没有一个是"代表-代表-代表"共线，
全部来自旋转轮廓类（F6 最多 +4）。即 E=5 种子在"纯共线"意义上已经干净，
障碍全在混合类。这与"能量下降式 cell 局部搜索反复失败"的现象一致：
修复动作必须同时消除 10 个加权代表级违规（分布在五个类），单点交换无法
做到。

## 7. 对后续理论的意义

1. **精确证书**：检验 C4 候选只需数六个二次型的零点（O(m³) 整数运算），
   不依赖浮点或大 Q 下的模运算解释（Q > 6(n-1)^2 保证 ≡0 ⟺ =0）。
2. **困难分解**：C_col 被分解为六项非负超出之和。随机 C4 配置的超额集中
   在少数类（示例中全在 N5），说明"哪一类先被违反"可作为搜索的诊断量。
3. **构造路线**：证明偶数 n 存在 2n 点 ⟺ 构造 m 个代表使六类计数落在下界。
   每类都是显式二次型回避条件；同一壳层上 F1,F3,F5,F6 自动成立（圆上三点
   不共线），只剩 F2/F4 类弦条件，但单壳层容量不足以容纳 m 个代表
   （需多壳层），故完整构造仍需处理跨壳层共线。
4. **不构成新上界**：恒等式是精确簿记，本身不给出 D(n) 的新上界；其价值在
   于把问题重述为六个独立可检验的二次型回避条件。
5. **奇偶下界**：六形式恒 ≡ 0 (mod 4)（引理 6），非零值自动 ≥ 4；解在每类
   都达到 min = 4（"4-紧"），该紧性是可检验的额外约束。

## 9. 理论现状评估与下一步方向（2026-08-14）

### 9.1 当前精确图景

六类普查把 C4-NTIL 等价于"六个二次型零点计数全部落在通用对角下界"。已知解
（n≤74）全部 4-紧地坐在下界上；近邻种子（m=38, E=5）N1 已在下界，缺陷全在
旋转类。困难被精确定位：

- **N1（代表共线）容易**：模 p 抛物线族 (x, x² mod p)（x=0..m-1, p≥m+1 素数）
  对所有测试 n（10..40）都满足 N1 = 3m²-2m——代表间无整数共线；
- **N2..N6（旋转轮廓共线/垂线条件）是真正的障碍**：抛物线族在这些类有
  Θ(n) 量级超额（n=40 时加权超额 234）；
- 但模 p 抛物线与真解的代表集合对称差 ~ n-4（n=10..20），即真解不是
  "抛物线型"。

### 9.2 值得推进的方向（按作者判断排序）

**A. 单轨道扩展的线回避重述（与 README Priority E 对接）**。刚性定理给出
"n → n+2"扩展的精确条件：向干净的 m 代表集插入一个新轨道代表 p*，新缺陷
当且仅当 p* 落在六个族 L_i(p,q) 之一（对旧对 (p,q)），或 p* 与旧点构成新的
类零三元组。随机选择 p* 的期望加权缺陷 ~ 24m²/n = 6n（n=76 时 ~456），而
真实 m=37 解的"线回避"使插入缺陷仅 10（加权）——即解的线族几乎避开全部
剩余轨道。把扩展问题形式化为"六线族回避插入 + 局部重排"：
1. 对每个旧代表对 (p,q) 显式列出六条 L_i(p,q)（每条由 ρ^h p 或 ρ^h q 与
   方向 p±q / p+q 决定）；
2. 一个轨道代表 p* 合法当且仅当它不落在任何 L_i 上、且不与任何旧对构成
   新零三元组；
3. 允许删除/重排 k 个旧代表吸收 p* 的冲突（k 越小越好；E=5 表明单点插入
   需 ≥ 5 缺陷）。
这给出一个可精确计算的"吸收器距离"：插入缺陷数 = 加权违规数（六个类分别
计）。若对每个 m 都能找到"吸收集"（k = O(1) 或 o(m) 的旧代表重排），
就得到归纳证明——这正是 README Priority E 的 census 精确化。

**B. 强制零点/下界定理（若成立则直接证否 n=76）**。六个形式恒 ≡ 0 (mod 4)
（奇偶引理），且解在每类达到 min|F| = 4。问题：是否存在 m 的函数
f(m)，使任意 m 代表集必有某类超额 ≥ f(m) > 0？已知 f(37) = 0（n=74 解）。
若 m=38 存在 f(38) > 0，则 n=76 无 C4 解——百年问题的直接进展。技术路线：
组合零点定理（Combinatorial Nullstellensatz）作用于六形式的零点多项式、
或代数几何（六张超曲面在 (Z²)^m 上的整数点）、或壳层/奇偶计数。风险高，
但这是唯一可能直接产出"证明或证否"的路线。

**C. 特征和上界**。N_i 是有限盒上二次型的零点计数；对结构族（如全部代表在
少数壳层、或模 p 曲线族），用 Gauss 和/Weil 型界控制 |N_i − 期望|。若某族
的期望与下界之差被界控制在 < 1，则该族必达到下界——构造型证明。抛物线族
的 N2..N6 超额 Θ(n) 说明"期望−下界"~ n，需要大幅改进族的选择（如组合
多个曲线或壳层）才可能压到 < 1。

**D. 普查引导的求解目标（算法方向，非证明）**。加权超额
E = ΔN1 + 3(ΔN2+ΔN3+ΔN4+ΔN5+ΔN6) 是 O(m³) 整数可算的精确目标，且
E = (3/2)C_col。相比直接数坏线，六类分解给出"缺陷在哪个类"的诊断；
E=5 种子显示缺陷偏向 F6/F3/F5。搜索可逐类压 E（先 N1，再 N6...），
每类都是"禁止超边"的命中集问题。

### 9.3 不建议的方向

- 继续盲目扩大随机/爬山搜索（解是 4-紧孤岛，单点移动必坏）；
- 把 E=9 或 E=5 数据当作解的"近似"（N1 干净但旋转类缺陷不可忽略）；
- 在无新约束的情况下继续推导更高阶谱矩（矩走廊已实测无分离）。
