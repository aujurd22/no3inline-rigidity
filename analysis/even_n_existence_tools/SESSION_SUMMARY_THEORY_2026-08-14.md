# 理论推进会话总结（2026-08-14 第二轮）

## 目标

用户要求回顾之前的推荐研究方向，找出未研究透的理论继续推进，过程中可换向。

## 方向评估（本轮结论）

1. **Priority E（n→n+2 局部吸收）——关闭**：跨层最小轨道编辑距离随 n
   线性增长（~n/2）；嵌入核心的吸收容量 ≤ 6（常数）；"每插入 +1 缺陷
   轨道"的墙定律使局部修复不可能。与 README 既有结论一致并量化。
2. **Priority C（k=2 相关估计）——指出真正的缺口**：相关只改变方差，
   不改变共线三元组期望（~2n ln n 调和发散）。k≥3 证明的删除预算在 k=2
   发散是结构性的；需要的是"条件测度本身压低轻线尾"（如带排斥的构造
   测度），而非对已知测度的相关估计。C4 对称也不改变均值（随机 rot4
   仍 ~n ln n）。这是该方向尚未被清晰指出的内在困难。
3. **Priority F（CRT 调色板 slack）——等价化**：调色板冲突计数 ≡ 插入
   对线冲突计数；本轮的"每自由格点 dE ≥ 12"（精确验证）即嵌入核心在
   76 棋盘上的调色板无 slack 的量化表述。
4. **四矩阵备忘录 §9B（强制零点/下界）**：E=24 墙现在有精确有限基础。

## 新结果

### 1. 精确有限定理（EXACT FINITE，全量扫描）

嵌入 n=74 rot4 解（+1 平移）到 76 棋盘（74 个半转代表，E=0）后：

- 全部 2814 个自由格点的单插入：dE ≥ 12（ΔC_col ≥ 4），最小值在
  (0,34)，无干净插入；
- 全部 3,957,891 个格点对的顺序插入：min E = 24（C_col = 8），唯一在
  (0,34)+(41,0)；
- 插入增量公式（含双重出现修正）经暴力逐项验证。

### 2. E=2 低缺陷状态（VERIFIED DATA，注意非法 2-per-line）

(0,34)+(41,0) 插入给出 C4 对称的 m=38 候选：8 条坏线 = **2 个 C4 缺陷
轨道（E=2），低于 E=5 种子（5 轨道，20 坏三元组），但它不是合法
2-per-line 配置（行/列 34、41 各 3 点，行/列 0、75 各 1 点），故不构成
对合法 E=5 纪录的改进。其六类 C4
census：N1..N6 = (4256, 0, 1446, 0, 1444, 1446)，超出仅 N3(+2) 与
N6(+2)（反演类与旋转类）。文件：`n76_e2_candidate.json`。

墙结构（n=76）：行/列 34、41 各 3 点（反演对），新边界行/列 0、75 各
1 点；8 条坏线 = 2 条水平 + 2 条垂直 + 两对斜率 ±3/7（互为反演）。
所有搜索（SA、最优改进、ILS、修复、随机替换、C4 单格移动、平衡空间
搜索、随机起点）均收敛到 E=24 或更差。

### 3. 平衡重构（结构定理）

NTIL 半转配置 ⟺ 每个下半行恰好 2 个代表 + 列对平衡
#{x} + #{75−x} = 2（由每行每列 2 点推出）。E=24 墙违反行平衡（行 34
有 3 代表），故非真近解；平衡空间已知最小 E=60。证明任意配置 E ≥ 24
仍开放，平衡框架是更干净的攻击面。

### 4. 板面裕量景观（VERIFIED DATA）

嵌入核心在更大棋盘 N 上逐点插入：紧棋盘（N=76..86）每插入 +12 不可
修复；N≥96 首次插入可修复回 E=0（吸收容量随裕量增长，N=112 时前 3-4
次可吸收）；但增长在 m≈80 处饱和，无法到达 m=N。E=24 作为"饱和地板"
在多个 N 出现但结构随 N 变化。

### 5. 墙定律（VERIFIED DATA）

最优插入的缺陷可加：每个插入细胞恰好新增 1 个 C4 缺陷轨道
（4 条坏线，C_col+4，dE+12）；75 代表配置可达 E=1 轨道，76 代表最小
E=2 轨道。这是 n=76 半转/C4 搜索困境的最简洁表述。

## 后续最有希望的方向

1. **证明 min-E(n=76, HT) = 24（对任意配置）**：平衡重构 + 墙结构
   （行/列共振 + 反演配对）给出证明骨架；难点在排除"非核心派生的
   配置"。
2. **Priority C 的构造测度**：寻找使轻线尾从调和变为可和的条件测度
   （带排斥的 Gibbs 或壳层加权）——这是 k=2 瓶颈的真正出路，但需要
   全新的测度构造。
