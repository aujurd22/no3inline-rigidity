# 行列各二点候选的精确枚举：一般类与 \(C_4\) 类

## 1. 一般饱和候选

任意大小为 \(2n\)、每行每列恰有两点的棋盘子集，等价于一个左右各 \(n\) 个
标号顶点的二部二正则简单图。每个连通分量都是一个交替偶圈，设它含 \(k\) 个
行顶点和 \(k\) 个列顶点，其中 \(k\ge2\)。

在固定的两组 \(k\) 个标号顶点上，交替 Hamilton 圈数为

\[
c_k=\frac{k!\,k!}{2k}.
\]

所以该连通分量在双变量指数生成函数中的权重为

\[
\frac{c_k}{k!\,k!}x^ky^k=\frac{(xy)^k}{2k}.
\]

标号集合公式给出

\[
\begin{aligned}
\sum_{n\ge0}\frac{B_n}{(n!)^2}x^ny^n
&=\exp\left(\sum_{k\ge2}\frac{(xy)^k}{2k}\right)\\
&=\frac{e^{-xy/2}}{\sqrt{1-xy}},
\end{aligned}
\]

其中 \(B_n\) 是 \(n\times n\) 棋盘上行列各二点的子集总数。因此

\[
\boxed{
B_n=(n!)^2[z^n]\frac{e^{-z/2}}{\sqrt{1-z}}.
}
\]

主奇点分析得到

\[
\boxed{
B_n\sim e^{-1/2}\frac{(n!)^2}{\sqrt{\pi n}}.
}
\]

特别地，

\[
\log B_n=2n\log n-2n+O(\log n).
\]

这把一般两置换启发式中的候选熵从“约 \((n!)^2\)”升级为精确一阶渐近。

## 2. 单 Hamilton 二因子的比例

一个覆盖全部 \(2n\) 个二部顶点的单交替圈有

\[
H_n=\frac{(n!)^2}{2n}
\]

种。因此

\[
\boxed{
\frac{H_n}{B_n}
\sim\frac{e^{1/2}\sqrt\pi}{2\sqrt n}.
}
\]

所以把一般饱和搜索限制为单 Hamilton 二因子，只损失一个
\(\Theta(n^{-1/2})\) 的多项式比例，不改变 \(2n\log n\) 的首项熵。

## 3. \(C_4\) 基本域候选

令 \(n=2m\)。`C4_ENTROPY_ENERGY_HEURISTIC.md` 中的独立分量枚举给出

\[
\boxed{
C_m=m![z^m]\frac{e^{-z^2/2}}{\sqrt{1-2z}}
\sim e^{-1/8}\frac{2^m m!}{\sqrt{\pi m}}.
}
\]

所以

\[
\log C_m
=m\log m+O(m)
=\frac n2\log n+O(n).
\]

单 Hamilton 基图比例同样为 \(\Theta(m^{-1/2})\)。

## 4. 四倍熵差

使用同一个 \(n\times n\) 原棋盘比较：

\[
\begin{array}{c|c}
\text{候选类}&\log\text{候选数的 }n\log n\text{ 首项}\\
\hline
\text{一般行列饱和二因子}&2n\log n\\
\text{\(C_4\) 饱和基本域}&\frac12n\log n
\end{array}
\]

故 \(C_4\) 对称把首项熵压缩为一般类的四分之一。另一方面，随机 \(C_4\)
置换轨道的坏三点期望仍有与一般两置换相同的

\[
\frac{24}{\pi^2}n\log n
\]

首项。这是 \(C_4\) 渐近上远比一般问题脆弱的精确计数原因。

## 5. 对算法与理论的意义

1. “单圈”在一般类和 \(C_4\) 类中都不是指数稀有事件；已知解频繁呈 Hamilton
   结构不能单独解释其几何特殊性。
2. 若要做容器计数，可直接以这里的 \(B_n,C_m\) 作为无冲突前的精确基准，
   不必用重复计数的有序置换对。
3. 一般空间仍有 \(2n\log n\) 熵，与修正 Guy--Kelly 冲突常数
   \(24/\pi^2\approx2.4317\) 只差约 \(0.4317n\log n\)；\(C_4\) 空间则差约
   \(1.9317n\log n\)。
4. 若未来能证明零冲突概率的正确 \(e^{-\Theta(n\log n)}\) 上界，以上公式会把
   概率估计立即转换成解数量或受限不存在定理。
