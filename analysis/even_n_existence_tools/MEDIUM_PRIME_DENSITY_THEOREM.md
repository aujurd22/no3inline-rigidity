# 中大素因子三元组的正密度定理

日期：2026-07-19

## 1. 定理

设 \(S\) 是 \(n\times n\) 整点棋盘中的 \(2n\) 点 NTIL 集。对三元组
\(T\in\binom S3\)，记非零整数行列式为 \(D(T)\)。

固定 \(0<\alpha<1\)，定义

\[
\mathcal U_\alpha(S)=
\left\{
T:\text{存在素数 }p\ge n^\alpha\text{ 使 }p\mid D(T)
\right\}.
\]

则

\[
\boxed{
|\mathcal U_\alpha(S)|
\ge
\left(\frac{1-\alpha}{2}+o(1)\right)
\binom{2n}{3}.
}
\tag{1}
\]

特别地，取 \(\alpha=1/2\)：

\[
\boxed{
\#\{T:D(T)\text{ 含有素因子 }p\ge\sqrt n\}
\ge
\left(\frac14+o(1)\right)\binom{2n}{3}.
}
\tag{2}
\]

也就是说，任意假想的 \(2n\) 点极值解中，至少渐近四分之一的全部三元组都
必须具有不小于 \(\sqrt n\) 的素因子。这不是对模三点组的带重计数，而是
不同三元组的真正密度下界。

该定理只使用“棋盘中有 \(2n\) 个点且所有行列式非零”，甚至不需要预先使用
行列饱和。

## 2. 两个输入

令 \(N=2n\)。对素数 \(p\)，记

\[
T_p(S)=\#\{T:p\mid D(T)\}.
\]

`DETERMINANT_PRODUCT_BARRIER.md` 中的方向分盒定理给出

\[
T_p(S)\ge\frac N3F_p(N-1),
\tag{3}
\]

其中若

\[
M=q(p+1)+r,\qquad0\le r<p+1,
\]

则

\[
F_p(M)=(p+1)\binom q2+qr.
\]

在 \(p\le n\) 的主范围内，

\[
T_p(S)
\ge
\frac{N^3}{6p}-O(N^2+Np).
\tag{4}
\]

第二个输入是棋盘行列式界

\[
1\le|D(T)|\le(n-1)^2.
\tag{5}
\]

## 3. 对数权重消除重复计数

对每个三元组 \(T\)，有

\[
\sum_{\substack{p\ge n^\alpha\\p\mid D(T)}}
\frac{\log p}{2\log n}
\le
\frac{\log|D(T)|}{2\log n}
<1.
\tag{6}
\]

若 \(T\notin\mathcal U_\alpha\)，左边为零；若 \(T\in\mathcal U_\alpha\)，
左边仍不超过一。因此逐三元组求和得到无重复的 union 下界

\[
|\mathcal U_\alpha(S)|
\ge
\frac1{2\log n}
\sum_{p\ge n^\alpha}T_p(S)\log p.
\tag{7}
\]

只保留 \(n^\alpha\le p\le n\)，把 (4) 代入，并使用

\[
\sum_{n^\alpha\le p\le n}\frac{\log p}{p}
=(1-\alpha)\log n+o(\log n),
\tag{8}
\]

得到

\[
\begin{aligned}
|\mathcal U_\alpha(S)|
&\ge
\frac1{2\log n}
\left(
\frac{N^3}{6}(1-\alpha)\log n+o(N^3\log n)
\right)\\
&=
\frac{1-\alpha}{12}N^3+o(N^3)\\
&=
\left(\frac{1-\alpha}{2}+o(1)\right)\binom N3.
\end{aligned}
\]

这证明 (1)。

## 4. 为什么比“最多三个素因子”更强

当 \(p\ge\sqrt n\) 时，一个非零 \(D\) 至多含三个不同的这类素因子，因为
四个的乘积至少为 \(n^2>(n-1)^2\)。直接把全部 \(T_p\) 相加再除以三，只能
给出渐近比例

\[
\frac{\log2}{3}\approx0.231049.
\]

对数权重利用了“较大的素数消耗更多行列式大小预算”，把常数提高到

\[
\frac14.
\]

更一般地，阈值 \(n^\alpha\) 的粗等权重只能得到分段常数；对数权重统一给出
\((1-\alpha)/2\)。

## 5. 有限阶精确版本

对固定 \(n\)，使用严格上界 \((n-1)^2\)，可取权重

\[
w_p=\frac{\log p}{2\log(n-1)}.
\]

把 (3) 的取整下界代入 (7)，得到完全显式的有限阶整数下界。
`analyze_medium_prime_coverage.py` 同时计算该下界和已知解的真实覆盖率：

\[
\begin{array}{c|c|c|c}
n&
\text{有限对数权重下界}&
\text{已知解真实比例}&
\text{真实 union 大小}\\
\hline
12&0.1388&0.5830&1180\\
24&0.1846&0.8187&14160\\

有限下界向 \(1/4\) 收敛较慢；实际极值解则已有约 \(80\%\) 到 \(85\%\)
的三元组行列式含 \(\ge\sqrt n\) 的素因子。\(n=72\) 中实际最大重复数为三，
与理论上界一致。

## 6. 意义与下一步

旧行列式乘积法只说明素因子总对数很多；(1) 进一步说明这些算术复杂度不能
集中到少量三元组上，而必须铺满正比例的三元组。

它仍不直接产生矛盾，因为普通棋盘三角形本来就常含较大素因子。真正可能形成
突破的加强是：

1. 对固定三行的八个行列式建立同时含大素因子的上界；
2. 证明低复杂度代数构造族无法让四分之一三元组满足 (1)；
3. 把“大素因子正密度”与小素数的零进位空洞联系成同一组相关约束；
4. 研究大素因子标记三元组在共享点、共享行三元组上的扩张性，而不只计总数。

目前最具体的新反向目标是：

> 对任意两置换之并，若所有普通三点线均被消除，则证明
> \(\mathcal U_{1/2}\) 必须集中在少数行三元组；再与 (2) 的正密度下界矛盾。

“必须集中”这一半尚未证明，但 (2) 给出了它需要击败的明确常数 \(1/4\)。
