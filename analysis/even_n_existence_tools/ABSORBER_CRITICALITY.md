# \(k=2\) 吸收器的点中心临界律

## 1. 问题

现代 \(k\ge3\) 的 no-\((k+1)\)-in-line 精确构造通常分两步：

1. 先做一个接近饱和的伪随机配置；
2. 再用局部 absorber 补齐缺失的行列。

若把同样思路直接移到 no-three-in-line，加入一个新点 \(q\) 之前必须保证：

> 通过 \(q\) 的每条直线上，当前点集至多已有一个点。

也就是 \(q\) 不能落在当前点集任何一条割线上。下面的计算说明，在目标密度
\(p=c/n\) 下，这种“零割线 absorber”不是常数密度资源，而是随 \(n\) 多项式
变稀；这正好只发生在 \(k=2\)。

## 2. 随机模型

在 \(n\times n\) 网格中独立地以概率

\[
p=\frac cn
\]

选取每个点。固定一个离边界距离 \(\Theta(n)\) 的候选点 \(q\)。

所有经过 \(q\) 的网格直线在去掉 \(q\) 后两两不交，因此各条线上已选点数是
相互独立的随机变量。

用本原无向方向 \(d=(a,b)\) 参数化这些直线，并令

\[
r=\max(|a|,|b|).
\]

当 \(q\) 位于中央区域时：

- 壳层 \(r\) 上有 \(\Theta(r)\) 个本原方向；
- 每条对应直线除 \(q\) 外含
  \(\ell_d=\Theta(n/r)\) 个网格点；
- 该线的期望已选点数为
  \[
  \lambda_d=p\ell_d=\Theta(c/r).
  \]

## 3. no-three 的对数障碍

令 \(E_d\) 表示方向 \(d\) 的直线上至少已有两个点。对充分大的 \(r\)，
\(\lambda_d\) 有界且很小，二项分布给出

\[
\Pr(E_d)=\Theta(\lambda_d^2)
=\Theta\!\left(\frac{c^2}{r^2}\right).
\]

因此通过 \(q\) 的已占割线数期望为

\[
\sum_{r=1}^{\Theta(n)}
\Theta(r)\,
\Theta\!\left(\frac{c^2}{r^2}\right)
=\Theta(c^2\log n).
\]

由于不同过 \(q\) 直线使用互不相交的网格点，事件 \(E_d\) 独立，所以

\[
\Pr(q\text{ 不在任何已占割线上})
=\prod_d(1-\Pr(E_d))
=\exp(-\Theta(c^2\log n))
=n^{-\Theta(c^2)}.
\]

换句话说，在接近目标大小 \(2n\)、即 \(c\approx2\) 时，一个普通随机点成为
零割线 absorber 的概率会按 \(n\) 的某个负幂下降，而不是保持正常数。

## 4. 为什么 \(k\ge3\) 不同

对 no-\((k+1)\)-in-line，加入 \(q\) 只需避免某条过 \(q\) 的直线上已经有
\(k\) 个点。对应坏事件概率为

\[
\Theta(\lambda_d^k)
=\Theta\!\left(\frac{c^k}{r^k}\right).
\]

壳层总贡献为

\[
\sum_r\Theta(r)\Theta\!\left(\frac{c^k}{r^k}\right)
=\Theta(c^k)\sum_r\frac1{r^{k-1}}.
\]

- \(k=2\)：调和级数，得到 \(\Theta(\log n)\)；
- \(k\ge3\)：级数收敛，总危险保持 \(O(1)\)。

所以 \(k\ge3\) 中“每个待补点有正比例 absorber”的机制，在 \(k=2\) 会在每个
方向尺度损失一部分，累计成对数或多项式稀疏。这与全局坏三元组的逐尺度临界律
是同一现象的点中心版本。

## 5. 对证明路线的裁决

不能直接照搬以下模板：

1. 取密度约 \(2/n\) 的普通伪随机近完美配置；
2. 对每个缺口寻找一个完全不落在任何旧割线上的随机 absorber；
3. 期望每个缺口仍有 \(\Theta(n^2)\) 或固定比例候选。

第二步的候选比例已经是 \(n^{-\Theta(1)}\)。

仍可能成功的修正版必须至少包含一项额外机制：

1. absorber 同时删除若干旧点，而不是要求新点避开所有旧割线；
2. 为每个二进方向尺度预留独立的修补资源；
3. 用强负相关或代数结构压低通过待补点的割线数；
4. 设计大 absorber，使多个尺度的冲突在一次宏步中相互抵消。

这也解释了为何完整两边/三边单调 switch 会出现深局部极小：在临界密度下，
改变一个小局部通常会在其他尺度立即制造新的割线冲突。
