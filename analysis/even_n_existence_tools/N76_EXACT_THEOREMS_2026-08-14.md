# n=76 的精确有限定理与板面裕量景观（2026-08-14 续）

## 1. 精确有限定理（EXACT FINITE）

**定理 A**：n=74 rot4 解平移 (+1,+1) 嵌入 76 棋盘后（74 个半转代表，
E=0），对全部 2814 个可用下半平面格点，任意两个格点的顺序插入
（精确增量公式，经暴力逐项验证）的加权超额最小值为 **E = 24**
（C_col = 8），唯一达到 (0,34)+(41,0)。全部 3,957,891 对穷举确认。

推论：任何"核心 + 2 轨道"的半转配置有 C_col ≥ 8。该配置即
四分之一旋转对称扩展（核心 rot4 对称 + 一个 C4 轨道 = 4 点），
其六类 C4 census 加权超出 = 30 = (3/2)·8·... = 12·...（与直接计数一致）。
这是当前已知的 n=76 最低坏三元组状态（C_col=8，低于 E=5 种子的 20），
但它**不是合法 2-per-line 配置**（行/列 34、41 各 3 点，行/列 0、75 各
1 点——8 条坏线中 4 条是轴线），故不构成对合法 E=5 纪录的改进。

**定理 B（结构）**：NTIL 的半转配置必须满足"每个下半行恰好 2 个代表"
且"列对平衡 #{x} + #{75−x} = 2"（由每行每列恰 2 点推出）。E=24 墙配置
违反行平衡（行 34 有 3 个代表，行 0 有 1 个），故不是真正的近解——
平衡配置的已知最小 E 为 60（平衡搜索），严格高于墙值。

## 2. 板面裕量景观（VERIFIED DATA）

将核心嵌入更大的棋盘 N（平移 (N−74)/2），逐点贪心插入 + 最优改进：

| N | 裕量(环) | E 轨迹（k=0..4 次插入后） |
|---:|---:|---|
| 76 | 0 | 0, 12, 24, 42, 60 |
| 78-86 | 1-5 | 0, 12, 24, 36, 48 |
| 88 | 6 | 0, 12, 24, 30, 42 |
| 92 | 8 | 0, 6, 12, 24, 36 |
| 94 | 9 | 0, 6, 12, 18, 24 |
| 96 | 10 | 0, **0**, 6, 12, 18 |
| 108 | 16 | 0, **0**, **0**, 6, **0** |
| 112 | 18 | 0, **0**, **0**, 6, **0** |

要点：

- 紧棋盘（N=76..86）：每插入一个代表精确增加 E=12（C_col=4），不可修复；
- 裕量 ≥ 10 环（N=96）后首次插入可被局部改进修复回 E=0（75 代表 E=0
  配置存在）；
- N=108/112：前 3-4 次插入都可修复（"吸收容量"随裕量增长）；
- 但增长在 m≈80 处饱和（联合双插入也不能突破），无法到达 m=N；
- E=24 作为"饱和地板"在多个 N 出现（N=76 的 k=2、N=88 的 k=9、N=112 的
  k=10），但其具体结构随 N 变化（n=76 为行/列共振，N=112 为垂直坏线对
  x=25/86、50/61）。

## 3. 对推荐方向的评估

1. **Priority E（n→n+2 局部吸收器）**：关闭。跨层最小轨道编辑距离线性
   增长（~n/2）；核心的插入吸收容量 ≤ 6（常数）且需大裕量；
   常数半径修补在已知训练对上已被否定（README 已述）。
2. **Priority C（k=2 相关估计）**：指出其内在困难——相关只改变方差，
   不改变共线三元组期望（~2n ln n 调和发散）。需要的是"条件测度本身
   压低轻线尾"的构造（如带排斥的 Gibbs 测度），而非对已知测度的相关
   估计。这是该方向真正的缺口。
3. **Priority F（CRT 调色板 slack）**：结构上等价于对线覆盖/插入冲突
   计数；本会话给出的"每自由格点 dE ≥ 12"（定理 A 的推论，精确验证）
   即调色板 slack 的紧界：嵌入核心的调色板在 76 棋盘上"无 slack"。
4. **四矩阵备忘录 §9B（强制零点/下界）**：E=24 墙现在有精确有限基础
   （全部 2 插入的下界）；任意配置的下界证明仍是开放的，平衡重构
   （定理 B）是更干净的攻击框架。
