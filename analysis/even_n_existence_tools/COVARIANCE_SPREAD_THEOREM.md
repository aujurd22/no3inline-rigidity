# 极值集的协方差扩散定理与三角形面积平方和

## 1. 定理

设 \(n\) 为偶数，\(S\subset\{0,\ldots,n-1\}^2\) 是一个 \(2n\) 点
无三点共线集。从 \(S\) 中均匀随机取一点 \((X,Y)\)，并记

\[
h=\frac{n-1}{2},\qquad
V=\operatorname{Var}X=\operatorname{Var}Y=\frac{n^2-1}{12},
\qquad C=\operatorname{Cov}(X,Y).
\]

则

\[
\boxed{|C|\le \frac{n^2-4}{24}}
\]

以及

\[
\boxed{
\left|\operatorname{Corr}(X,Y)\right|
\le \frac{n^2-4}{2(n^2-1)}<\frac12.
}
\]

因此协方差矩阵满足

\[
\boxed{
\det\operatorname{Cov}(X,Y)
=V^2-C^2
\ge \frac{n^4-4}{192}.
}
\]

若 \(D(A,B,C)\) 表示三点的有向二倍面积

\[
D(A,B,C)=\det(B-A,C-A),
\]

则还有精确的全局下界

\[
\boxed{
\sum_{\{A,B,C\}\in\binom S3}D(A,B,C)^2
\ge \frac{n^3(n^4-4)}{24}.
}
\]

等价地，随机三元组满足

\[
\boxed{
\mathbb E D^2
\ge
\frac{n^2(n^4-4)}
{16(2n-1)(n-1)}
=\left(\frac1{32}+o(1)\right)n^4.
}
\]

## 2. 每行每列饱和

每行和每列本身都是直线，所以各自至多含两点。总点数为 \(2n\)，故每行、
每列都恰有两点。因此 \(X\) 与 \(Y\) 都在
\(\{0,\ldots,n-1\}\) 上均匀分布（每个值出现两次），从而

\[
\mathbb EX=\mathbb EY=h,\qquad
\operatorname{Var}X=\operatorname{Var}Y=\frac{n^2-1}{12}.
\]

## 3. 一个带容量的整数平方和引理

令 \(n=2m\)。在整数轴上，每个整数位置最多允许放两个元素。任意含 \(2n=4m\)
个元素的多重集，其平方和至少为

\[
2\cdot0^2+
2\sum_{k=1}^{m-1}\big(k^2+(-k)^2\big)+m^2+(-m)^2
=\frac{n^3+2n}{6}.
\]

理由很直接：按绝对值从小到大填充容量为二的位置。前
\(4m-2\) 个槽位恰好是两个零和 \(\pm1,\ldots,\pm(m-1)\) 各两个；
最后两个槽位的绝对值至少为 \(m\)。取 \(m,-m\) 达到下界。

## 4. 两组对角线同时控制协方差

对每个点定义

\[
d=Y-X,\qquad s=X+Y-(n-1).
\]

固定一个 \(d\) 就是一条斜率 \(+1\) 的对角线，固定一个 \(s\) 就是一条斜率
\(-1\) 的对角线。无三点共线说明每个整数值的重数都至多为二。由上一节，

\[
\sum_{S}d^2\ge\frac{n^3+2n}{6},
\qquad
\sum_{S}s^2\ge\frac{n^3+2n}{6}.
\]

除以 \(|S|=2n\)，并使用

\[
\mathbb E d^2=2V-2C,\qquad
\mathbb E s^2=2V+2C,
\]

得到

\[
2V\pm2C\ge\frac{n^2+2}{12}.
\]

代入 \(V=(n^2-1)/12\)，即得

\[
|C|\le\frac{n^2-4}{24}.
\]

继续计算

\[
\begin{aligned}
V^2-C^2
&\ge
\frac{(n^2-1)^2}{144}
-\frac{(n^2-4)^2}{576}\\
&=\frac{n^4-4}{192}.
\end{aligned}
\]

## 5. Cauchy--Binet 面积恒等式

把每个点写成齐次行向量

\[
(1,X_i-h,Y_i-h)
\]

并组成 \(2n\times3\) 矩阵 \(M\)。任取三行的 \(3\times3\) 行列式正是对应
三角形的 \(D\)。Cauchy--Binet 给出

\[
\sum_{\{A,B,C\}}D(A,B,C)^2=\det(M^\mathsf TM).
\]

中心化使第一列与后两列正交，所以

\[
M^\mathsf TM=
\begin{pmatrix}
2n&0&0\\
0&2nV&2nC\\
0&2nC&2nV
\end{pmatrix}.
\]

因此

\[
\sum_{\{A,B,C\}}D^2
=(2n)^3(V^2-C^2)
\ge\frac{n^3(n^4-4)}{24}.
\]

## 6. \(C_4\) 对称情形

若 \(S\) 在绕棋盘中心旋转 \(90^\circ\) 下不变，则协方差矩阵也必须在该旋转
下不变，故

\[
C=0.
\]

于是任意 \(C_4\) 饱和点集（甚至不要求无三点共线）都有完全相同的面积平方和：

\[
\boxed{
\sum_{\{A,B,C\}}D(A,B,C)^2
=(2n)^3\left(\frac{n^2-1}{12}\right)^2
=\frac{n^3(n^2-1)^2}{18}.
}
\]

也就是说，在 \(C_4\) 搜索类内，二阶面积能量不是可优化目标；不同候选的差异
只存在于面积分布的高阶统计、零面积原子以及素因子谱。

## 7. 对研究路线的裁决

1. 两张置换图不能长期压在一条宽度 \(o(n)\) 的对角带内；仅斜率
   \(\pm1\) 的容量约束就把相关系数限制在 \(1/2\) 以下。
2. 所有极值候选都含正比例数量的面积为 \(\Theta(n^2)\) 的三角形；问题并非
   通过让绝大多数行列式都很小来逃避。
3. 该平方和下界仍不足以控制行列式**乘积**或大素因子，因此不能填补
   `DETERMINANT_PRODUCT_BARRIER.md` 中的首项系数二倍缺口。
4. 对 \(C_4\) 搜索，平方能量恒定；更合理的目标是零行列式数、低面积尾部、
   \(\sum\log|D|\) 或分素数的模共线谱。
