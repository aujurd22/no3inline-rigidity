# pure_binary_cycle_scale 修正重做报告（2026-07-21）

> 标签：**[COMPUTATIONAL CERTIFICATE]**——全部为计算结果，非定理。

## 0. 旧版错误（必须显式撤回）

旧文件 `pure_binary_cycle_scale.json` 记录的是「两顶点普通有向环」，例如字面量
序列 `[3, 0, 3]`（即 `lit_3 → lit_0 → lit_3`）。这仅是 implication 图里的一条
普通双向边，**不保证是矛盾见证**。矛盾见证的硬性要求是：*某个变量 x 的两个文字
`lit(x,0)` 与 `lit(x,1)` 落在同一 SCC 且被同一条有向环同时遍历*。旧脚本
`shortest_simple_cycle` 只取 SCC 内任意最短环（可能只是 `a↔b`），并不保证环含
矛盾变量的两个文字，因此旧文件的「边数/变量数」统计是**错误口径**，必须作废。

## 1. 修正版方法（已与 classify_contradiction_type.py / verify_pure_binary_reclassify.py 对齐）

对每幅补全：

1. 构建 **全图** `adj_full`（含一元强制 + 一元矛盾 + 二元禁配）与
   **纯二元图** `adj_pure`（剔除一切一元）。
2. 分类：
   - `trap`：全图 UNSAT 且 纯二元图 NOT UNSAT（矛盾依赖一元强制）；
   - `pure_binary`：纯二元图 UNSAT（矛盾不依赖任何一元）；
   - `sat`：两者皆 SAT（需回退几何 oracle）。
3. 对每幅 UNSAT 补抽取**真正矛盾环**：枚举矛盾变量 p，取
   `lit(p,0) → … → lit(p,1) → … → lit(p,0)` 双向最短路径拼接，得到同时遍历 x
   两文字的最小环（记录边数与不同变量数）。
4. 对纯二元补全额外用精确子集枚举 `exact_min_contradiction_vars(adj,W)`
   （k=2,3,4 全枚举所有 C(W,k) 子集）给出**严谨最小矛盾变量数**。

> 注：步骤 3 的 BFS 最短环给出的变量数是*上界*——其路径有时绕经矛盾子集之外，
> 故可能比真实最小大 1。步骤 4 的子集枚举才是真实尺度。两者一致地表明：
> k=14 不存在任何 4 变量以上的最小矛盾（精确枚举上界为 3）。

## 2. 结果

### k=14（23 幅补全，全部来自 6 个 V20 盆地）

| 指标 | 值 |
|---|---|
| 类型分布 | trap=0，pure_binary=23，sat=0 |
| 最短矛盾环边数（字面量） | 5 边：21 幅；6 边：2 幅 |
| 最短矛盾环变量数（BFS 上界） | 2 变量：7；3 变量：14；4 变量：2 |
| **精确最小矛盾变量数（子集枚举，严谨）** | **2 变量：7；3 变量：16；4 变量：0** |

抽查（k14, v20_01, mask 8929978983）真实矛盾环：
```
[(9,0),(2,0),(9,1),(2,1),(9,0)]   # 同时含变量 9 的两文字(lit18,lit19) → 真矛盾
变量数=2
```
对比旧文件同补全记录的 `[[1,1],[0,0],[1,1]]`（lit3→lit0→lit3）——仅普通两顶点
有向环，不含任何矛盾变量的两个文字，是错误见证。

### k=15（16 幅补全，全部来自 6 个 V20 盆地，探针）

| 指标 | 值 |
|---|---|
| 类型分布 | trap=0，pure_binary=16，sat=0 |
| 最短矛盾环边数（字面量） | 5 边：14 幅；6 边：2 幅 |
| 最短矛盾环变量数（BFS 上界） | 2 变量：3；3 变量：11；4 变量：2 |
| **精确最小矛盾变量数（子集枚举，严谨）** | **2 变量：3；3 变量：11；4 变量：2** |

抽查（k15, v20_02, mask 75365587979）真实矛盾环：
```
[(1,0),(11,0),(1,1),(14,1),(1,0)]   # 同时含变量 1 的两文字 → 真矛盾
变量数=3
```

## 3. 结论（诚实标定）

1. **k=14 与 k=15 的全部 UNSAT 补全均为纯二元矛盾（0 个陷阱）**。这直接否定了
   旧定理 B「2-变量 2-CNF 矛盾 ⟺ 陷阱」以及旧猜想 G「任意低容量补全 UNSAT 必为
   陷阱」。详见 `trap_rigorous_theory.md` §4（定理 B 修正版）与 §7。
2. 纯二元矛盾的**最小尺度**为 2–3 个变量（k=14）或 2–4 个变量（k=15）。存在真正的
   2-变量纯二元矛盾（反例 `(x∨y)∧(x∨¬y)∧(¬x∨y)∧(¬x∨¬y)` 的结构），证明 2-变量
   矛盾无需一元强制即可出现。
3. 矛盾环边数恒为奇数（5 或 6）——这源于有向环需交替遍历两文字、闭合于起点，
   最小非平凡矛盾环长度为 4（两变量互相强制）+ 闭环感 1，实际观测最小值为 5。
4. 旧 `pure_binary_cycle_scale.json` 已作废；本结果以
   `pure_binary_cycle_scale_corrected.json` 为准。
