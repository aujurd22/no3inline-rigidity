# 半转（中心对称）Census 与 n=76 的 E=24 墙（2026-08-14）

## 1. 半转 census 定理（PROVED + VERIFIED）

偶数 n = 2m 棋盘上，中心对称（半转，rot2）的 2n 点配置由 n 个反对称对组成；
取每个对的下半平面代表（y ≤ m−1）为 r_1..r_n。在中心化加倍坐标
（X = 2x−(n−1), Y = 2y−(n−1)）下定义：

```
F1(p,q,r) = det(p,q) + det(q,r) + det(r,p)      (面积形)
F2(p,q,r) = det(p,q) − det(q,r) − det(r,p)      (反演形)
```

则（推导同 C4 情形，仅两个 Fourier 块 j=0,1）：

```
2·N1 + 6·N2 = 6·C_col + 12 n² − 4 n
N1 = #{(p,q,r) ∈ R³ : F1 ≡ 0 mod Q}
N2 = #{(p,q,r) ∈ R³ : F2 ≡ 0 mod Q}
```

对任意素数 Q > 4(n−1)²（本工作取 Q > 6(n−1)² 保证 ≡0 ⟺ =0）。通用下界：

```
N1 ≥ 3n² − 2n   （p=q, q=r, r=p 三个对角片恒为零）
N2 ≥ n²         （p=q 片恒为零）
```

因此**半转 NTIL ⟺ N1 = 3n²−2n 且 N2 = n²**，且

```
C_col = [ (N1 − 3n² + 2n) + 3·(N2 − n²) ] / 3
```

验证：n=6..16 的全部 rot2 解精确落在下界；E=5 种子（n=76）的半转视角
N1=17194(+18), N2=5790(+14)，C_col = 20 与直接计数一致；满棋盘应力测试
精确满足恒等式。

几何意义：F2 = 0 ⟺ p, q, −r 共线（反演三元组）。故半转 NTIL ⟺
（a）代表间无三点共线 且 （b）无 {p,q,−r} 三点共线 且 （c）无两代表与
中心共线（由 NTIL 自动蕴含）。这比 C4 的六类约束轻得多。

## 2. n=74 解嵌入 n=76（VERIFIED DATA）

将 n=74 的 rot4 解平移 (+1,+1) 嵌入 76×76 棋盘：保持关于 76 中心的
四分之一旋转对称（从而中心对称）。其 74 个半转代表满足 N1=16280=3·74²−148，
N2=5476=74²——**E=0，即 148 点无三点共线**。

因此 D(76) = 152 等价于：向该配置添加 2 个反对称对（4 点）保持无三点共线。

## 3. 行列强制与扩展墙（EXACT FINITE）

152 点的 NTIL 配置每行每列恰好 2 点。嵌入配置占据行/列 1..74；故新增 4 点
必须在行 0, 75 与列 0, 75 中——**唯一候选是四角
{(0,0),(75,0),(0,75),(75,75)}**。直接验证：四角扩展产生 28 个共线三元组
（E=84），失败。

任何其他扩展必须移动旧点。穷举扫描（精确增量公式）：

1. **单插入**：对嵌入配置，最优单插入 dE=6（格点 (0,34)）；无干净插入。
2. **双插入**：top-400 格点的全部 8 万对，最小联合 E=24（(0,34)+(41,0)）；
   其余全部 ≥ 30。
3. **局部改进**：单点最优移动、交换、双代表联合移动、踢出+改进（ILS）、
   移除-重插修复、全代表最优改进——全部无法突破 E=24。
4. **其他核心**：n=72/70/68/66 解嵌入 76 后逐点插入，最小 E 分别为
   60/72/84/108——n=74 核心最优。
5. **随机起点**：8 个随机 76 代表配置经改进后 E ∈ [216, 294]。
6. **角点路径**：嵌入+四角（E=84）经最优改进也收敛到 E=24。

结论：**n=76 半转配置的加权超额 E 的已知最小值为 24（C_col = 8）**，
由多条独立路径（E=5 C4 种子、嵌入 n=74 + 最优双插、角点扩展）收敛到同一
墙。E=24 墙配置的结构：

```
行 34、41 各有 3 点（互为反演），行 0、75 各有 1 点（新边界行）；
列 34、41 各有 3 点，列 0、75 各有 1 点；
8 条坏线 = 2 条水平 + 2 条垂直 + 2 对斜率 ±3/7 的斜线（互为反演对）。
```

坏线全部由两个插入代表 (0,34)、(41,0) 与旧代表的"镜像行列共振"产生。

## 4. 理论意义与后续方法

1. **证否路径**：若可证明 n=76 的任意半转 76 代表配置 E ≥ 24（即
   min C_col = 8），则中心对称的 D(76) = 152 不存在。当前证据强烈支持
   E_min = 24，但缺少证明。这是"偶数全可解"猜想的潜在反例方向：
   需要 (i) 2-per-row/col 强制 + 角点失败（已得），(ii) 任意移动旧点的
   补偿下界（缺证明）。
2. **归纳障碍量化**：跨层最小轨道编辑距离随 n 线性增长（n=30→32 时为 19，
   即仅 6 个轨道共用）——n→n+2 局部归纳不可行；E 的"每插入 +12"线性响应
   表明 n=74 核心对扩展饱和。

4. **验证过的插入增量公式**：向 m 代表配置插入格点 a 的精确 (ΔN1, ΔN2)：
