# \(C_4\) 对称类的熵--冲突失衡

## 1. 结论先行

在一个最自然的随机 \(C_4\) 饱和模型中，坏三点的期望仍为

\[
\left(\frac{24}{\pi^2}+o(1)\right)n\log n,
\]

与普通两张随机置换之并具有相同首项常数。

但全部 \(C_4\) 饱和候选的对数数量只有

\[
\left(\frac12+o(1)\right)n\log n,
\]

远小于一般两置换空间的 \(2n\log n\)。

因此朴素 Poisson 零冲突启发式给出

\[
\log\mathbb E(\#C_4\text{ 解})
\approx
\left(\frac12-\frac{24}{\pi^2}\right)n\log n
\approx-1.9317\,n\log n.
\]

这不是不存在证明，但它强烈说明：即使一般 \(2n\) 解可能继续存在，要求所有偶数
阶都存在 \(C_4\) 解是一个更不可信、熵严重不足的猜想。

## 2. 随机置换轨道模型

令 \(n=2m\)。在左上 \(m\times m\) 基本域中取一张均匀随机置换图

\[
A_\pi=\{(i,\pi(i)):0\le i<m\}.
\]

把每个胞元扩成完整的四分之一转轨道。所得点集 \(S_\pi\)：

- 大小为 \(4m=2n\)；
- 每行每列恰有两点；
- 自动具有 \(C_4\) 对称。

它只是全部总度二基本图的一个子模型，但已经保留正确的首项熵和局部选点密度。

## 3. 坏三点期望的首项

网格中的非轴向共线三元组总数为

\[
T_3(n)=\left(\frac3{\pi^2}+o(1)\right)n^4\log n.
\]

对一个一般三元组，其三个点属于三个不同基本胞元，而且这些胞元的基本行、
基本列都互异。随机置换同时包含三个指定胞元的概率为

\[
\frac1{(m)_3}
=\frac8{n^3}\left(1+O\left(\frac1n\right)\right).
\]

例外三元组包括：

- 两点属于同一个 \(C_4\) 轨道；
- 两个基本胞元共享基本行或基本列；
- 水平、竖直等轴向三元组。

轨道碰撞类只有 \(O(n^3)\) 个；共享折叠坐标或轴向的类至多 \(O(n^4)\) 个，
比 \(T_3(n)\) 少一个 \(\log n\) 因子。前者被选中的概率至多 \(O(n^{-2})\)，
后者要么概率为零，要么仍为 \(O(n^{-3})\)，总贡献只有 \(O(n)\)。

因此

\[
\boxed{
\mathbb E\,B(S_\pi)
=\left(\frac{24}{\pi^2}+o(1)\right)n\log n,
}
\]

其中 \(B\) 是共线三元组数。

也就是说，\(C_4\) 对称没有消除临界的调和尺度和；它只把同样多的首项冲突塞进
了小得多的候选空间。

## 4. 全部 \(C_4\) 饱和候选的数量级

任意基本域 \(A\) 的行列饱和条件为

\[
r_i(A)+c_i(A)=2\qquad(0\le i<m).
\]

把胞元 \((i,j)\) 看成从 \(i\) 到 \(j\) 的有向边，忽略方向后得到每个顶点
总度二的伪图；环按度二计算。

事实上可以精确枚举。忽略有向边方向后，每个连通分量只能是：

1. 一个环胞元 \((i,i)\)，分量大小一，配置数 \(c_1=1\)；
2. 两个顶点间同时选择 \((i,j),(j,i)\)，分量大小二，配置数 \(c_2=1\)；
3. \(k\ge3\) 个顶点上的无向圈，并给每条边独立选择一个方向，故
   \[
   c_k=\frac{(k-1)!}{2}\,2^k=2^{k-1}(k-1)!.
   \]

标号集合结构的指数公式给出

\[
\begin{aligned}
\sum_{m\ge0}\frac{\#\mathcal C_m}{m!}z^m
&=\exp\left(
z+\frac{z^2}{2}
+\sum_{k\ge3}\frac{2^{k-1}}kz^k
\right)\\
&=\boxed{\frac{e^{-z^2/2}}{\sqrt{1-2z}}}.
\end{aligned}
\]

所以有精确系数公式

\[
\boxed{
\#\mathcal C_m
=m![z^m]\frac{e^{-z^2/2}}{\sqrt{1-2z}}.
}
\]

它给出

\[
2,12,90,810,8940,116760,1756860
\]

作为 \(m=2,\ldots,8\) 的计数，精确复现独立穷举结果。

在主奇点 \(z=1/2\) 处作奇点分析可得

\[
\boxed{
\#\mathcal C_m
\sim e^{-1/8}\frac{2^m m!}{\sqrt{\pi m}}.
}
\]

因而 Stirling 公式严格给出

\[
\boxed{
\log\#\mathcal C_m=m\log m+O(m)
=\frac n2\log n+O(n).
}
\]

所以扩大到全部 Hamilton 圈、多个圈、双向二重边和环，不但不改变
\(\frac12n\log n\) 的首项熵，其完整一阶渐近也已确定。

大小 \(m\) 的单 Hamilton 分量恰有

\[
H_m=2^{m-1}(m-1)!
\]

种：先取无向标号圈，再独立定向每条边。故

\[
\frac{H_m}{\#\mathcal C_m}
\sim
\frac{e^{1/8}\sqrt\pi}{2\sqrt m}.
\]

所以 Hamilton 基图只比全部基本图少一个多项式因子，而不是指数因子。已知大阶
解频繁出现单圈结构，至少在纯计数层面并不反常；把搜索限制为 Hamilton 圈仍保留
完整的首项熵，但也不会改善冲突常数。

初步均值为：

有限阶比极限常数 \(24/\pi^2\approx2.4317\) 小，但比值随 \(n\) 上升，

## 6. 为什么这仍不是定理

把零冲突概率写成 \(e^{-\mu}\) 使用了独立 Poisson 近似。实际坏事件通过共享点和
共享方向簇集；标准 Janson 依赖项为 \(\Theta(n\log^2 n)\)，只能给出
\(e^{-\Theta(n)}\) 级上界，仍不足以压过
\(e^{(1/2+o(1))n\log n}\) 个候选。

所以目前不能据此断言“大 \(n\) 无 \(C_4\) 解”。但与一般空间相比，这里的熵
余量少了四倍，而冲突首项没有下降；若要先证明一个受限不存在定理，\(C_4\)
类应是比一般 NTIL 更现实的目标。

## 7. 对下一步的裁决

1. “用 \(C_4\) 对称统一证明所有偶数阶”不应再被当作默认正向主线。
2. \(m=37\) 搜索长期不突破，与这个熵--冲突失衡一致；继续加算力未必能改变
   结构性稀缺。
3. 若研究 \(C_4\) 理论，最有价值的目标改为：
   - 对 \(C_4\) 候选建立多尺度容器计数；
   - 证明零冲突候选数为
     \(e^{-(c+o(1))n\log n}\#\mathcal C_m\)，其中 \(c>1/2\)；
   - 或先证明某个自然子类（置换轨道、Hamilton 基图）最终无解。
4. 若坚持全偶数存在，应允许非对称构造；目前没有证据说明旋转对称能在渐近上
   免费获得。
