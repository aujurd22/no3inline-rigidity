# 两行 permutation switch 的尺度安全性

日期：2026-07-19

## 1. 实验定义

本文件最初把每个已知行列饱和 NTIL 解的 2-正则二部图交替染色，分解成两张完美匹配。
在其中一张匹配里选两行 \(a,b\)，交换它们的列：

\[
(a,f(a)),(b,f(b))
\longmapsto
(a,f(b)),(b,f(a)).
\]

排除与另一张匹配重合的非法交换。对每个合法交换，完整枚举新产生的共线
三元组，并记录它们最小的本原方向尺度

\[
q=\max(|u|,|v|),\qquad \gcd(u,v)=1.
\]

若最小值至少为 \(Q\)，该交换就不会重新打开任何尺度 \(<Q\) 的冲突。

程序：`analyze_switch_scale_safety.py`。

## 2. 结果

对缓存中的全部偶数阶 \(6\le n\le72\) 第一条已知解进行了完整枚举。

- 没有任何一个合法两行交换直接到达另一个 NTIL 解；
- 保护尺度 \(1\) 的交换只占很小比例；
- 保护尺度 \(1,2\) 后数量通常降到个位数或几十；
- 没有形成随 \(n\) 增长的固定正比例安全度数。

代表数据：

\[
\begin{array}{c|r|r|r|r|r}
n&\text{合法交换}&q_{\min}\ge2&q_{\min}\ge3&
q_{\min}\ge4&q_{\min}\ge5\\
\hline
24&504&28&0&0&0\\
36&1190&98&22&6&0\\
48&2162&223&32&0&0\\
60&3422&182&16&4&0\\
72&4968&254&26&4&0
\end{array}
\]

全部阶数的结果见 `switch_scale_safety_n6_72.json`。

对 \(n=6,8,10,12\) 的每个合法交换，另用修改后点集的全三元组枚举逐一核对，
与 secant 索引算法完全一致。

## 3. 理论含义

上一轮提出的“每个冲突拥有固定比例安全 switch”若把 switch 理解为普通两行
换位，已经被数据明确否定。即使从零冲突解出发，短方向二点割线也会使几乎所有
换位立即产生三点线。

这不否定宏观 switch，但规定了它必须具备的结构：

1. 同时移动多于两个点；
2. 对最短方向产生相关抵消，而不是独立随机选择新位置；
3. 最自然的充分条件是保持短方向 line sum；`TOMOGRAPHIC_SWITCH_BARRIER.md`
   又证明这种充分条件最多推进到 \(O(n^{1/3})\)；
4. 因此最终需要“只保护已饱和二点线”的带 slack trade。

下一步可计算对象不再是所有短方向，而是障碍线族

\[
\mathcal B_Q(S)=
\{\ell:\operatorname{scale}(\ell)<Q,\ |S\cap\ell|=2\}.
\]

寻找 signed switch \(h\) 时只要求：

- 对 \(\ell\in\mathcal B_Q(S)\)，加入端不能落到 \(\ell\) 上，除非同时删去
  其旧点；
- 对未饱和短线只要求新负载不超过二；
- 横竖线和仍严格为零。

这比全 X-ray 保持弱得多，因而可能越过 \(n^{1/3}\) 唯一性壁垒；同时它比
“随机宏 switch”精确得多，可以转成带障碍的稀疏整数 kernel/匹配问题。

## 4. 扩大到一般 2-factor 邻域后的修正

固定两张匹配的换位不是完整的距离四邻域。`analyze_general_rectangle_switches.py`
又枚举了任意两个旧点的矩形重连。它在 \(n=36\) 找到四个能够保护全部尺度
\(<5\) 的一般重连，其中一个为

\[
(9,1),(24,28)
\longmapsto
(9,28),(24,1).
\]

所以“尺度五已经没有距离四 switch”只对固定分解成立，不能推广到一般
2-factor 空间。

但更高尺度仍迅速封闭：

- 全部 \(6\le n\le72\) 的一般矩形重连都没有直接 NTIL 邻居；
- \(n=72\) 的 10008 个合法矩形重连中，保护尺度 \(<4\) 的只有八个，
  保护尺度 \(<5\) 的为零；
- 完整枚举三边交替圈也没有产生任何直接 NTIL 邻居。

最终的严格局部半径结论与插入代价证明见
`SECANT_INSERTION_RIGIDITY.md`。因此本文件的正确裁决是：

> 固定分解的两行换位过窄；一般矩形 switch 能多走一层，但仍不足。真正的
> 宏观 move 应建模为带割线 transversal 条件的交替圈。
