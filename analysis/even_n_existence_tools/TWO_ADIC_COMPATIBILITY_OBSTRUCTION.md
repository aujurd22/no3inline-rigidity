# \(2\)-进相容置换的统一障碍

## 1. 定义与结论

称置换

\[
f:\{0,\ldots,2^k-1\}\longrightarrow\{0,\ldots,2^k-1\}
\]

是 \(2\)-进相容的，如果对每个 \(t\le k\) 都有

\[
x\equiv x'\pmod {2^t}
\quad\Longrightarrow\quad
f(x)\equiv f(x')\pmod {2^t}.
\]

这正是深度 \(k\) 的有根二叉树自同构；所有在
\(\mathbb Z/2^k\mathbb Z\) 上诱导置换的整系数多项式都属于此类，常见的
三角位函数、逐位可逆映射以及相容的奇部模逆分层也都落在这个框架内。

本项目得到：

> **定理。** 若 \(k\ge3\)，任意 \(2\)-进相容置换 \(f\) 的整数图
> \[
> \{(x,f(x)):0\le x<2^k\}
> \]
> 都含三个共线点。

因此，利用单个 \(2\)-进置换多项式或相容位函数先造一张无三点置换，再把两张
这样的图合并，原则上就不可能成功；第一张图已经失败。

## 2. 从任意 \(k\) 递归缩到 \(k=3\)

相容性说明一个固定输入奇偶类 \(x=2u+r\) 被映到固定输出奇偶类
\(f(x)=2v+s\)。定义

\[
g(u)=\frac{f(2u+r)-s}{2}.
\]

由于 \(f\) 在每一级剩余类上都是双射，\(g\) 是
\(\{0,\ldots,2^{k-1}-1\}\) 上的相容置换。

若 \((u_i,g(u_i))\) 三点共线，则仿射映射

\[
(u,v)\longmapsto(2u+r,2v+s)
\]

保持共线性，于是 \(f\) 的图也有三点线。反复限制任意奇偶分支，就把问题降到
\(k=3\)，即模 8。

## 3. 模 8 的 128 种可能与六三元组证书

把输入输出写成低位在前的二进制位。任一相容置换恰有形式

\[
\begin{aligned}
y_0&=x_0\oplus c_0,\\
y_1&=x_1\oplus g_1(x_0),\\
y_2&=x_2\oplus g_2(x_0,x_1).
\end{aligned}
\]

自由布尔值数为 \(1+2+4=7\)，所以恰有 \(2^7=128\) 种。对每一种，
下列六个输入行三元组中至少有一个使相应图点共线：

\[
\begin{gathered}
(0,1,2),\quad(0,1,3),\quad(1,4,7),\\
(3,4,7),\quad(3,5,7),\quad(3,6,7).
\end{gathered}
\]

逐项只需检查整数等式

\[
(j-i)(f(k)-f(i))=(k-i)(f(j)-f(i)).
\]

纯 Python 证书 `verify_compatible_permutation_obstruction.py` 枚举七个布尔
参数而不是枚举 \(8!\) 个任意置换，并断言上述六个三元组覆盖全部 128 种。
另一个精确集合覆盖计算确认六是这套候选行三元组中的最小证书大小，记录见
`compatible_permutation_n8_cover_certificate.json`。

## 4. 对偶数阶构造的意义

这个定理封闭的是一个相当大的“按二进制位递归造置换”家族，但不封闭一般偶数
阶构造：

- 一般置换不必保持任何 \(2^t\) 同余；
- 已知大阶极值解的两张完美匹配分解通常高度混合，未表现为二叉树自同构；
- 非相容的跨尺度进位恰可能是避开上述递归三点线所必需的结构。

所以后续若仍走二进制方向，必须主动打破相容性，而不能只增加多项式次数或更换
相容位函数。
