# \(p-1\) 阶棋盘中的二次曲线匹配层分类

令 \(p\) 为奇素数，\(n=p-1\)，并把棋盘坐标

\[
B=\{0,1,\ldots,p-2\}
\]

按模 \(p\) 看成 \(\mathbb F_p\setminus\{-1\}\)。本文件分类满足下列条件的
点集 \(M\subset B^2\)：

1. \(M\) 每行每列恰有一点，即 \(M\) 是一张完美匹配；
2. \(M\) 包含在一条定义于 \(\mathbb F_p\) 的次数至多二曲线上。

结论是：除退化情形外，所有这类匹配只有穿孔模直线和穿孔模双曲线两族。因而
本项目此前对这两族的计算不是随意选取的样例，而覆盖了全部“单二次曲线完美
匹配层”。

## 1. 非退化圆锥曲线必须经过两个坐标无穷远点

设射影闭包为非退化圆锥曲线 \(C\)。固定一个有限横坐标 \(x\)，竖直射影线
与 \(C\) 的交数为二。

若竖直无穷远点

\[
P_y=[0:1:0]
\]

不在 \(C\) 上，则每条竖直线的两个交点都在有限部分。由于二次方程定义于
\(\mathbb F_p\)，只要其中一个交点是 \(\mathbb F_p\)-有理点，另一个也必然
是有理点；“恰有一个有限有理交点”只可能发生在该竖直线与 \(C\) 相切时。
但一个固定方向的切线至多有两条；更直接地，从 \(P_y\notin C\) 向非退化
圆锥曲线作切线至多两条。

这里 \(p-1\ge4\) 个棋盘横坐标都要求恰有一个有限点，故不可能全部由相切
解释。因此必须有 \(P_y\in C\)。同理，横直无穷远点

\[
P_x=[1:0:0]
\]

也在 \(C\) 上。

一般齐次二次式写成

\[
A X^2+BXY+C Y^2+D XZ+EYZ+FZ^2.
\]

代入 \(P_x,P_y\) 得 \(A=C=0\)。在仿射片 \(Z=1\) 中，曲线因此形如

\[
Bxy+Dx+Ey+F=0. \tag{1}
\]

若 \(B=0\)，它是模直线；若 \(B\ne0\)，它是双线性双曲线。

## 2. 用射影直线上的缺失二点得到精确正规形

式 (1) 把 \(y\) 表成 \(x\) 的分式线性函数 \(f\)。棋盘匹配条件等价于

\[
f:\mathbb P^1(\mathbb F_p)\setminus\{-1,\infty\}
\longrightarrow
\mathbb P^1(\mathbb F_p)\setminus\{-1,\infty\}
\]

是双射。分式线性变换本身是整条射影直线的双射，所以它必须把缺失二点集合
\(\{-1,\infty\}\) 映到自身。只有两种可能。

### 情形 A：分别固定两个缺失点

\[
f(\infty)=\infty,\qquad f(-1)=-1.
\]

此时 \(f\) 是仿射函数，且精确写成

\[
y+1=s(x+1),\qquad s\in\mathbb F_p^\*. \tag{2}
\]

这就是穿孔模直线层。

### 情形 B：交换两个缺失点

\[
f(\infty)=-1,\qquad f(-1)=\infty.
\]

此时

\[
y+1=\frac{a}{x+1},\qquad a\in\mathbb F_p^\*,
\]

即

\[
(x+1)(y+1)=a\pmod p. \tag{3}
\]

这就是穿孔模双曲线层。

所以分类没有遗漏额外的平移参数：一旦棋盘是连续的 \(p-1\) 个整数坐标，
缺失剩余类必为 \(-1\)，所有平移都已经被 (2)、(3) 的 \(x+1,y+1\)
吸收。

## 3. 退化二次曲线

若二次式分解为两条直线，一个无三点共线集在每个因子上至多取两点，总共至多
四点。对 \(n=p-1\ge6\)，它不可能包含一个大小为 \(n\) 的匹配层。因此大阶
情形无需另留退化分支。

## 4. 与已有障碍的合并

本项目已经得到：

1. 对每个 \(p\ge7\)，任一穿孔模直线层 (2) 自身就含普通整数三点线；见
   `PUNCTURED_MODULAR_LINE_OBSTRUCTION.md`。
2. 穿孔模双曲线层 (3) 自身是无三点共线的，因为普通整数共线会推出模
   \(p\) 共线，而一条有限域直线与非退化圆锥曲线至多交两点。
3. 两条固定双曲线层的全部乘子对在 \(p=13,17,\ldots,61\) 的精确扫描中
   均失败；从 \(p=29\) 起，扫描内每一对甚至已经在斜率 \(+1\) 或 \(-1\)
   的某条普通对角线上各贡献两点，形成四点线。
4. 更强地，即使只固定一条双曲线而让第二张匹配完全任意，\(p=13,17,19,23\)
   的每个乘子也都被精确证明无法完成；小素数 \(p=5,7,11\) 仍有例外。

严格可下的裁决是：

> 在 \(n=p-1\) 模型中，任何把最终 \(2n\) 点预先分成两张“单二次曲线
> 完美匹配”的方案，只剩双曲线—双曲线一种候选；它在全部已精确检查的
> \(p\ge13\) 上失败。

最后一句目前仍是有限范围计算事实，不应冒充“所有素数”的定理。要完全封闭
这条路线，还需证明以下二者之一：

- 任意两条 (3) 在充分大 \(p\) 时共享一条普通二割线；
- 或任意一条 (3) 的普通割线与一旧点—二新点约束阻止任何第二完美匹配。
