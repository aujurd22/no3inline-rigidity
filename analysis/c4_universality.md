## 0. 重大更正（先读）

研究文档 `research_directions_2026-07-09.md` §1 曾断言：

> "full m-cycle 与 (1,m−1) 两种模式对所有 m ≥ 10 都有效（已验算 m=10..28）"

**该断言是 BUG 产物**。原验证脚本 `c4_constructive.py` 的 `verify()` 只检查**前 5000 个三元组**就 early-exit，对大 m（C(4m,3) ≫ 5000）它把"前 5000 个恰好无共线"误判为"整体无共线"。

用 **SOUND 的 O(N²) 方向哈希共线检查**（`has_collinear`，与 brute-force 全三元组交叉验证一致）重做后：

| 模式 | 结论（m = 3..60，部分到 200） |
|---|---|
| **full m-cycle** | **对全体 m ≥ 4 失败**（m=3 侥幸成立） |
| **(1,m−1) 单/多 loop** | **对 m = 3..60 全部失败**（无一例外） |
| **skip-k 单圈** `(i,i+k)` | m = 4..60 中**没有任何 k 适用** |

**朴素循环普适性猜想（full m-cycle / (1,m−1) 万能）因此证伪。**

### 0.1 失败是结构性的，不是凑巧
full m-cycle 的种子为 `(i,i+1),(i+1,i+2),(i+2,i+3),…`。其中
`(i,i+1),(i+1,i+2),(i+2,i+3)` 三点满足 `y = x+1`（斜率 1，截距 1），
**必共线**。故只要 m ≥ 4，三点 `(0,1),(1,2),(2,3)` 即构成共线三元组。
(1,m−1) 同理：去掉自环轨道后，剩余种子仍含连续对而共线。
→ 这两种"最自然"的构造注定失败，不是偶然。

## 2. 反直觉发现：合法 C₄ 2-因子是稀疏子集

对每个 m 跑 100 次**随机 2-因子**（随机置换的圈分解）：

- **m = 3**：39/100 成功；**m = 4**：偶有成功。
- **m ≥ 5**：**0/100 全部失败**。

含义：
1. C₄ 合法的 2-因子**不是"随便取一个就成"**——它们是全部 2-因子中的**稀疏子集**，随机几乎命中不了。
2. 这**直接反驳**了 `construction_law_final_2026-07-09.md` §3–§6 的乐观叙事
   （"轨道对冲突率 ∝ m^−1.68 ⇒ 约束稀疏 ⇒ 大 n 易存在 ⇒ 可用 LLL 轻松证"）。
   若随机采样都 0/100，则"坏事件概率小"的 LLL 前提**不成立**；存在性即使为真，也**不是稀疏约束的平凡推论**。

## 3. 但存在性在实测范围内为真

Flammenkamp 缓存对 **每一个偶数 n ∈ [6, 72]（共 29 个 n：6,8,…,72）** 都收录了
`rot4`（C₄ 对称、90° 旋转）解，且均为 extremal 的 2n 点解。

- "存在" 与 "易采样" 是正交的两件事：解**存在**（缓存实证），但**极难随机命中**（§2）。
- 这把方向 1 从"找一个万能显式公式"重新定位为：**证明/否定"对所有偶数 n 都存在某个冲突自由的 2-因子"**。

## 4. 修正后的精确开放问题

> **C₄ 存在性猜想（修正版）**
> 是否对**每一个偶数 n**，都存在一个 C₄ 对称的 2n 点 NTIL 解？
> - 实证：**n = 6,8,…,72 全为真**（29 个连续偶数）。
> - **前沿缺口：n = 74（m = 37）未知** —— 截至 2026-06-25 无已知 rot4 解；
>   我们此前的 GPU / CaDiCaL / Z3 / 2-matching / 置换搜索**均未证实也未证伪**。
>   - 若 n=74 **有**解 ⇒ 存在性至少延续到 74，需继续。
>   - 若 n=74 **无解** ⇒ 这是猜想的**反例**，本身是可发表的否定结果
>     （"并非每个偶数都有 C₄ extremal 解"）。
> - 这是一个**非平凡定理/反例**，不再是稀疏约束的推论。

## 5. 正确框架（Row-Degree 定理，已证）

n = 2m 的 C₄ 解 ⇔ 顶点集 `{0,…,m−1}` 上的一个 **2-因子（2-正则图）**，
每条边 `{i,j}` 对应基本域格点 `(i,j)` 及其 4-轨道

```
O(i,j) = { (i,j), (j, 2m−1−i), (2m−1−i, 2m−1−j), (2m−1−j, i) }
```

- 2-因子恰有 m 条边 ⇒ m 个 4-轨道 ⇒ 4m = 2n 点（中心不被占用）。
- 合法 ⇔ 任意三点不共线。
- **H_ring 视角**（呼应 H_ring 深化）：C₄ 解的环人口 ≡ 0 (mod 4) 且 ≥ 4
  ⇒ 永不是 H_ring 独立集 ⇒ 自动非 missing-center（对称排除定理的重述）。

**冲突超图模型**：顶点 = 基本域格点（候选轨道）；超边 = 会使被选轨道集出现共线三元组的轨道组合。C₄ 存在性 = 在该超图上找一个 2-因子，使其被选边集不含任何冲突超边。

## 7. 与方法论教训

- **不完备校验器会制造"定理"**：旧 `c4_constructive.py` 的 5000-三元组上限
  把"前 5000 个无共线"误当"整体无共线"，直接导致"循环普适性成立"的假结论。
  任何"构造验证"都必须做**全量 sound 共线检查**（本文件的 `has_collinear` 已与
  brute-force 交叉验证，可直接复用）。
- **随机正例 ≠ 易证存在**：§2 的 0/100 提醒我们，存在性实证不能替代对"构造难度"的诚实评估。
