## 1. 对合型行列式的代数结构

设 π mod N 为对合型排列，σ(x) = N-1-π(x)。对任何三元组 (i,j,k)，三种冲突类型的行列式：

### PPP: 三点来自 π
D_PPP = (j-i)(π(k)-π(i)) - (k-i)(π(j)-π(i))

### PPS: 两点来自 π，一点来自 σ
D_PPS = (j-i)(σ(k)-π(i)) - (k-i)(π(j)-π(i))
其中 σ(k) = N-1-π(k)
→ D_PPS = (j-i)(N-1-π(k)-π(i)) - (k-i)(π(j)-π(i))
        = (j-i)(N-1) - (j-i)(π(k)+π(i)) - (k-i)(π(j)-π(i))

### PSS: 一点来自 π，两点来自 σ
D_PSS = (j-i)(σ(k)-π(i)) - (k-i)(σ(j)-π(i))
其中 σ(j) = N-1-π(j), σ(k) = N-1-π(k)
→ D_PSS = (j-i)(N-1-π(k)-π(i)) - (k-i)(N-1-π(j)-π(i))
        = (j-i)(N-1) - (j-i)(π(k)+π(i)) - (k-i)(N-1) + (k-i)(π(j)+π(i))
     = ((j-i)-(k-i))(N-1) - (j-i)π(k) - (j-i)π(i) + (k-i)π(j) + (k-i)π(i)
        = (j-k)(N-1) - (j-i)π(k) + (k-i)π(j) - (j-k)π(i)
        = (j-k)(N-1-π(i)) - (j-i)π(k) + (k-i)π(j)

## 2. 进位效应

设 π_int(x) = π(x) + c_x·N，其中 c_x ∈ {0,1,2} 随机选择。

### PPS 进位
D_int_PPS = (j-i)(N-1-π(k)-c_k·N-π(i)-c_i·N) - (k-i)(π(j)+c_j·N-π(i)-c_i·N)
          = D_mod_PPS - N[(j-i)(c_k+c_i) + (k-i)(c_j-c_i)]

令 K_PPS = (j-i)(c_k+c_i) + (k-i)(c_j-c_i)

若 D_mod_PPS = 0（模 N 冲突），则 D_int_PPS = -N·K_PPS。
→ 需要 K_PPS ≠ 0 才能进位提升。

### K 的随机性分析

c_i, c_j, c_k ∈ {0,1,2} 独立均匀随机。

K = (j-i)(c_k+c_i) + (k-i)(c_j-c_i)
  = (j-i)c_k + (j-i)c_i + (k-i)c_j - (k-i)c_i
  = (j-i)c_k + (k-i)c_j + [(j-i)-(k-i)]c_i
  = (j-i)c_k + (k-i)c_j + (j-k)c_i

对固定 (i,j,k)，K 是三个独立随机变量（各取 0,1,2）的线性组合。
- 值域：|K| ≤ 2·(|j-i|+|k-i|+|j-k|) ≤ 4N
- P(K=0) ≈ 1/|值域| ≈ 1/(4N) 对于均匀分布（近似）

**关键推论**：进位提升率 = 1 - P(K=0) ≈ 1 - 1/(4N)。

对 N=8:  ≈ 97%  ✓ (实测 91%)
对 N=20: ≈ 99%  ✓ (实测 97%)
对 N=74: ≈ 99.7%

## 3. 残存冲突的上界

随机对合 π 的模 N 冲突数 ≈ α·C(N,3) 其中 α 是排列的共线概率。

对于随机排列，α ≈ 3/N²（每行两个点，任选三行产生共线的概率）。
→ 模 N 冲突数 ≈ 3·C(N,3)/N² ≈ N/2。

进位后残存：残存 = (模N冲突数) × P(K=0) ≈ (N/2) × 1/(4N) = 1/8 ≈ 0.125。

**这意味着进位后平均仅 ~0.125 个残存冲突！** SA 吸收器可以处理。

但实际观测中 N≥10 有 4-14 个残存冲突（远高于 0.125）——这是因为 K 不是真正均匀的，且 (j-i),(k-i) 的尺度效应。

## 4. 多进位优化

当前仅随机选择一种进位模式。改进：
- 对每个 π_mod，尝试多种进位模式（k_i 的不同选择）
- 选择残存冲突最少的进位
- 若仍 >0，SA 吸收器修补

## 5. m=37 (N=74) 外推

- 模N冲突 ≈ 74×73×72/6 × (3/74²) ≈ 37
- 进位后残存 ≤ 37/(4×74) ≈ 0.125（理论下限）
- 实际残存 ≤ 5（基于 N=16 的缩放：残存~0.3N 的趋势外推）
- SA 吸收器需求量：~N/2 = 37 次 4-环交换
- 预计总时间：~10-60s
