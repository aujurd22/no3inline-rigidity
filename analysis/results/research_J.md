## 1. 有限域 / 代数几何（m=37 是素数——独有的礼物）

m=37 是素数 ⇒ 候选 cell 坐标空间 `0..36` 本身就是一个有限域 **F₃₇**。这是之前所有
文档都没利用的结构。两个子方向：

### 1a. 圆锥曲线（代数曲线）构造 —— **已探针排除**
**想法**：若全部 m 个 fundamental cell 落在**同一个 Euclidean 圆**（圆心=棋盘中心
(36.5,36.5)）上，则 4m 个提升点全在该圆上；而一条直线与圆至多交 2 点 ⇒ **自动无 3 共线**。
问题退化为「在圆上挑 37 个满足 2-因子（rowSum+colSum=2）的 cell」。

**探针 `conic_probe_m37.py`（精确 C4 不变圆）**：
- cell 空间圆方程用**正确半整数中心**：C = (73−4x)² + (73−4y)²（`x,y∈0..36`）。
- 枚举全部 521 个 C4 不变圆，统计每圆的格点数。
- **结果：单圆最多仅 `n=8` 个格点（R=5330）**，绝大多数圆 ≤4 点。

**结论：决定性不可行。** 37×37 网格内任一圆（含 C4 不变圆）的格点数 ≪ 37，
连 37 个候选 cell 都凑不齐，更谈不上在其中挑出 2-正则子集。这是**点数列瓶颈**，
不是中心取错导致的假阴性（近似中心版也只到 24）。
→ 该优雅构造对**素数 m=37 失效**；但对非素数 m（圆可更大、格点更多）可能仍值得追。
**本方向在 m=37 关闭。**

### 1b. Chevalley–Warning / 特征和存在性证明
把「2-因子 + 每线 ≤2」写成 F₃₇ 上的多项式方程组，用 Chevalley–Warning：若方程总次数
< 变量数，则解数 ≡0 mod 37 ⇒ 至少一解存在。
- **障碍**：约束数（~1.26M 条线 + 74 个 2-因子方程）远大于变量（m²=1369），
  经典 CW 次数条件**不满足**，不能黑箱套用。
- **可能补救**：把变量压到「2-因子结构」本身（m 个出 stub 的完美匹配 ≈
  只用 ~37 个选择变量而非 1369），使变量/次数比翻转。属**推测性**，需重新编码。

### 1c. Combinatorial Nullstellensatz（Alon）非消失证书
构造冲突多项式 `P = ∏_{坏三元组 T} (1 − ∏_{i∈T} z_i)`，变量 `z_{xy}∈{0,1}`。
若展开后某个高次单项式系数 ≠0，则由 Nullstellensatz 存在一组 `z` 使所有坏三元组
不整取（即无 3 共线）且 Σz=m、满足 2-因子。
- 与 LLL 本质不同：LLL 要「正概率无坏事件」，**Nullstellensatz 直接给确定性存在**。
- **障碍**：系数 = 大规模容斥，需结构化才能算；但框架干净，是对 m=37 给
  **非构造存在证明**的最有希望代数路线之一。

## 2. 拓扑法（Z₄-等变 Borsuk–Ulam / Tucker）
把配置空间建成 Z₄-空间，冲突集建成 Z₄-子空间；用 Z₄-Tucker 引理证明「存在一个
无冲突的 Z₄-对称 2-因子」。类比 Z₂-Tucker 用于 Tverberg 型存在性。
- **优点**：一旦证成，给「所有充分大 m 存在」的**渐近非构造定理**，且不依赖
  概率/搜索。
- **难点**：把「2-因子 + 无 3 共线」落成 Tucker 的「平衡完全染色」需要精巧的
  几何-拓扑翻译；有限 m=37 的严格应用很硬。属**最雄心但最优雅**的方向。

---

## 3. CDCL SAT + C4 对称性破缺（最务实的具体下一步）★推荐
CP-SAT 在 m≥17 卡在 **presolve 墙**（1.26M 约束，presolve 不返回）。但**普通
CDCL SAT 求解器**（Kissat / CaDiCaL）处理 1.26M 子句毫无压力，且对 C4 对称性有成熟的
**lex-leader 对称性破缺**编码。
- **为什么是不同范式**：CP-SAT 的 presolve 是瓶颈；CDCL 的冲突子句学习 +
  对称性破缺是另一套机制，不共享那个墙。
- **编码**：变量 `z_{xy}`（cell 选/不选）+ 2-因子（每顶点 in+out=2，转 CNF 用
  顺序计数器/排序网络）+ 每线 ≤2（`Σ_l w·z ≤2` 转 CNF）+ C4 lex-leader 破缺。
- **风险**：m=37 仍可能难，但这是**未试过的新鲜范式**，且能直接给 SAT/UNSAT
  （UNSAT = 严格证伪 m=37，比搜索更有结论力）。
- **工作量**：中（生成 CNF ~1.26M 子句，单文件几百 MB；跑 Kissat 几分钟~几小时）。

## 4. 表示论 / Burnside 轨道计数 + Möbius 容斥
LLL 在双空间失败的根因是**依赖度通过 37 个 label 爆炸**（d~1.7×10⁷）。但若在
**C4 轨道商空间**上工作：配置 = 选若干轨道，冲突依赖只在「共享轨道」间发生，
商空间依赖图比 37-label 空间**小约 4 个数量级**。
- 用 Burnside 数出 2-因子轨道数，再用轨道级容斥/Möbius 下界「无冲突轨道选择数」。
- 这**正面攻击 LLL 的真实弱点**（label 爆炸），可能让某个 LLL 变体在商空间通过。
- 与「匹配/nibble」互补：nibble 是构造，这是计数存在性。

## 5. 最小冲突核 + 放电法（extend research_H 的「核」方向）★
假设 **m=37 不存在** rot4-NTIL，则必存在一个**极小的「不可修复冲突核」** K
（2-因子诱导子图的一小团冲突，无法靠换边消除）。用**放电法**证明：由于 induced
冲突超图极稀疏（codegree 最大 380 / 平均 157，见 `conflict_hypergraph_params.json`），
任何这样的核都「装不进」m=37 的尺寸/度数预算 ⇒ 矛盾 ⇒ **存在性得证**。
- 这是「极小反例」方法，与搜索无关，且**直接消费已有 codegree 数据**。
- 若反过来能构造出装得进 m=37 的核 ⇒ 给出**不可能性证书**。
- 关键缺口（research_H 已指出）：需补「核扩展引理」——把局部核扩成全局不可解的
  充分条件。

## 6. Gröbner 基 / 消元（理论干净但大概率不可行）
把多项式系统（每三元组 det≠0 + 2-因子）算 Gröbner 基 / 消元理想，提取一个解。
- 理论上最「代数求解」，但 m=37 规模（1369 变量、~1.26M 多项式）Gröbner 不现实。
- 仅作**理论框架**记录，不推荐作为主攻。
