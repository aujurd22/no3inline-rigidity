# Combinatorial Nullstellensatz 应用于 NTIL 全局障碍

## 1. 思想

Alon (1999) 的组合 Nullstellensatz：
> 设 F 是域，f ∈ F[x₁,...,xₙ]，若对某单项式 Π x_i^{t_i}（t_i ≤ |S_i|）系数非零，
> 则 f 在 S₁×...×Sₙ 上不恒为零。

对 NTIL：定义指示多项式 P(x₁₁,...,x_{nn})，使其零点 = 有效配置。

## 2. 双排列编码

对 n×n 网格，定义变量 z_{i,j} ∈ {0,1,2}：
- 0 = 空格
- 1 = π 的 1 个点  
- 2 = σ 的 1 个点
- 3 = 两个排列都在此格（非法，需排除）

每行每列恰有「一个 π 点 + 一个 σ 点」→ 每行 4 个 1+ 每列 4 个 1。

可简化为两个排列变量：
- x_{i,j} = 1 iff π(i)=j
- y_{i,j} = 1 iff σ(i)=j

约束多项式：
- 排列：Π_j (1 - Σ_i x_{i,j}) ← 这是指数级...
- 非退化：Π_i Σ_j x_{i,j}(1-y_{i,j}) ← 也不是多项式

→ 标准 Nullstellensatz 编码不实用。

## 3. 替代：理想饱和 + GB 全局分析

更可行的方法：对**固定 2-因子类**（如 D=0/L=1），分析其**参数化多项式理想**。

设 2-因子由 cycle 结构参数化。对每个具体的 2-因子，我们已有 GB 证书（52/52）。
问题：能否对**整个类**构建统一的 GB 证书？

### 3.1 符号化 Gröbner 基

对 D=0/L=1（36-cycle + 1 自环），有：
- 36 个 cycle 边（坐标 a_i, b_i）
- 1 个自环（坐标 s, s）
- 取向变量 x_0, ..., x_{36}

共线性条件 → 多项式 f_k(a_i, b_i, s, x_j) = 0

若系数域 = ℚ，理想 I = ⟨f_k, x_j²-x_j⟩ 对所有足够一般的 (a_i,b_i,s) 满足 1∈I，
则 D=0/L=1 整体不可行。

### 3.2 可行性

对「全坏三元组 Type 1」：a+b=常数 → 独立于 x_j（纯几何）→ 可直接从参数消去。

对「全坏三元组 Type 2」：等跨度 → 也独立于取向。

关键 open 问题：能否在参数空间 (a_i,b_i,s) 上证明**任意** Hamiltonian cycle + 自环必然包含 Type 1 或 Type 2 三元组？

→ 若证成，D=0/L=1 被定理证否。

## 4. 组合引理猜想

**[CONJECTURE C]**：对任意 n≥10，在 {0,...,n-1} 上的任意 Hamiltonian cycle，
其边集必然包含三个不同的边 (u,v) 满足 |v-u| 取相同值，或 u+v 取相同值。

n=5（m=10 的 cycle 部分）：counterexample? 需检查。
n=18（m=36 的 cycle 部分）：counterexample? m=36 解无 Type1/2！

→ **[OBSERVATION]** m=36 解（纯 36-cycle）无 Type1/2，故猜想 C 在 n=36 为假。
但 m=36 解有 Type1/2 吗？之前实验显示 m=36 的 allbad_triples=0。

**修正**：Type1/2 不是 cycle 的 universal 性质——m=36 证明。

## 5. 结论

- Nullstellensatz 在固定 2-因子层面已工作（52/52 GB 证书）
- 全局推广需要**参数化 GB**或**组合鸽笼原理**证明某类 2-因子必然含 bad triple
- m=36 解为纯 cycle 反例 → D=0 不一定整体 UNSAT
- 最可能的突破点：D=0/L=1（含自环）空间的组合鸽笼证明
