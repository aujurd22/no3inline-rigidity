# CP-SAT 全约束双排列 NTIL 模型：发现与分析

## 1. 模型

对 n×n 网格的 2n 点 NTIL 问题，用双排列 (π,σ) 编码：

- 变量：x_{i,j} = 1 iff π(i)=j, y_{i,j} = 1 iff σ(i)=j (2n² 个布尔变量)
- 行约束：每 i 有一个 π 列和一个 σ 列
- 列约束：每 j 被 π 和 σ 各选一次
- 非退化：π(i) ≠ σ(i) ∀i（确保 2n 个不同点）
- 线约束：每条含 ≥3 格点的直线最多 2 个点被选

## 2. 解的存在性

### n=8（16 点 in 8×8）
- CP-SAT: OPTIMAL in 0.0s
- π = [1,5,7,2,0,6,4,3]
- σ = [7,3,1,5,2,0,6,4]
- 非对合（仅 2/8 满足 σ=N-1-π）
- σ∘π 无固定点，π∘σ 无固定点

### n=10（20 点 in 10×10）
- CP-SAT: OPTIMAL in 4.4s
- π = [4,2,8,0,3,1,5,7,6,9]
- σ = [5,8,6,9,0,2,7,1,3,4]
- 非对合（仅 3/10 满足对合）
- π+σ 聚类于 9（3 次）

### 关键推论

1. **非对合 NTIL 双排列存在且 CP-SAT 能找到**——这否定了"对合是必要条件"的猜想。
2. **小 n 上 CP-SAT 极高效**（0.0-4.4s）——比 SA 吸收器快得多。
3. **解的空间结构未知**——CP-SAT 找到的解有无穷多族？能否参数化？

## 3. 缩放前景 (n=74)

n=74 的 CP-SAT 模型：
- 变量：74²×2 = 10,952 个布尔变量
- 线约束：含 ≥3 格点的直线数 ≈ (74²/π²)×(2×74) ≈ 176K（去重后约 50K-80K）
- 每线 1 个 ≤2 约束

CP-SAT 的性能取决于：
- 搜索空间能否被约束充分剪枝
- 是否存在快速可行解

若 n=12-20 的解时间呈次指数增长，则 n=74 可行（~100-1000s）。
若呈指数增长（如 5^n），则 n≥30 就不可解。

## 4. 与 C₄ 对称空间的对比

| 特征 | C₄ rot4 空间 | CP-SAT 全空间 |
|------|-------------|--------------|
| 变量数 | 37 cells × 28 orientations | 10,952 bool |
| 约束类型 | 3-CNF sound 松弛 | 精确排列+线容量 |
| 解的对称性 | C₄ 强制 | 无对称性强制 |
| m=37 状态 | 52/52 UNSAT（D≤3） | 未测 |
| 优点 | 快速筛选（~90s/GB） | 精确完备 |
| 缺点 | 固定因子逐一验证 | 搜索可能指数爆炸 |

## 5. 开放问题

1. CP-SAT 在 n=74 上是否有可行解？若有，这是否定了 C₄ 对称性的必要性。
2. 非对合 NTIL 解的代数特征——π 和 σ 模 n 下是否接近某种低次映射？
3. 能否从 CP-SAT 对小 n 找到的解归纳出构造公式？
