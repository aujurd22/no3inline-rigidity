# 双排列 NTIL 框架与多尺度吸收路线

> **审计说明（2026-07-22）**：“双排列表达”结论正确，但下文原证明中
> “每行每列各两点，所以两层分别是排列”的跳步不成立。正确证明是：
> 行—列二部图为 2-正则图，在每个偶圈上交替二染边，从而分解为两个
> 完美匹配。后续多尺度吸收和进位构造仍是猜想性路线。

## 1. 问题重述

对 n×n 网格上恰有 2n 个无三点共线的点，等价于：

**定理 0（双排列表达）**：2n 个无三点共线的点 ⟺ 存在两个排列 π, σ ∈ S_n，使得
```
S = {(i, π(i)) : i ∈ [n]} ∪ {(i, σ(i)) : i ∈ [n]}
```
中无三点共线。证明：每行恰 2 点 ⇒ π,σ 的像覆盖每列各 1 次 = 都是排列。

**推论**：问题降维为搜索 (π, σ) ∈ S_n²，避开所有共线三元组。

## 2. 冲突分类

三元组按涉及的排列可分为四类（3+0, 2+1, 1+2, 0+3），共线条件：

```
det = (x₂-x₁)(y₃-y₁) - (x₃-x₁)(y₂-y₁) = 0
```

其中每个点要么来自 π（y=π(x)）要么来自 σ（y=σ(x)）。

### 2.1 冲突矩阵 H（方向直方图）

对每个方向向量 d = (Δx, Δy)，计数该方向上三点共线数。按二进尺度分层：

```
D_j = {d : 2ʲ ≤ max(|Δx|, |Δy|) < 2ʲ⁺¹}, j = 0, 1, ..., ⌊log₂ n⌋
```

关键观察（Ghosal et al. 2026）：k≥3 时轻尺度收敛，k=2 时每个 D_j 同等重要。

## 3. 吸收操作（Alternating Cycle Switch）

**定义 1（交替 4-环）**：若存在 i₁≠i₂ 使排列值满足：
```
π(i₁) = a, σ(i₁) = b
π(i₂) = c, σ(i₂) = d
```
则切换为：
```
π'(i₁) = a, σ'(i₁) = d
π'(i₂) = c, σ'(i₂) = b
```
（交换 σ 在 i₁,i₂ 的值）保持每行每列恰 2 点不变。

**定义 2（交替 6-环）**：三个行 i₁,i₂,i₃，对 π 或 σ 做三循环置换，保持行列约束。

**定义 3（吸收器 Absorber(A, d)）**：对方向 d 上的坏线 L（含 ≥3 点），吸收器是一组交替环的集合，执行后可：
1. 修复 L 上的共线（降至 ≤2 点）
2. 不引入新的坏线
3. 不影响其他方向的线容量

## 4. 多尺度策略

```
Algorithm MultiScaleAbsorption(n):
  1. 构造初始近满解 S₀（模双曲线: ~1.5n 点，每行 ≤2，每列 ≤2）
  2. For j = ⌊log₂ n⌋ down to 0:
     a. 识别 D_j 中的坏线
     b. 为每条坏线构造独立吸收器（利用 D_j 尺度下冲突图的低度性）
     c. 执行吸收器（交替环切换）
  3. 补全未饱和行/列（剩余空缺用全局吸收器填补）
  4. 返回 2n 点完整配置
```

### 4.1 关键引理（待证明）

**引理 A（吸收器存在性）**：对方向 d，若冲突图中 d-坏线数远小于 n，则每条 d-坏线存在 Ω(n) 个不相交的交替 4-环吸收器。

**引理 B（跨尺度独立性）**：对 d ∈ D_j 和 d' ∈ D_{j'} (j ≠ j')，吸收器操作在尺度 d 上不产生新的 d'-坏线。

**引理 C（吸收器容量）**：一组吸收器可同时执行（不相交），修复所有 D_j 坏线的 1-ε 比例。

## 6. 实验证据（2026-07-21）

### 6.1 吸收器密度不随 n 衰减

在 n=6,8,10,12,14 上各采样 3 个随机双排列，统计交替 4-环改善冲突的比例：

| n | 冲突数(均值) | 改善率(均值) | 退化率 | 中性率 |
|---|-------------|-------------|--------|--------|
| 6 | 12 | 0.400 | 0.467 | 0.133 |
| 8 | 18 | 0.488 | 0.393 | 0.119 |
| 10 | 37 | 0.400 | 0.489 | 0.111 |
| 12 | 41 | 0.465 | 0.422 | 0.113 |
| 14 | 69 | 0.564 | 0.356 | 0.080 |

**关键结论**：改善率的线性回归斜率为 **+0.015/n**（几乎平坦），说明交替 4-环作为吸收器的有效性**不随 n 增长而衰减**。

### 6.2 贪心改进的能力与瓶颈

在 n=10 上 5 次试验：
- 初始冲突：17–46
- 100 次贪心 4-环交换后：2–8
- 最终（300 次含随机扰动）：2–20

瓶颈：局部极值。需要 6-环和 8-环吸收器打破对称性，或全局随机 restart。

## 7. 对合型双排列 (2026-07-21 晚, [COMPUTATIONAL CERTIFICATE])

### 发现

**σ = N-1-π（对合/involution）是天然的冲突过滤器。** 随机对合仅 ~3-6 个 ππσ 冲突 vs 随机双排列 ~30-100。抑制率 ~7-10×，N 越大优势越明显。

**根因**：行列式 D = (j-i)(N-1) - (j-i)(π(k)+π(i)) - (k-i)(π(j)-π(i))。大尺度下 (j-i)(N-1) 主导 → D ≠ 0。

**确证**：所有已知 rot4 解 π+σ 均值 = N-1（行和约束）。m=5 完美对合 (σ=N-1-π, 100%)。N=4 存在二次对合解 π=[2,3,0,1] 但 N≥6 无纯二次构造。

## 8. 进位配方：突破性构造法 (2026-07-21 夜, [COMPUTATIONAL CERTIFICATE])

### 核心思想

σ = N-1-π（对合）的 PPS 行列式：D = (j-i)(N-1) - (j-i)(π(k)+π(i)) - (k-i)(π(j)-π(i))。进位提升 π_int = π + c_x·N (c_x ∈ {0,1,2}) 引入：D_int = D_mod - N·K，其中 K = (j-i)c_k + (k-i)c_j + (j-k)c_i。若 D_mod = 0（模N冲突），则 D_int = -N·K。K=0 概率 ≈ 1/(4N) → 进位提升率 ≈ 1-1/(4N)。
