## 解读（修正）

- **极端对 = 全部转置对（确定性对应）**。666 个 co3>800 配对与 666 个转置对
  `(i,j)↔(j,i)`（m(m−1)/2 = 666）一一对应，且**所有转置对的 co3 都 >800**
  （均值 945，范围 800–1132，无一 ≤400）。
- 因此 a-priori 预测规则退化为最简洁形式：**“禁止所有转置对同时出现”**。
  无需计算 co3，直接由坐标 `(x,y)↔(y,x)` 识别，即可覆盖 100% 的极端 codegree 对。
- 之前 `sat_m37.py --forbid-extreme` 用 co3>800 选出的恰好就是这 666 个转置对
  （因为二者相等），说明该预处理已是最优、无遗漏。
- 几何上这些对无更细的“稀疏/密集”区分（gcd≥2 比例 40.5% 与非极端转置对相同；
  s=x+y 均值 36=m−1 但分布很宽），故不能进一步压缩到更少配对——禁 666 已是最小集。
- 残留瓶颈：禁用全部转置对后残余 (X) codegree ≤796 < 954 满足 Glock (C3)，但 CDCL 仍
  UNKNOWN（搜不动）→ 说明真正障碍已不是 codegree，而是 **2-因子全局耦合 + CDCL 规模**。
  这把攻坚焦点精确收敛到：在 2-因子表示下找到 (X)-free 解（见 csearch2 实验）。
