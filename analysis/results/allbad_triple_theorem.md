# Type 1/2 全坏三元组的几何证否定理

## 背景

对 rot4-NTIL：N×N 网格（N=2M，偶数），rot4 = 90° 旋转 (x,y)→(N-1-y,x)。
2-因子有 M 条边（基本域 cell），每条边 `(u,v)` 在两个取向下产生 4 个 rot4 网格点。
所有 M 个 cell × 每个 cell 的 4 rot4 点 = 4M = 2N 个网格点。
NTIL 要求：这 2N 个点中无三点共线。

## 定理 A (Type 1 证否)

**命题：** 若存在 3 个 cell，其基本域坐标 `(a₁,b₁), (a₂,b₂), (a₃,b₃)` 满足
```
a₁+b₁ = a₂+b₂ = a₃+b₃ = C    (即三点共线于 y = -x + C)
```
则对该 2-因子的**任意** 8 种取向组合，rot4 展开后的 72 个点中必存在共线三点。
特别地，该 2-因子的多项式系统的 Gröbner 基 = [1]，即不存在 rot4-NTIL 取向。

**证明：**

1. 基本域中，三点全部在直线 L₀: `y = -x + C` 上。

2. rot4 作用将 L₀ 依次映射为：
   - L₀: y = -x + C
   - L₁ = rot4(L₀): 将 (x, -x+C) ↦ (N-1-(-x+C), x) = (N-1+x-C, x)
     ⇒ y = x - (N-1-C)（斜率 +1）
   - L₂ = rot4(L₁): ⇒ y = -x + (2N-2-C)（斜率 -1）
   - L₃ = rot4(L₂): ⇒ y = x + (N-1-C)（斜率 +1）
   - rot4(L₃) = L₀（闭合）

3. 三个 cell 各有两个取向。但取自环方向 0 还是方向 1 都不改变 `a+b` 的值（因为 `a+b = b+a`），所以**无论取向如何，36 个基本域点全部在直线 L₀ 上**。

   ⚠️ 修正：每个 cell `(u,v)` 在 orientation 0 作为 `(u,v)`，在 orientation 1 作为 `(v,u)`。两种情况的基本域坐标都在同一直线上（u+v = v+u）。所以从基本域角度看，三 cell 的 6 个基本域坐标（3 cell × 2 取向，但每 cell 的两个取向给出相同的点集）全在 L₀ 上。实际上是 3 个点（每个 cell 看做一个点）在 L₀ 上。

4. 每个 cell `(u,v)` 在给定取向下产生 4 个 rot4 点，分别在 L₀, L₁, L₂, L₃ 上（rot4 群作用将这 4 条线作为一个轨道）。

5. 3 个 cell × 4 rot4 点 = 12 个点。取向翻转不改变「4 个点所在的 4 条线」集合（只是点的顺序变化）。

6. **关键：** 12 个点分布在 4 条直线上。每条直线最多包含多少个点？
   - L₀ 上有 3 个基本域点（三 cell 分别在 L₀ 上的初始位置）
   - 但 rot4 展开后，**每个** cell 的 4 个点中恰好 1 个在 L₀ 上、1 个在 L₁ 上、1 个在 L₂ 上、1 个在 L₃ 上
   - 所以每条线恰好有 3 个点（每 cell 各 1 个）

7. **矛盾：** 每条线上有 3 个点，而 NTIL 要求每条线至多 2 个点。因此**无论何种取向**，这 4 条线上必然出现 ≥3 个点共线。

8. 结论：多项方程式 `∏(x_i 或 1-x_i) = 0`（表示"禁止该取向组合"）在全部 8 种取向下恒为 0 ← 即每个取向组合都被禁止 ← 系统无解 ← Gröbner 基 = [1]。

**注意：** 上述证明的第 6 步需要验证：cell 的 4 个 rot4 点是否确实各落在不同的 Lᵢ 上。这源于 rot4 群作用的传递性：rot4 将 L₀ 上的点（基本域点）映射到 L₁, L₂, L₃ 上。如果初始点 (u,v) 在 L₀ 上，则 rot4(u,v) 必然在 rot4(L₀) = L₁ 上，依此类推。

## 定理 B (Type 2 证否——等跨度，任意方向) ⚠️ 2026-07-21 强化

**命题：** 若存在 3 个 cell，其基本域坐标满足
```
|b₁-a₁| = |b₂-a₂| = |b₃-a₃| = d
```
即三个 cell 的**绝对值跨度相等**（不要求方向一致），则同样对所有 8 种取向不可行。

**实验证实：** 混方向三元组 `(11,20), (16,25), (31,22)`（spans 9,9,9，后者反向）— 8/8 全坏。

**证明：** 绝对值跨度相等 ⇒ 三 cell 的基本域坐标落在至多 2 条对角线上（y=x±d）。rot4 将每条对角线映射到另一条斜率相反的对角线 ⇒ 全部 12 个 rot4 点落在 ≤ 4 条对角线上 ⇒ 鸽笼原理 ⇒ 至少 3 点共线。

**关键洞察：** 取向翻转 `(a,b)→(b,a)` 仅改变点在两条对角线之间的归属（从 y=x+d 切换到 y=x-d 或反之），不改变间距 d。因此无论任意方向组合，12 个 rot4 点始终限制在 4 条对角线上 ⇒ 某条线必含 ≥3 点。

## 推论 C (组合必要条件——强化版)

若一个 m=37 rot4 2-因子存在 NTIL 取向，则其基本域 cell 坐标必须同时满足：
- 集合 `{a_i+b_i}` 的最大重数 ≤ 2（无 Type 1）
- 集合 `{|b_i-a_i|}` 的最大重数 ≤ 2（无 Type 2，不区分方向）

等价地说：37 个基本域点中，"反对角线和"与"绝对值跨度"两个多重集中，任何值的重数均 ≤ 2。

## 推论 D (m=37 的 D=0/L=1 必然不可行——[CONJECTURE])

**猜想：** 对任意 36-cycle（顶点 {0..35}）+ 1 自环（顶点 36）的 2-因子，基本域 cell 坐标必然包含 Type 1 或 Type 2 全坏三元组。

**计算证据：** 23/23 随机 D=0/L=1 因子均 >0 全坏三元组。但迄今为止未严格证明——这是**尚未闭合的最后一个引理**。

若能证明，则得出：
> **定理**：m=37 rot4-NTIL 的 2-因子必须满足 D≥2（至少含 2 个 2-圈）。


## 2026-08-13 修正：推论 D 撤回（模型错误），正确模型下为假

### 1. 撤回

早前"用 MILP 证明推论 D（m=6..40）"的尝试无效：模型使用无向边 + 双向 MTZ
（对同一条边同时加 u_i-u_j+n·x<=n-1 与反向约束，x=1 时互相矛盾），且多重度
约束被写成"每对边单独 <=2"（平凡约束），导致所有 Hamilton 环被错误排除。

### 2. 正确模型与结果

正确模型：有向 Hamilton 环（每顶点出度=入度=1，有向 MTZ），Type-1/2 作为
固定和约束（对每个 s：Σ_{u<v,u+v=s}(x_uv+x_vu) <= 2；对每个 d 同理）。
loop cell (m,m) 单独计入（a+b=2m 唯一、|b-a|=0 唯一）。

对 m=6..38 全部 **FEASIBLE**，且显式提取的解经直接检查均为
**Type-1/2-free**（a+b 与 |b-a| 的重数全部 <=2）。

**结论：推论 D 为假。** 存在 Type-1/2-free 的 (m-1)-cycle + loop 因子。
历史 23/23 随机采样观察是采样偏差，不是必要性。

### 3. 对 n=76 的意义

- 旧候选（cpu E=9、gpu-elite）的 Type-1/2 缺陷是该特定因子的性质，
  不排除 (m-1)+1 类的其他因子。
- Type-1/2-free 因子的取向是否存在 NTIL 解，仍是开放问题（Type-1/2 只是
  必要条件，且现在知道它是可满足的必要条件）。

### 4. 遗留

- 正确模型下提取的 Type-1/2-free 因子可作为 rot4 搜索的新起点。
- 推论 D 的原始动机（大循环+单 loop 因子难有 NTIL 取向）未完全排除：
  仍需取向层检验。
