## 0. 方法：把每个解约化成「基本域 2-因子」

对每个 rot4 解（2n 点，n=2m），取第一象限 `x<m, y<m` 的 m 个 seed cell `(u,v)∈[0,m-1]²`
（每 C4 轨道恰一个）。已用 `c4_lifts` **验证**：这 m 个 cell 经 90° 旋转能**完美重建**整个 4m 点解。

关键修正：这 m 个 cell 构成顶点集 `[0,m-1]` 上的 **2-因子**——判据是
**合并列表 `(u ∪ v)` 中每个值 0..m-1 恰好出现 2 次**（不是分别检查 u/v 各值两次）。
对跖投影 `P(x)=min(x,2m-1-x)` 在 Q3 上恒等，故 Q3 cell 即 2-因子本身。

**全部 3877 个 rot4 解**（n=6..44 完整 + n=54/56 抽样）均正确解析为此 2-因子。

## 1. 四种「朴素公式」假设——全部被实证排除

| # | 假设 | 检验方式 | 结果 |
|---|------|---------|------|
| 1 | 种子点是单值函数 `y=f(x)` | 统计同一 x 是否有多 y | **445/446 采样解「一 x 多 y」**，几乎从不是函数 |
| 2 | 线性模映射 `y≡ax+b (mod m)` | 穷举 a,b 拟合 | **0 命中** |
| 3 | 二次模曲线 `y≡ax²+bx+c (mod m)`（HJSW 签名） | 素数 m≤23 穷举 | **0 命中** |
| 4 | 单圈解是完全映射置换（步长 `π(i)-i` 互异） | 对全部单圈解算步长多重集 | **ortho_count = 0（所有 n）** |
| 5 | FD 向量在螺旋上近似等距（角度间隙均匀） | 变异系数 cv | **cv 随 m 单调增长 1.29→3.54**，越来越非均匀 |

**结论**：rot4 NTIL 解**不是任何简单代数公式生成的**——它们是
**真正的组合 2-因子对象**，几何约束（无三共线）淘汰了几乎所有 2-因子，
幸存者无闭式表达。

## 2. 解的真正本质 = 「2-因子 + 二次共线 CSP」

把问题用 2-因子语言重写（这正是 SIRH 定理的二次层 (R8) 的离散版本）：

- 一个 rot4 解 ⇔ 顶点集 `[0,m-1]` 上的一个 2-因子（即置换 π 的无向骨架）。
- 「4m 点无三共线」 ⇔ 该 2-因子的 rot4 提升满足二次共线约束 `(X)∧(S)`。
- **FDR 线性层** = 必要不充分条件：`a−b` 每值 ≤2（斜率±1 线保持），在 2-因子上自动成立。
- **Trace 常数**（唯一普适不变量）：`Σ(A²+B²) = n(n²−1)/12`，其中 `(A,B)` 为 seed 的奇数坐标。
  所有解落在同一个「能量壳层」上——这是一个真正的**守恒常数**。

> 所以「公式」不是生成表达式，而是 **CSP 本身 + FDR 必要性 + Trace 常数**。

## 3. 跨 m 的结构规律（往回发现的线索）

**(a) 单圈率随 m 下降**（来自 `mine_solution_essence.json`）：
```
m=3:1.00  m=4:1.00  m=5:0.67  m=7:0.69  m=8:0.54  m=10:0.19  m=14:0.19 ...
```
小 m 几乎全是哈密顿单圈；大 m 绝大多数裂成**多圈** 2-因子
（n=44：2 圈 417 个、3 圈 296 个、4 圈 89 个、单圈仅 206 个）。

**(b) 典型大 m 解 = 「小固定结构 + 大圈」**：如 n=14 的 `[1,6]`（一个自环 + 6-圈）、
`[3,4]`。**这恰好与外部 agent 的 token/funnel 框架呼应**：每个圈=一个可局部重写的单元，
多圈结构就是「token 组合」——两条独立研究殊途同归。

**(c) 解计数增长（来自档案行数）**：
```
count / m!  : m=3→0.5    m=14→6.7e-10    m=27→7.1e-25  (暴跌)
count(n)/count(n-2): 大 m 稳定在 ~1.3–1.7（m≥26 约 1.5–1.6）
```
→ 有效解**指数增长但占全部 2-因子的比例趋于零**（约束可满足、密度稀疏）。
→ **所有 m=3..56 都有解**。m=37 若无解将是首个反例，与「稳定比例 ~1.5」的既有规律相悖，
   **数据层面支持「m=37 应有解」**（统计性论据，非证明；障碍在二次 CSP 的可满足性，
   而非存在性）。

## 4. 发散视角（升维 / 时间-空间 / 常数）

- **时间-空间**：单圈解 ⇔ 一个 m-圈置换 π ⇔ 离散动力系统。几何构型是这条
  「时间轨迹」在平面上的嵌入，共线约束 = 「轨迹不重访同一直线」。解的本质是
  **动力学 + 嵌入约束**的耦合。
- **升维**：固定 m 的所有解位于「2-因子空间」中的一片由二次约束定义的子流形上，
  全部坐落在 Trace 能量壳层 `n(n²−1)/12`。随 m 增大子流形体积分数→0 但非空。
- **常数**：Trace 是唯一的普适守恒量；其余矩（Σx²、Σxy、Σ(x−y)²）随解变化，
  是「自由参数」而非不变量。

---

## 5. 诚实结论与建议方向

1. **不存在生成这些解的闭式代数公式**（4+1 种假设全否）。继续寻找「公式」是死路。
2. **本质 = 满足二次共线 CSP 的 2-因子（置换）**。研究应转向
   **刻画「合法置换」集合的结构**（禁止模式？闭包性质？），而非拟合表达式。
3. **数据与 m=37**：计数稳定比例 ~1.5 + 全部 m≤56 有解 → 强烈提示 m=37 有解，
   真正难点是二次 CSP 的可满足性求解（与外部 agent 的 funnel/零解可达性框架一致）。
4. **可衔接的外部 agent 框架**：把 m=37 的 v40 盆地也按「2-因子圈 = token」重新刻画，
   看 40 局部极小的「卡点」是否正是某个不可消去的多圈结构——这比盲目搜索更有理论产出。
