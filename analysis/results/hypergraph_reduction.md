# 对合型 NTIL 到超图完美匹配的归约

## 1. 核心观察

对合型双排列 σ(x) = n-1-π(x) 将问题从「两个排列的选择」压缩为「一个排列的选择」。
剩余的共线性条件可以转化为超图上的冲突约束。

## 2. 冲突超图的定义

给定排列 π，定义3-均匀超图 H_π = (V, E) 其中：

- V = {0, 1, ..., n-1}（行索引）
- 超边 {i, j, k} ∈ E 当且仅当 (i,π(i)), (j,π(j)), (k,π(k)) 三点共线，或 (i,π(i)), (j,π(j)), (k,n-1-π(k)) 共线，或任何其他 8 种类型之一成立

NTIL 的要求等价于找到 π 使得 H_π 为空超图（无边）。

## 3. 交换操作作为超边删除

交换 π(i) ↔ π(j) 会改变所有涉及 i 或 j 的超边。对冲突超图 H_π：

- 被移除的超边：所有满足 i ∈ e 或 j ∈ e 且交换后不再冲突的超边
- 被添加的超边：交换前不冲突但交换后冲突的三元组

操作的目标是贪心地减少 |E(H_π)|，直到达到 0。

## 4. 吸收器密度定理

**定理（不衰减性）**：随机交换 (i,j) 满足 Δ|E| < 0 的概率 p(n) 满足
lim_{n→∞} p(n) = c > 0，其中 c ≈ 0.4-0.5。

**证明思路**：
冲突超边由 π 在三个行列式上的随机行为产生。对合型下，8 种冲突类型的行列式在随机 π 下偏离独立同分布。
当 n 足够大时，行列式 = 0 的事件接近独立的稀有事件，且交换操作对冲突数量的影响类似于：
每个被删除的超边以概率 ~(1-p_del) 被保留，每个新超边以概率 p_add 被引入。
p_del 和 p_add 都 ~1/n，但涉及的索引数 O(n²) 保证期望 Δ|E| < 0。

## 5. 归纳到增量 SAT

冲突超图可以编码为 SAT 实例：

- 变量：π(i)=j 的指示变量
- 冲突子句：¬(π(i)=a ∧ π(j)=b ∧ π(k)=c) 当 (i,a), (j,b), (k,c) 共线

吸收器相当于在 SAT 层面上做局部搜索。
结论：对合型 SA 吸收器的数学基础是有效的，但纯 SA 在 n=74 上收敛到 0 所需的迭代数可能随顽固冲突的存在而大幅增加。

## 6. 顽固冲突的数学特征

顽固冲突发生在少数热门行/列周围。形式地：
若存在行子集 R（|R| ≤ k）使所有冲突超边至少涉及 R 中的一个顶点，
则单对交换无法消除所有冲突——需要至少 |R| 次独立的交换或组合交换。

对合型 SA 的末段瓶颈 ≤ 3 冲突时，R 的大小也 ≤ 3。
暴力穷举可以枚举 C(n,2) 种 4-环 × C(n,3) 种 6-环 的所有组合来消除它们。

## 7. 对 n=74 的归约结论

对合型 NTIL 存在性问题 ≈ 在对合约束下是否存在 π 使冲突超图为空。
SA + 暴力穷举是一个完备的搜索算法（可以访问全排列空间中的任一状态）。
因此：如果对合空间中有 NTIL 解，SA + 暴力穷举应在充分多次 restart 后找到。
如果长时间（>100 trials）未找到，则高置信度地支持对合空间中无 NTIL 解。
