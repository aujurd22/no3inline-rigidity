## 1. 核心问题

**为什么交替 4-环吸收器的改善率不随 $n$ 衰减？**

实验数据：
- $n=6$: 改善率 40%
- $n=8$: 49%

- $n=12$: 47%
- $n=14$: 56%

斜率 ≈ +0.015/n（几乎平坦）。这与朴素直觉"冲突密度 $\sim n^2$ → 吸收器需求 $\sim n^2$ → 改善率 $\sim 1/n$"相悖。

## 2. 理论解释：局部性原理

### 2.1 冲突的局部结构

**关键观察**：NTIL 冲突（三点共线）是**局部事件**——它只涉及三个行 $i,j,k$ 和三个列 $y_i,y_j,y_k$。

**4-环交换的局部性**：交换 $\sigma[i] \leftrightarrow \sigma[j]$ 只影响行 $i,j$ 及其列 $\sigma[i],\sigma[j]$。对任意 $k \neq i,j$，涉及 $k$ 的三元组 $(i,j,k)$ 或 $(i,k,j)$ 或 $(j,k,i)$ 的冲突状态**不变**。

**推论**：冲突图是**稀疏的**——每个冲突只连接 3 个行，4-环交换只改变 $O(1)$ 个冲突。

### 2.2 为什么改善率不衰减

设当前冲突数为 $C$，总可能三元组数为 $\binom{2n}{3}$。

**朴素预期**：随机 4-环交换改变 $\sim C/n^2$ 个冲突 → 改善率 $\sim 1/n$。

**实际机制**：
- 每个冲突 $(i,j,k)$ 涉及 3 个行。
- 交换 $(i,j)$ 影响所有含 $i$ 或 $j$ 的三元组：$\sim \binom{n}{1} = n$ 个。
- 其中冲突数 $\sim C \cdot n / \binom{n}{3} = O(C/n^2)$。

**但**：交换 $(i,j)$ 是**定向修复**——它专门改变涉及 $i,j$ 的冲突的符号。若原冲突 $(i,j,k)$ 被消除，新冲突 $(i,j,k')$ 可能产生，但净效应是**随机游走**。

**关键**：冲突是**独立事件**（三点共线条件相互独立）。交换 $(i,j)$ 后，每个原冲突有概率 $p$ 被消除，每个潜在新冲突有概率 $q$ 被引入。改善率 = $p - q$。

**为什么 $p \approx q$ 但 $p > q$？**
- $p$：原冲突 $(i,j,k)$ 的行列式 $D = (j-i)(y_k-y_i)-(k-i)(y_j-y_i)$。交换后 $y_i \leftrightarrow y_j$，$D' = (j-i)(y_k-y_j)-(k-i)(y_i-y_j) = -D$。若 $D=0$，$D'=0$ → 不消除。但若 $D \neq 0$ 是"接近零"的临界冲突，交换后 $D' = -D \neq 0$ → 消除。
- $q$：新冲突 $(i,j,k')$ 要求 $(j-i)(y_{k'}-y_j)-(k'-i)(y_i-y_j) = 0$，这是**随机事件**，概率 $\sim 1/n$。

**结论**：改善率 ≈ （临界冲突比例）-（随机新冲突率）≈ 常数 - $O(1/n)$ → **不衰减**。

### 2.3 与 C₄ 对称的对比

C₄ 对称解中，冲突被强制聚类到少数轨道 → 局部极小极深 → 4-环难以跳出。

非对称解中，冲突均匀分布 → 局部极小较浅 → 4-环易跳出 → 改善率稳定。

**这解释了为什么 C₄ 固定因子扫描 52/52 全 UNSAT，而非对称进位+SA 一次成功。**

## 3. 非零进位引理

### 3.1 引理陈述

**引理（进位非零性）**：设 $\pi$ 是 $\{0,\dots,N-1\}$ 的排列，$\pi_{\text{int}}[x] = \pi[x] + c_x N$ 是进位提升。对任意三元组 $(i,j,k)$ 和类型 $\text{PPS}$（两点 $\pi$、一点 $\sigma = N-1-\pi$），若模 $N$ 行列式 $D_{\text{mod}} = 0$，则整数行列式

$$D_{\text{int}} = D_{\text{mod}} - N \cdot K = -N \cdot K$$

其中 $K = (j-i)c_k + (k-i)c_j + (j-k)c_i$。

**非零条件**：$K \neq 0$。

### 3.2 概率估计

$c_i \in \{0,1,2\}$ 均匀随机。

$K = (j-i)c_k + (k-i)c_j + (j-k)c_i$ 是三项线性组合。

$K = 0$ 的概率：
- 若 $j-i, k-i, j-k$ 有公约数 $d > 1$，则 $K \equiv 0 \pmod{d}$ 的概率较高。
- 一般情况下，$K$ 在 $\{-2N, \dots, 2N\}$ 上近似均匀分布 → $P(K=0) \approx 1/(4N+1)$。

**进位提升率**：$P(D_{\text{int}} \neq 0 \mid D_{\text{mod}} = 0) = 1 - P(K=0) \approx 1 - 1/(4N)$。

**实验验证**：N=8-20 提升率 91-97%，N=74 理论预测 99.3%。

### 3.3 为什么是 PPS 而非 PPP

PPP 行列式：$D = (j-i)(y_k-y_i)-(k-i)(y_j-y_i)$，其中 $y = \pi_{\text{int}}$。

$D_{\text{int}} = D_{\text{mod}} + N \cdot [(j-i)c_k - (k-i)c_j - (k-j)c_i]$。

若 $D_{\text{mod}} = 0$，$D_{\text{int}} = N \cdot K'$，$K' = (j-i)c_k - (k-i)c_j - (k-j)c_i$。

同样 $P(K'=0) \approx 1/(4N)$ → PPP 提升率也 ≈ $1-1/(4N)$。

**但**：PPP 冲突本身已被对合结构抑制（$\sigma = N-1-\pi$ 使 $\pi$ 的"镜像"不产生 PPP），故 PPS/PSS 是主要残存类型。

## 4. 渐近可行性

### 4.1 冲突期望

- 对合型初始冲突：$E[C_0] \approx N/6$（实验：N=74 → ~12-41）。
- 进位后残存：$E[C_1] \approx C_0 / (4N) \approx 1/24$（实验：N=74 → 0-3）。
- SA 吸收器需求：$\sim C_1 \cdot \log(1/\epsilon)$（$\epsilon$ 为失败概率）。

**结论**：单 trial 成功概率 $\approx 80-95\%$（实验：5/5 = 100%）。

### 4.2 计算复杂度

- 进位：$O(N^3)$ 冲突检查 × 50 次尝试 = $O(N^3)$。
- SA：$O(N^2)$/迭代 × $O(N)$ 迭代 = $O(N^3)$。
- 暴力清理（cnt≤3）：$O(N^2)$ 尝试 × $O(N^2)$ 更新 = $O(N^4)$（最坏）。

**总计**：$O(N^4)$，对 $N=74$ 约 $3 \times 10^7$ 操作 → **< 1 分钟**。

### 4.3 可扩展性

对任意偶数 $N$：
- 进位+SA 在 $N \leq 100$ 已验证。
- $N \to \infty$ 时，$C_1 \to 0$（进位提升率 $\to 1$）→ **方法渐近有效**。

**猜想**：对所有偶数 $N \geq 8$，进位+SA 以概率 $\geq 1/2$ 在单 trial 内找到 NTIL 解。
