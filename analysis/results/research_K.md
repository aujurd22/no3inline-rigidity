## #1c Combinatorial Nullstellensatz（理论成立，m=37 计算阻塞）

**构造**：在域 F（char 不整除相关量，取 Q 或 F_p）上，令变量 `x_{a,b}∈{0,1}`。
定义「消去多项式」
```
P(x) = (∏_i (1 - χ_2F(i))) · (∏_{triple T} (1 - ∏_{k∈T}(1-x_k)))
```
其中 `χ_2F(i)=1` 当 vertex i 的 2-因子度≠2，`T` 跑遍全部共线三点组。
则 `P(x)=0 ⇔ x` 是一个有效 rot4-NTIL 选择。NSS 定理：若 `P` 中某个
「极大单项式」`∏ x_{a,b}^{d_{a,b}}`（Σd_{a,b}=deg P）的系数非零，则存在使 P=0 的
{0,1} 赋值 ⇒ **存在解**。

**可计算性障碍（决定性）**：
- `deg P = 37×2 + N(X)×3 ≈ 9.3×10⁷`，极大单项式空间为 `2^{1369}`。
- 任一项系数 = 对所有 `2^{1369}` 个赋值的求和 → 在 m=37 **不可计算**。
- 即便取最小情形 m=5（25 变量），冲突三元组也已上千，系数计算需遍历 `2^{25}`。
  仅 m≤~8 可暴力验证。

**小 m 验证思路（诚实标注，未执行重计算）**：
对 m=3（9 变量，`2^9=512` 全枚举）可构造 P 并验证
「解存在 ⇔ 某极大单项式系数≠0」，从而**确认方法正确**；但无法推进到 m=37。

**诚实裁决**：#1c 是合法的非构造存在性框架，但其在 m=37 的可行性 = 与 #4 的容斥
同构，本质上仍被 3100 万冲突的规模卡住。它的价值是**理论**（存在性 = 一个多项式恒等式），
而非实战。→ 不优先投入计算。

## #4 轨道商 + Möbius 容斥（一阶矩 = 正在实测；完全容斥在 m=37 阻塞）

**两个子方向**：

### (a) Burnside / 轨道商
计数「up to C4」的冲突自由 2-因子：
`N/4 = (fix(e)+fix(r90)+fix(r180)+fix(r270))/4`。
- `fix(r90)=0`（非平凡 90° 固定解不存在）。
- `fix(r180)` = 180° 对称（iden 类）配置。
这**降低对称性**，但每个陪集仍需解原 CSP ⇒ 不解决核心硬度。

### (b) Möbius / 容斥（一阶矩 = 已实测）
```
#valid = Σ_{S⊆Conflicts} (-1)^{|S|} · N(S)
```
`N(S)` = 包含冲突集 S 的 2-因子数。|S|=1 即**一阶矩**：
`E[#bad] = Σ_{triple T} Pr(T 全选)`。这正是 `sample_conflicts_m37.py` 测的量。

**实测结果（m=37, 4000 个均匀 stub-matching 2-因子）**：
- `mean_conflicts = 416.4`（min=204, max=884）
- **`fraction_zero_conflicts = 0 / 4000`** —— 没有任何一个随机 2-因子是无冲突的。

**解读**：一阶矩 416 ≫ 1，且 4000 次抽样 0 命中无冲突 ⇒ 随机 2-因子**几乎必然**
带冲突。这**坐实**了 LLL 在两个空间的失败（与 `lll_matching` 的 p·N≫1 一致），并说明
nibble 不能从「随机起点」贪心得到——必须**构造性穿针**（按 codegree 局部修正）。
（注：`lll_matching` 早先估的 `expected #bad ≈ 5981` 用的是双射空间的宽松概率；本采样的
416 是 stub-matching 空间的实际值，二者同量级、同结论。）

- 完全容斥（|S| 任意）在 31M 冲突下**不可行**（2^{31M} 项）。

### 素数 m=37 的 Fourier 角度（标注限制）
m=37 是素数 ⇒ 加群 Z_37 可作用。但共线性是**几何**约束，不是 Z_37 上的加法关系
（"共线"无法写成 `f(x)+g(y)=h` 的加法等式），故 Fourier（特征标）**不能对角化**
冲突超图。素数性在此问题里**没提供代数捷径**（与 Costas 阵列不同，后者是加法差集）。

**诚实裁决**：#4 的可执行部分（一阶矩）已用采样直接测；完全容斥与素数 Fourier
均在 m=37 阻塞。一阶矩本身**解释了为何 LLL 失败**，并把球踢给 nibble/构造。

## #5 最小冲突核 + 放电法（核已刻画；势函数未知）

**定义**：最小冲突核 K = 极小 cell 集合，使得**任何** 2-因子只要包含 K 就至少触发一个
(X)/(S) 违规。

**关键事实（已坐实）**：at-most-2 条件下，极小禁用集**恰为共线三点组**——
任意 3 个共线 cell 不能全选，而任 2 个可以。故「核超图」= 全部 (X) 三元组
（`N(X)=30,992,032`，由 `codegree_m37.py` 已枚举）。这层已彻底刻画。

**更深的核**（研究级，未做）：一组 cell 本身不共线，但其 2-因子度约束**强制**
某个共线三点组必被选（即无论怎么补全成 2-因子都撞冲突）。枚举这类需
对「2-因子 + 冲突」联立求解，等价于原问题的小规模实例，仅 m≤~12 可枚举验证。

**放电法**：给 cell 分配势能，沿冲突三元组放电；若总势能可做到非负、仅在特定
「好结构」处出现赤字，则可证存在。这是极值组合标准手法，但**需要巧妙的势函数**，
本问题目前**未知**。注意：已算出的 codegree 数据（`co3_max=1132`）正是放电论证
会消费的输入（每个核的「扩散度」）。

**诚实裁决**：#5 的「核超图」已是完全已知的 3100 万三元组；剩余工作是找放电势函数，
属长期研究项目，非近期判定手段。但它与 (c)/Graves 的 codegree 数据直接衔接，
是渐近存在性证明（"所有大 m"）最可能的归宿。
