## 1. 本轮最重要的新结果

从旧 best72 的完整 1-switch 因子邻域（1,221 个合法 2-switch）出发：

- raw codegree 排名前 30：真实定向搜索最好 80；
- 随机 30：最好 84；
- weighted cavity 排名前 30：找到 60。

随后使用独立 CP-SAT 模型对这个固定无向因子的全部方向做精确优化：

```text
status = OPTIMAL
objective = 60
best_bound = 60
Board.verify_total() = 60
```

所以 60 不是退火误报，而是该固定因子的全局最优方向值。

对应的下降链非常短且可解释：

```text
旧因子/旧方向：72
2-switch: 删除 (3,29),(16,30)，加入 (3,16),(29,30)：68
再翻转公共边 (15,34) 的方向：60
```

这证明因子变换与方向翻转应交替进行；把两层完全分开优化会漏掉有效下降方向。

## 2. 60 的局部冲突核

60 个坏三元组恰好分解为：

- 60 条三点直线；没有四点或更多点的坏线；
- 15 个 C4 轨道，每个轨道大小恰为 4；
- 等价地，基本域中还剩 15 个冲突轨道。

把每个冲突轨道投影到其涉及的 2-因子边，最小边击中集大小精确为 8。一个最小击中集为：

```text
(2,23), (4,31), (8,24), (8,25),
(12,36), (15,34), (20,25), (29,30)
```

这不证明必须改八条边才能得到解，因为方向翻转会改变冲突核；但它说明当前 15 个冲突并不集中在一两条边上，单次 2-switch 贪心很难直接清空。

## 3. 60 周围已经排查到什么程度

### 3.2 独立 SA 与精确复核

从 60 的完整一步邻域中，对 raw 前 40、weighted 前 40、随机 40 做独立真实目标 SA：

三个不同来源的 64 分候选又分别经 CP-SAT 证明固定因子的全局最优确为 64，并由 Board 独立核验。

### 3.3 多步远邻抽样

从 60 随机生成 1,500 个 1–8 次 2-switch 的因子：

- 随机组最好 80；

## 4. 对另一 agent 最新 BFS 的审计

最新已落盘的 `results/bfs_lm_batch.json` 是：

```text
n=12: found=false, best cost=4
n=14: found=false, best cost=4
n=16: found=false, best cost=6
```

这些记录自身没有伪造“找到解”；但负结果不能推出局部不可达，更不能推出不存在，原因是：

- BFS 只允许下一步代价 `c2 <= c+1`；
- targeted 版本只移动当前坏三元组涉及的行；
- 最大深度有限；
- 失败时不保存最低点的 `pi,sigma`，无法复现实验盆地。

仓库中已有独立验证为 `is_exact_ntil=true` 的 n=12 真解，而这个 BFS 仍停在 4。因此它目前连小规模“已知有解”基准都没有稳定穿透，不能给 m=37 提供障碍证据。

可保留的只有“最后一公里允许短暂上坡”的思想。若要迁移，应在 m=37 的 15 个 C4 冲突轨道上做 conflict-directed beam/LNS，而不是直接复用当前按行 swap 的实现。

截至本报告写入时，另一 agent 的新 `targeted_bfs_solver.py --batch 10,12` 仍在运行，结果文件尚未落盘。

## 5. 对另一 agent 最新 Gröbner 扫描的审计

最新刷新时 JSON 已记录约 47 次固定因子计算（推进到 `D4_L2`），全部得到 Gröbner 基含 1，即对应固定因子的方向多项式系统 UNSAT。对“实际被抽到的固定因子”，这个结论原则上是可靠的；但不能外推到整个 `(D,L)` 分层：

- 脚本约束是 `D<=max_d, L<=max_l`，不是指定精确 `D,L`；
- `D3_L1`、`D3_L2` 的样本实际都是 `D=3,L=0`；
- `D3_L3` 实际是 `D=3,L=2`；
- `D4_L1` 有一个样本实际为 `D=3,L=1`，`D4_L2` 也出现 `D=3,L=0`，再次说明配置名只是上界标签；
- JSON 没有保存每个样本的边集，且 seed 使用进程相关的 `hash(config_name)`，无法独立复现原样本；
- 数十个随机固定因子 UNSAT 对巨大的因子空间没有覆盖证明。

更现实的是，当前精确 CP-SAT 定向器对本轮候选通常只需约 4–19 秒，并同时给出最优值、下界、方向见证和 Board 核验；Gröbner 每个样本约几十到数百秒，只给固定因子 UNSAT。就 m=37 搜索而言，当前 Gröbner 实现被 CP-SAT 严格支配。

Gröbner 路线只有在能产出“随因子族参数统一成立”的低次数 Nullstellensatz 证书或可解释代数不变量时才值得继续；继续随机抽固定因子意义很小。

## 6. 下一步最值得做的方向

### 主线：围绕 15 冲突轨道做联合大邻域

原先建议从 8 边击中集起步；精确 Hamming-ball 结果已进一步证明半径 0–12 全部不可行。因此新的 LNS 应直接从半径 13 起步：

1. 先选当前冲突超图的 8 边最小击中集，再补入至少 5 条“新冲突抑制”边；
2. 允许至少 13 个 selected cell 改变，跳过已经严格排除的半径 0–12；
3. 方向变量同时开放；
4. 用真实坏线 CP-SAT/Benders 求 `objective < 60`，找到即扩展，证明不可行则形成局部排除证书。

它比盲目增加随机样本更有希望，因为旧纪录的突破已经表明有效原子动作是“2-switch + 方向翻转”的联合块移动。

### 次线：有界越岭 beam

把已认证的 64、68 因子当作第一层父节点，只保留冲突核不同的多样化状态，再搜索第二个 2-switch。接受短暂上升到 64/68，但第二层必须低于 60。停止条件应是：

- 若多批独立 beam 都回不到 60 以下，扩大一次开放边集；
- 不继续把同一 weighted 分数当唯一排序；
- 每个新纪录必须立即用 CP-SAT 最优界和 Board 双重核验。

## 7. 当前判决

这是实质进展，但不是 m=37 解：

- 新的严格认证纪录：`72 -> 60`；
- weighted cavity 已证明能提供 raw 漏掉的邻域多样性；
- 60 周围不仅表现出局部刚性，而且已有精确 `distance >= 13` 证书；
- 下一阶段应从半径 13 的冲突核驱动联合 LNS 起步，而不是继续扩大无结构近邻搜索；
- 另一 agent 的 BFS/Gröbner 当前没有可直接合并为定理或 m=37 解的结果。
