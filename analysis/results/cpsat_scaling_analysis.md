## 2. 线约束数的解析公式

对 n×n 网格，含 ≥3 格点的直线数近似为：

$$L(n) \approx \frac{n^3}{\pi^2} \times 2 \approx 0.2026 \times n^3$$

（因子 2 来自正反两个方向）

实际数据：
- n=8: L=344, 预测=0.2026×512=104（3.3×偏低——方向枚举更密）
- n=10: L=800, 预测=0.2026×1000=203（3.9×偏低）

修正：实际 L(n) ≈ 0.8 × n³（n=8→410, n=10→800, n=12→1382）

用于 CP-SAT：每条线 1 个 ≤2 约束 = 800 约束 at n=10。

## 3. 解的存在性与 CP-SAT 性能

CP-SAT 的求解效率取决于：
1. **约束传播强度**：线约束提供强剪枝
2. **解密度**：合法配置占全空间比例

如果解密度随 n 指数下降，则 NP-hard-like 行为。但从 n=8/10 都秒解看，小 n 上解密度高。

### 关键实验：n=12 的时间

如果 n=12 ≤ 60s → 子指数 → n=74 可能在 10³-10⁴s 内解（10-100min）。
如果 n=12 > 300s → 超线性 → n=74 可能需要数小时到数天。

## 4. 与已知 NTIL 构造的关系

已知最优构造（非对称）：
- n≤46: 已知 2n 解（镜像法、模素数法）
- n=52,56,...,72: 已知 2n 解（Heule 2026 rot4）
- n=74: 未知（本文 focus）

CP-SAT 模型属于完备搜索——如果 n 存在 2n 解，CP-SAT 会找到（在无限时间下）。

## 5. 优化方向

若 n=12-20 呈超线性增长，可尝试：
1. **对称破缺**：强制 π(0)=0（消除 n 个对称性）
2. **加热启动**：从小 n 解通过插值扩展到大 n
3. **增量构造**：从 n-2 解添加两行两列
4. **可行解注入**：用已知 rot4 或对合解作为初始猜测
