## 1. 统计力学 / 聚合物气体（Cluster Expansion · Pirogov-Sinai · Kotecký-Preiss）★ 最该立刻试

**为什么"不相关"**：这是凝聚态物理 / 量子场论的工具，用来证明晶格气体低温相的存在性。

**怎么映射**：把"(X)-free 的 2-因子"建模为一个**硬核聚合物气**。
- 聚合物 = 冲突依赖图上的极大连通块；
- 活动量 `w(P)` = 该连通块的权重；
- 收敛 ⇒ 存在唯一的"空态"（没有任何 bad event 被触发）⇒ 一个合法解存在。

**关键洞见（直接利用已发现结构）**：对称 Shearer 界失败，是因为它强制所有事件同权。但**非对称 LLL / Kotecký-Preiss 准则允许异质权重**——给 666 个极端匹配对极小活动量 ε，给普通边较大活动量 α。因为极端对互相独立（匹配）、且只与有限个普通边共现，收敛半径判据 `Σ_{P∋γ} w(P)·e^{Σ_{Q~P}w(Q)} ≤ 1` 对极端事件一侧可以轻松满足。

**可立刻落地的一步**：实现**两档权重的非对称存在性检验**——
1. 用实际冲突超图（m=37, N=30,992,032）构建依赖图；
2. 给 666 个极端事件赋极小 `x_i`，普通事件赋适中 `x_i`；
3. 解非对称 LLL 不等式 `p_i ≤ x_i·Π_{j~i}(1−x_j)`（或跑 Kotecký-Preiss 级数）。
4. 若通过 → **非构造性地证明 m=37 必有解**，反向给 csearch2 / SAT 搜索以"解一定存在"的理论背书。

**置信度：高**（直接吃下"匹配结构"这口低垂果实，且绕开了对称界的失败）。

## 2. Gale 变换 / 有向拟阵（凸几何）

**为什么"不相关"**：经典计算几何 / 凸几何工具，NTIL 文献几乎不用。

**怎么映射**：4m 个点的"三点共线" ⟺ 其 Gale 对偶点的某种线性/凸包关系（Radon 划分）。把二次 incidence 重述为**凸位置条件**，可能更易用概率/壳化论证处理。

**诚实 caveat**：2D 点集的 Gale 对偶落在 `4m−3` 维，**维度不降反升**，所以实用收益不确定；但它把 (X) 变成"Gale 点凸包不含某结构"，可辅助 #1 / #4 的论证框架。

**置信度：中**（理论优雅，计算收益待验证）。

## 3. 组合 Nullstellensatz / Alon-Tarsi（代数组合）

**为什么"不相关"**：把存在性变成"某多项式最高次单项系数非零"的代数判定。

**怎么映射**：2-因子 + 取向可写成某棋盘多项式 / 横截式；(X) 禁位 = 消去某些单项。若 max-degree 单项式系数在特征 p 下非零，CNT 直接给出存在性。

**置信度：中**（难点在找到合适的多项式与次数分配，可能很硬）。

## 4. 迭代吸收法（Iterative Absorption · Kühn–Osthus / Montgomery）

> 你的路线图已提过 "absorption"，这里补具体抓手。

**怎么映射**：在 2-因子空间里构造"吸收器"小簇，预留 reservoir；先随机铺掉绝大部分，再用 reservoir 把剩余吸收成合法解。

**含金量**：Keevash 设计存在性 (2014)、Kwan–Sah–Sawhney–Simkin 的 semirandom / resilient 方法都用此路线，专门对付"带禁位的张成子结构"。

**置信度：中高**（构造性，但工程量大）。

## 5. 热带几何（Tropical Geometry）

**为什么"不相关"**：把 `det≠0` 的二次约束 tropicalize 成**分段线性超平面排布**。

**怎么映射**：在热带半域上解 (X) = 线性规划 / 拟阵问题，再做 tropical→classical lifting。

**置信度：低中**（优雅，实用未知）。

## 12. TRIAL LOG（实际跑过的验证，2026-07-15）

### #1 非对称 LLL / 集群展开 — **FAIL（结构性）**
- 实验 `asymmetric_lll_m37.py`：在**真实 2-因子概率空间**（uniform random 2-regular graph on {0..m-1}）蒙特卡洛 1500 样本。
- 复现 nX=30,992,032 超边；依赖度 d(e) 均值 ~206k、最大 ~263k（deg1_max=92,488）。
- `p_e`（3 特定 cell 同时选中）均值 1.2e-5、最大 2e-3。
- 对称 LLL 判据 `p_e·e·(d+1)≤1`：实测 LHS 最大 **1080 ≫ 1**。逐超边最优非对称（2 档权重）仍差 **~1430×** → 不可行。
- **结论**：LLL 家族（对称/非对称）在 2-因子空间**无法证明**冲突自由 2-因子存在；`d(e)~263k` 是 2-因子耦合固有结构（每经过热 cell 的超边共享约 26 万邻居），**不是对称界太粗的假象**。666 转置匹配对仅占其零头，无关。
- 严谨性：LLL 失败只是"该充分判据不够"，非证明 m=37 无解；但 1430× 差距意味着细化 LLL 无望。→ 转向重塑搜索空间的工具。

### #2 Gale 变换 — **FAIL（局部等价在真实数据上不成立）**
- 实验 `gale_probe_m10.py`：用已验证 m=10 解（40 提升点）算 Gale 变换（ℝ³⁷）。
- 真解 Gale 点无相关三元组（min SV=0.857，与 bad_X=0 一致）。
- **但**刻意构造的共线三元组 (0,1,2) **未**产生相关 Gale 三元组（SV=0.928，秩 3）。
- → 朴素局部等价"3 点共线 ⟺ 3 Gale 点线性相关"**在本题点型上不成立**。Gale 真正内容是全局 Radon/Tverberg 凸划分，不形成结构化 2-因子搜索的局部约束集；也不缩减约束数（m=37 时 C(148,3)≈54 万 vs 原始 3100 万超边，仅因原始碰撞合并）。
- **结论**：Gale 理论漂亮但**对本攻坚实用杠杆低**，建议降级为"可选全局凸体存在性论述语言"，不作为计算杠杆。

### #4 迭代吸收法 / 手术法 — **FAIL（被 C4 抬升的棋盘尺寸依赖钉死）**
- **先发现假阳性（关键）**：`results/m37_surgery_result.json`（2026-07-13，声称 `m=37` 经 `split` 解出）被**独立暴力验证为假阳性**——2-因子合法、148 点互异，但有 **248 个共线三元组**。根因：v1–v3 的 (X) 检查有 bug（v5 文件头明写 "CORRECT incremental collinearity check"），假阳性 JSON 正是 bug 版所写；v5 修正后单一种子+受限 k-switch 找不到解 → m=37 仍 OPEN（与全部前提一致）。**该 JSON 应 quarantine，勿误读为已解。**
- 已存在 `surgery_m36_to_37.py`–`v5.py` 共 5 版，正是 #4 思路；v5 为修正版但**仅用单个 m=36 种子**。
- **正确测量 `absorber_m37.py`**（用精确 line_cons 做 (X)-检查，不用 bug 版）：对种子的 36 个切分，正确 (X)-成本 min=32、中位 60、最大 92（仅计"新点涉及的违规"）。
- **但核心已崩**：`check_seed_board_dependence.py` 实证——同一批 m=36 种子 cell 在 **N=72 抬升下 0 共线**（合法 m=36 解），在 **N=74 抬升下 188 共线**。朴素手术法把 m=36 的 cell 坐标直接复用到 N=74 板，核心本身已 ~188 违规；任何切分（再加 32）都不可能 (X)-free。
- **结论**：#4（朴素手术/吸收）被 **C4 抬升对棋盘尺寸 N 的依赖** 根本性 obstructed。正确做法（在 N=74 上重优化 cell）会**退化为 csearch2 已在做的同一道 2-因子硬搜**，"从 m=36 扩展"框架不提供额外杠杆。→ #4 实质上已证伪（naive 版），非开放步。

### 余下候选的即时评估（基于 #1/#2/#4 教训）
- #3 组合 Nullstellensatz / Alon-Tarsi：需构造恰当多项式+次数，难以直接"跑"出存在性；且 #1 已表明 2-因子空间依赖极密（d~263k），代数存在性判据大概率同样被压制。→ 低优先。
- #5–#9（热带/多项式法/Cap set/熵压缩/谱方法/拓扑）：在 #1/#4 负结果光照下，凡依赖"低依赖度/局部约束/可复用小解扩展"的都受同一结构性障碍牵制（依赖度墙 + 棋盘尺寸依赖）。拓扑/多项式法属不同机制，可作远期探索，但非近期主攻。
- **当前总判断**：已试的 #1(LLL)、#2(Gale)、#4(吸收/手术) 三大方向**全部失败**，且失败原因互相独立、共同指向 m=37 的结构性难度（2-因子全局耦合 + 棋盘尺寸依赖）。剩余工具 (#3,#5–#9) 预期杠杆更低。建议：把精力从"找新工具"转向 (a) 让 csearch2 在 N=74 上长时运行 / 多起点，或 (b) 承认并形式化"m=37 是 rot4-NTIL 的相变点"这一经验结论。
