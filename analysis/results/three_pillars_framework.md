# NTIL 三大新工具框架

2026-07-21 深夜。基于当天全部实验教训 + 理论积累的最终战略判断。

## 一、Radon–Birkhoff 多尺度整数化（优先级 50%）

### 核心思想
- 连续松弛 A⁰_xy = 2/n 完美满足所有行列和 + 所有 Radon 线 ≤ 2
- 问题纯粹是：如何把 {0, 2/n} 的分数值推到 {0, 1} 而不让任何 R_ℓ 从 ≤2 跳到 3
- 工具：沿二分图交替环舍入（保持行列和），同时按线长 L 分层控制 discrepancy

### 最小 PoC（立即执行）
n=8 起：从分数矩阵出发 → 贪心找交替环 → 推最大 ε → 迭代至 {0,1}。检查是否违反 R_ℓ ≤ 2。

关键度量：
- 每轮有多少"危险线"（R_ℓ 接近 2）
- 剩余分数变量数与危险线数之比（自由度是否够）
- 长线 L≥n/2 是否总能在早期冻结

## 二、p-adic 行列式分离码（优先级 30%）

### 核心思想
- carry 消除共线但 y 越界 → 真正解法不是弃用 carry，而是把 carry 编码进坐标自身的位展开
- x = Σ x_i · B^i，y = F(x) 同样位展开
- 三位一行列式的 p-adic 估值：找最低非零位，若该位 ≠ 0 mod p → 整数行列式 ≠ 0
- 需要构造"有限状态 carry 自动机"——每个数位要么消除共线，要么传递残余状态

### 最小 PoC
B=2 (二进制)，n=8 (3 位)。构造两个位排列 F₀, F₁ → 对随机三元组检查 p-adic 最低非零位。

## 三、多模数行列式筛（优先级 20%）

### 核心思想
- 每个非零整数行列式 |Δ| ≤ (n-1)²
- 若 p | Δ，则 p ≤ (n-1)²
- p>n 的大素数至多一个能整除同一 Δ（因为两个乘积超界）
- 从有限平面弧理论导出 T_p(S) 下界 → 若 Σ_p T_p(S) log p > (组合预算) → 不存在

### 最小 PoC
对 n=74，列出所有 p>74，计算 C(148,3) ≈ 530K 三元组 / (p 整除行列式) 下界。

## 三大工具的互馈

- **RB 舍入** 失败 → 产生对偶证书 → 喂给**筛子**验证不存在
- **筛子** 说某些 n 不存在 → 缩小目标 → **p-adic** 仅需构造无限子序列
- **p-adic** 成功给出一族显式解 → 喂给**RB 舍入**作初始点加速
