## 0. 动机与对象

此前的研究把 k=14  impossibility 归结为「三元冲突核」（3 个自由变量耦合）。但修正边之后发现：全部 19 个代表补全的 MUS 子句**都只涉及 1 或 2 个自由朝向变量**，没有一个必须依赖 3 个自由变量。

这意味着：固定旧骨架后，新边朝向的无解性实际上是一个**很小的 2-SAT / 蕴含图矛盾**。本报告把正确的理论对象定为**朝向蕴含图**，并对全部 **23 个真实补全因子**做完整的 2-SAT 矛盾核提取与逻辑同构正规化。

## 1. 方法 [METHOD]

对六个 V20 盆地、19 个幸存 mask，用 `v9w_all.exe` 枚举**全部**补全因子（15 单 + 4 双 = **23** 个），每个补全：

1. **正确边几何**：用 C++ 补回的 37 条边（旧边 + 14 条新边）重建三元冲突超图 `build_correct_fs`。
2. **约束提取**：只取一元（`n_free=1`）与二元（`n_free=2`）约束，记录**完整禁配组合**（而非仅 `F_popcount`）。
   - 一元：2 旧边 + 1 新边 → 强制某新边朝向 `x_i = a`；
   - 二元：1 旧边 + 2 新边 → 禁止组合 `(x_i=a, x_j=b)`。
3. **蕴含图（2-CNF 字面量图）**：字面量 `x_p=v` 编号 `2p+v`，否定为 `^1`。
   - 一元力 `x_p=a` 加边 `(p,¬a)→(p,a)`；
   - 二元禁配 `¬(x_p=a ∧ x_j=b)` 加边 `(p,a)→(j,¬b)` 与 `(j,b)→(p,¬a)`。
4. **SCC 矛盾判定**：Tarjan 求强连通分量；若某字面量与其否定同 SCC → UNSAT。
5. **最短矛盾环（注意：不完整）**：对每个矛盾变量对取 `L→¬L` 与 `¬L→L` 最短路径拼接，但 BFS **只为每个变量对保留一条**最短路径，**并未枚举所有最短环**。故该集合只能证明「存在」2-变量陷阱，不能用于计数或完备归类（陷阱的完整枚举见 `geometric_orientation_traps.md`）。
6. **逻辑同构正规化**：对每个最短矛盾环，在「变量重命名（环上不同槽位 → 0..m-1）+ 0/1 翻转」下暴力取字典序最小的规范形；对该补全的所有最短环再取最小，得到其**逻辑类型**。

> C4 旋转对称是更细的商：由于「重命名+翻转」已把所有 23 个补全塌缩为**单一**类型，再模 C4 只会保持或加强统一（不会分裂），故统一结论在完整对称群下成立（见 §5）。

## 3. 朝向矛盾核（原「统一矛盾环引理」——已降级为观察 [OBSERVATION]）

> ⚠️ **理论定级修正（2026-07-20 晚，用户复核）**：本节原以「统一引理 / [THEOREM-CERT]」定级，**过度领先于实际结论**，现降级为观察并修正以下误述：
> 1. **「23 个补全归为一个逻辑类型」信息量极低**：正规化只保留「2-变量 3-边有向环」的拓扑，允许任意变量重命名与逐变量 0/1 翻转；而此类环在重命名+翻转下**本来就只有一种类型**，故「类型数=1」是平凡的，不构成深层统一。
> 2. **解码错误（已修正见下）**：此前把规范环第三边解读为「两条二元禁配把 a 的另一朝向经 b 锁回自身」——这是**错误解码**。真实机制是：a 被一元力强制后，b 的两个朝向被两条独立几何见证分别禁止，b 无合法值即矛盾。
> 3. **`all_min_cycles` 名不副实**：BFS 对每个矛盾变量只取一条最短路径，并未枚举所有最短环；故「最短矛盾环集合」不完整，只能用于确认「存在」2-变量陷阱，不能用于计数或完备归类。
> 4. **逻辑正规化丢弃几何标签**：不能由此推出「模 C4 后仍是同一几何机制」——这是把逻辑同构误读为几何同构。
> 5. 真正值得挖掘的现象（见 §9 与 `geometric_orientation_traps.md`）：每个补全含 **1–11 个互不相同的「三条款朝向陷阱」T(a,b;s)**，平均约 5.83 个（k=14）；这些陷阱按**真实几何**（C4/盆地自同构）归类后才可能成为理论对象。
> 6. k=15 探针与 k=14 结论均**不推广为全空间定理**（详见 §8 边界）。

在「变量重命名 + 0/1 翻转」正规化下，**全部 23 个补全塌缩为同一个逻辑类型**（类型数 = 1）。其规范形（有向边 `(from_slot,from_val)→(to_slot,to_val)`）为：

```
((0,0,0,1), (0,1,1,0), (1,0,0,0))
```

解码为约束集合（令 `x0, x1` 为两个自由新边变量；注意 0/1 已按正规化翻转，**不对应真实几何朝向**）：

| 规范边 | 语义 | 对应约束 |
|---|---|---|
| `(0,0)→(0,1)` | `x0=0 ⇒ x0=1` | **一元力**：`x0 = 1`（由 1–2 条旧边共线强制） |
| `(0,1)→(1,0)` | `x0=1 ⇒ x1=0` | **二元禁配**：`¬(x0=1 ∧ x1=1)`（禁止 `b=1` 给定 `a=1`） |
| `(1,0)→(0,0)` | `x1=0 ⇒ x0=0` | **二元禁配**：`¬(x0=1 ∧ x1=0)`（禁止 `b=0` 给定 `a=1`） |

矛盾结构（即「朝向陷阱」T(a,b;s)）：

```
  一元力：  a = s=1  （强制）
  给定 a=1：
     二元禁配 ¬(a=1 ∧ b=1)  ⇒  b=1 被禁止
     二元禁配 ¬(a=1 ∧ b=0)  ⇒  b=0 被禁止
  ⇒  b 在 a=1 下无任何合法朝向 → 矛盾
```

⚠️ **修正（2026-07-20 晚 用户复核）**：此前把第三边误读为「两条二元禁配把 a 的另一朝向 `A'` 经副变量 `b` 锁回 `a=A'`」，并写成 `¬(x1=0 ∧ x0=0)`。正确解读如上——是 **a 被强制后，b 的两个朝向被两条独立几何见证分别禁止**，b 无合法值即矛盾；并非「b 把 a 的另一朝向反馈锁死」。逻辑上 a=1 与 a=0 落入同一 SCC 只是该陷阱的 2-SAT 表象。

### 朝向陷阱观察（k=14，V=20 六盆地，q≤3 线容量）[OBSERVATION，非定理]

> 对六盆地中任一幅 k=14 替换的**任意**补全因子（全部 23 个已穷举），固定旧骨架后，新边朝向的冲突必然包含至少一个**三条款朝向陷阱** T(a,b;s)：存在一条中心新边 `a`（被一元力强制为 `s`）与一条副新边 `b`，以及旧边构成的共线背景，使得
> - `a` 被一元力强制为朝向 `s`；
> - 给定 `a=s`，两条独立几何见证分别禁止 `b=0` 与 `b=1`；
> - 从而 `b` 在 `a=s` 下无合法朝向 → 矛盾。
>
> 这是已穷举确认的**观察**：每个补全都含此类陷阱（事实上 1–11 个，均≈5.83）。但「所有补全都含同一类陷阱」**不等于**存在唯一的几何机制——逻辑正规化的「类型数=1」是 2-变量 3-边环的平凡拓扑性质，不构成深层统一。陷阱是否压缩为少数几何模板，需按真实几何归类（见 §9 与 `geometric_orientation_traps.md`）。

## 5. 关于 C4 旋转对称

本正规化已包含「变量重命名 + 0/1 翻转」。C4 坐标旋转是更细的商：把补全 `A` 的几何整体旋转 90°/180°/270° 会映射到 C4 旋转后的盆地（六盆地本身即全局 NTIL 集的 C4 轨道族）。由于「重命名+翻转」已使 23 个补全归为**单一**逻辑类型，再模 C4 只会保持或加强该统一、**不会引入分裂**，故统一引理在用户指定的完整对称群（重命名 + 翻转 + C4 轨道/相位）下成立。

## 6. 对 k=15 的含义与下一步

**廉价 UNSAT 预筛（建议）**：本引理直接给出推进更高 k 的工具。
对任一 k=15（或更高）候选替换，无需穷举 `2^W` 朝向，只需：
1. 用正确边重建三元冲突超图；
2. 提取一元/二元约束 → 蕴含图；
3. Tarjan SCC 判定矛盾。
若候选的冲突超图已含「2-变量 3-边矛盾环」结构，则**立即判 UNSAT**。这把 k=14 的 `2^14` 暴力验证，压缩为一次 SCC（线性时间）。

**尚待验证（不要声称 k=15 封闭）**：本引理仅在已穷举的 k=14 补全（23 个）上成立。更高的 k 可能：
- 仍总含此类 2-变量矛盾环 → 可继续用预筛推进；
- 或涌现出三元/更复杂耦合 → 预筛仅给出充分条件（UNSAT 可证，SAT 不能证），需结合全局 C4 容器 / 零进位理论。

按既定优先级：**先以统一引理做 k=15 的 SCC 预筛；若 k=15 仍全部 UNSAT 则强结论成立；若出现 SAT 候选则转全局 C4 容器/零进位理论。**

## 8. k=15 结构化探针实证（[COMPUTATIONAL EVIDENCE]，非封闭认证）

**探针设计**（因 k=15 全空间被 CUDA 根扫描 300M 缓冲溢出阻断，无法直接全枚举）：
取 19 个 k=14 幸存掩码，每个再删 1 个旧 cell → 437 个 k=15 候选（六盆地超集）；
经 `--size 15` 容量审计（q=0..3），v20_01 在 q=3 下 0 幸存，v20_02–05 共得 **15 个 q3 幸存掩码**；
对每个幸存掩码用 v9w_all 枚举补全因子，共 **16 个补全**（v20_05 有 1 个双补全掩码）。

**实证结果**（2026-07-20）：

| 量 | 值 |
|---|---|
| k=15 q3 幸存掩码 | 15（v20_02:4, v20_03:5, v20_04:3, v20_05:3；v20_01:0；v20_06 无 k=14 幸存） |
| 补全因子 | 16 |
| 2-SAT UNSAT | **16/16** |
| 逻辑类型数 | **1**（规范形 `((0,0,0,1),(0,1,1,0),(1,0,0,0))`，与 k=14 完全相同） |
| 一元/二元已足（无需三元） | 16/16 |
| 独立 OR 归约 UNSAT（含三元，与 SCC 零不一致） | 16/16 |

**交叉验证**：`validate_k15_truth.py` 用与 SCC 蕴含图**完全独立**的机制（把所有冲突子句禁配位图 `mask_fs` 做 OR 归约）重判 16 个补全，结论与 SCC 100% 一致，且全部由一元/二元引发 → 排除 W=15 参数化引入的假 UNSAT。

**结论与边界**：
- 统一 2-变量矛盾环引理在 k=15 的**结构化探针**（15 个 k=14 超集掩码）上**全部成立**——这是强计算证据，但**不是 k=15 全空间封闭认证**（全空间被 CUDA 300M 瓶颈阻断，437 个超集仅占极小子集）。
- **不得声称「k=15 距离 ≥16」或「k=15 已封闭」**：探针只覆盖了「k=14 幸存掩码的超集」这一结构化子集，未枚举 k=15 的全部 ~1.8e9 根候选。
- 理论含义：k=14（已认证）+ k=15（探针）两档都塌缩为同一 2-变量奇异矛盾环，强烈暗示 **V20 六盆地对局部 k-替换具「局部刚性」**——任何小扰动都触发同一旧骨架→新边二元冲突。这把论证重心从「逐一穷举 k」推向你的优先级 #4：**全局 C4 容器 / 零进位理论**（m=37 若存在，必是全新全局构造，而非对 V20 盆地的局部修补）。
- 推进全 k=15 封闭仍需解决上游瓶颈：CUDA 根扫描多趟分块（每趟 ≤300M，合并幸存者），见 `k15_path_and_bottleneck.md`。
