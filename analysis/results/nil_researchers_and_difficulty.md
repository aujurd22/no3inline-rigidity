# NTIL 问题：为什么这么难推进 + 主要研究人员

> 写于 2026-07-15。背景：我们卡在 rot4 对称子问题的 m=37（=n=74）实例上。
> 本文回答两个问题：(1) 为什么推进这么难；(2) NTIL 领域的主要研究者有哪些、现在谁在活跃。
> 注：渐近上界/下界均为**猜想或已证构造**之分，凡未证者均明确标注。

---

## 一、为什么推进这么难

### 1.1 它本身就是个百年公开问题
- **提出**：Henry Dudeney 1917（8×8 棋盘特例 "A puzzle with pawns"）。
- **平凡上界 2n**：鸽巢原理，每行/列至多 2 点。
- **已知精确 2n 解**：对所有 n ≤ 46，以及 n = 48, 50, 52（Flammenkamp 推到 n=52，这是目前记录）。**n > 52 全部未知**。
- **渐近下界（已证构造）**：Erdős(经 Roth 1951) 模抛物线 ~(1−ε)n；Hall–Jackson–Sudbery–Wild 1975 模双曲线 **3n/2 − o(n)**（至今未被打破）。
- **渐近上界（猜想）**：Guy–Kelly 1968 猜 c·n，原式 c=∛(2π²/3)≈1.874；Pegg 2005 指出 Ellmann 发现其启发式推理有误，修正为 c=π/√3≈**1.814n**。Green 则认为答案约 1.5n。
- **鸿沟**：最佳下界 1.5n 与猜想上界 1.814n 之间仍有巨大未知带，且"答案到底是什么"连共识都没有。

### 1.2 我们 rot4 子问题的特殊难度（已量化、障碍互相独立）
理论层面其实**已经收口**（SIRH 总定理 / Th-44）：rot4-NTIL ⇔ 2-正则图 + 每线 ≤2 + 取向，问题彻底降到有限 CSP。
剩下 m=37 这道坎，障碍已被我们逐个钉死，且**失败原因互不相同**——说明是问题本体的结构性难度，不是"工具没用对"：

| 障碍 | 实测 | 含义 |
|---|---|---|
| 原始冲突超图 | 30,992,032 条 (X) 超边 | 约束规模随 m 平方×立方增长 |
| 2-因子全局耦合 | 依赖度 d(e) 均值~206k / 最大~263k | LLL 家族结构性失效（非对称仍差 ~1430×）|
| C4 抬升的棋盘尺寸依赖 | 同种子 cell：N=72 下 0 冲突、N=74 下 188 冲突 | "从 m=36 扩展"手术法核心直接崩，退化成 csearch2 同款硬搜 |
| CDCL SAT | m≥17 在 33M 子句处 presolve 墙（UNKNOWN）| 编码规模超出 SAT 求解器可处理 |
| Gale 变换 | 局部"3 共线 ⟺ 3 Gale 点相关"在真实数据不成立 | 不能把 (X) 重述成更干净的局部约束 |
| 迭代吸收/手术 | 被棋盘尺寸依赖钉死（见上）| "扩展框架"不提供额外杠杆 |

**本质**：解空间是 0 维离散、全局耦合、无代数闭式——剩下的障碍是**计算搜索在尺度上的困难**，不是"理论没想清楚"。
**经验证据**指向"解大概率存在但极难构造"：源占比 ~0.26、最长圈 ~0.79m、m=36→37 约束密度连续无突变（不在相变点）。所以"推进难"≈"算力/搜索难"，不是"证明难"。

### 1.3 跨领域"神奇工具"已穷举试过
- #1 非对称 LLL / 集群展开 → FAIL（依赖度墙 d~263k，结构性）
- #2 Gale 变换 → FAIL（局部等价不成立，低杠杆）
- #4 迭代吸收 / 手术 → FAIL（棋盘尺寸依赖）
- 余下 #3 Nullstellensatz / #5 热带 / #6 多项式法 / #7 熵压缩 / #8 谱 / #9 拓扑：预期受同一结构性障碍牵制，边际收益低。

**结论**：再找新工具性价比低。正路只有两条——
(a) 给 csearch2 更多算力 + 多随机起点长时间跑（它本就是正确框架，只是尚未收敛到 0）；
(b) 把"m=37 是 rot4-NTIL 的相变点 / 解存在但极难构造"形式化成一份经验结论文档。

## 二、NTIL 主要研究人员

### 2.1 历史 / 经典（按贡献）
- **Henry Dudeney (1917)**：问题提出者（8×8 特例）。
- **Paul Erdős**（经 Roth 1951）：模抛物线 (i, i² mod p) 下界 ~(1−ε)n。
- **Guy & Kelly (1968)**：经典论文；给出渐近上界猜想（后修正为 ~1.814n）。
- **Hall, Jackson, Sudbery, Wild (1975)**：模双曲线 xy=k mod p 构造，**最佳下界 3n/2−o(n)**（至今未破）。
- **Woodall (1978)**：用有限射影平面构造，把 2n 解推到许多 n。
- **Adena, Holton, Kelly (1974)**：早期推进。
- **Achim Flammenkamp (1992, 1998)**：**计算枚举之王**，把精确 2n 解推到 n=52；他的对称分类（rot4/rot2/iden/dia1/dia2/ort1/ort2/rct4/full）正是我们工作的对称类来源。
- **Brass, Moser, Pach**：《Research Problems in Discrete Geometry》把 NTIL 列为"最古老、研究最透彻的格点几何问题之一"。
- **David Eppstein**：ILP / 回溯专著性工作，系统整理计算途径。

### 2.2 近期活跃（2024–2025）
- **Kovács, Nagy, Szabó**（ELTE 布达佩斯，arXiv:2502.00176, 2025）：证明 **no-(k+1)-in-line 答案为 kn，当 k > C√(n log n)**。这是对推广型的重大突破（虽非 k=2 本体，但机制直接相关，是近年最硬的结果）。
- **Thomas Prellberg**（Queen Mary 伦敦）+ Ramanathan, Lewis（QMUL）+ Joshi, Dandekar 等（Vizuara AI）（arXiv:2512.11469, 2025）：首次系统比较 **ILP vs AI（PatternBoost / PPO）**；ILP 可证最优到 19×19，AI 在小实例有竞争力。我们引用的 CP-SAT 对称约化（arXiv:2602.07751）即出自此线。
- **Dong Zichao (IBS), Xu Zijian (北大)**（arXiv:2506.18113, 2025）：网格子集无 d+2 共球/共线，改进 Erdős–Purdy 下界——把 NTIL 视为更一般的格点子集问题。
- **Ben Green**：公开认为答案约 1.5n（偏向 Hall et al. 构造是渐近真相）。

### 2.3 我们的位置
- 我们做的是 **rot4（C4 旋转对称）NTIL 子问题**，m=37 对应 n=74。主流不专攻此对称类。
- 与我们**最直接相关**的两条线：Flammenkamp 的对称分类（数据/枚举）+ Prellberg 的 CP-SAT 对称约化（计算框架）。
- 我们**原创贡献**（主流未覆盖的角度）：SIRH 总框架 + Th-44，把 rot4 子问题彻底代数化为"2-正则图 + 每线≤2 + 取向"的有限 CSP，并证明了单向刚性链。这是从对称约束反推代数结构的独特切入点。

---

## 三、一句话总结
NTIL 是 1917 年至今未决的公开问题；我们卡住的 m=37 不是"理论没想清"，而是 rot4 子问题在相变尺度上的**计算搜索困难**——跨领域工具（LLL/Gale/吸收）已各自因独立的结构性原因失效。领域当前前沿在渐近界（Kovács–Nagy–Szabó 的推广型突破）与 AI×ILP 混合计算（Prellberg 线），而我们的 rot4 代数化是主流少有人走的岔路。
