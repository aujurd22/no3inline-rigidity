# m=37 独立续研：真实几何缺陷从 64 降到 48

## 1. 最终结果

得到一个新的 m=37 rot4 合法2-因子及取向：

- 37条边，所有37个顶点度数均为2；
- 展开后148个点互不重复；
- 精确几何坏三元组：**48**；
- 48条坏直线，每条恰有3点，最大共线点数3；
- 斜率 `+1/-1` 的坏三元组数：**0**；
- 完整148点暴力行列式枚举：48；
- 第二次独立重建的加权 Ising + CP-SAT：`OPTIMAL 48`。

这把此前可信最佳的64个几何坏三元组降低了16个，即下降25%。同时还得到一个独立的 `OPTIMAL 52` 因子。

注意：`OPTIMAL 48` 是说这个固定2-因子的取向子问题精确最优为48，不是证明所有 m=37 因子的全局最优为48，更不是 m=37 不可解证明。

## 2. 旧目标函数存在系统性偏差

旧模型对每组三个 cell/orbit 和8种取向只记录：该12点集合“是否存在”共线三元组。这个布尔条款模型对判定零解仍然有效，但不等于真实几何缺陷数。

关键问题是坏三元组可能只涉及两个 C4 轨道。若轨道 `i,j` 的某个取向产生一个坏三元组轨道，旧三变量枚举会把同一个二轨道冲突对每个任意第三轨道 `k` 再记录一次。在 m=37 时，它被重复罚

```text
m - 2 = 35 次。
```

因此：

- 一个真实的二轨道 C4 缺陷轨道只有4个几何坏三元组；
- 旧无权模型却可能把它计成35个违例；
- 三轨道缺陷通常计1个旧违例，对应4个几何坏三元组；少量模式可对应8个。

新48构型正好利用了这个差异：

- 真实结构为12个 C4 缺陷轨道：11个三轨道缺陷 + 1个二轨道缺陷；
- 真实几何计数为 `12 × 4 = 48`；
- 但同一取向在旧模型里被计为46个违例；
- 该因子的旧模型精确最优仍为17，所以旧搜索不会进入这个盆地。

这解释了为什么以最低条款数或无权条款违例为主目标长期卡在64附近。

## 3. 修正后的精确加权 Ising

对每个二轨道取向模式，记录其实际产生的坏三元组数 `w`；对每个三轨道模式也记录真实重数 `w`。所有模式在全反取向下仍成对且权重相同。

二变量互补对满足

```text
w * (1[s=a] + 1[s=-a])
= w/2 * (1 + a_i a_j s_i s_j).
```

三变量互补对满足

```text
w * (1[s=a] + 1[s=-a])
= w/4 * (1 + a_i a_j s_i s_j
           + a_i a_k s_i s_k
           + a_j a_k s_j s_k).
```

因此加入正确的二轨道项和几何重数后，真实坏三元组总数仍然是纯二次 Ising/weighted MaxCut；不需要引入三次变量。

我在每个测试因子上抽取100个随机取向，将加权 Ising 值与148点精确几何计数逐一比较，全部完全相等。

## 4. C4 缺陷的4整除定理

任一坏三元组在90度旋转下产生一个 C4 轨道。对于偶数阶网格，点集中没有网格中心；含3个点的集合不可能被180度旋转保持，因此坏三元组轨道不可能只有1或2个元素，只能有4个。

所以任意 C4 对称配置的坏三元组总数满足

```text
bad_triples ≡ 0 (mod 4).
```

这意味着64之后的可能改进是60、56、52、48……，不会出现63、55等结果。

## 5. 对角线约束变成外层因子不变量

早期的八个56缺陷因子都有斜率 `+1/-1` 缺陷。强制禁止这些模式后，八个因子的取向问题全部 `INFEASIBLE`；原408、404因子也同样不可行，而 m=36 真解控制组得到 `OPTIMAL 0`。

进一步化简发现：一个 cell 从 `(u,v)` 转置为 `(v,u)`，只会反射其 C4 轨道；两族对角线 `x-y=c` 与 `x+y=c` 的占用多重集保持不变。因此是否存在三点落在斜率 `+1/-1` 线上与取向无关，是2-因子本身的硬不变量。

这给出极便宜的外层筛选：统计每个因子的 C4 轨道在所有对角线上的占用，任何一条超过2点就直接淘汰，不必运行内层 SAT/Ising。

1. 从408/16无权因子附近的500个邻居出发，先得到两个无权 `V=14` 因子，对应真实56缺陷。

4. 九个近优因子的10950个唯一一步邻居中，发现43个对角完全安全的因子。
5. 将43个安全因子全部用真实加权几何目标排序，找到对角安全的 `OPTIMAL 56` 因子。
6. 在安全空间继续一层，找到3个新的 `OPTIMAL 56` 邻居，证明安全56不是孤点。
7. 再走一层，得到 **`OPTIMAL 48`** 和 **`OPTIMAL 52`**。
8. 从48/52继续检查99个对角安全邻居，最好回到 `OPTIMAL 52`，未发现44；48当前是一步邻域意义下的深谷。
