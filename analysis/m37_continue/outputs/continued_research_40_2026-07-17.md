# m=37 独立续研（二）：真实几何缺陷从48降到40

时间：2026-07-17 01:50（Asia/Shanghai）

源目录保持只读。源项目 `mega_sweep_escape` 在01:49的 checkpoint 为 trial 48100、最低条款数404、历史无权违例16、`breakthrough=false`。

## 1. 新纪录

从已验证的对角安全48缺陷因子出发，只重配3条因子边，得到新的 m=37 rot4 候选：

- 37条边，所有37个因子顶点度数均为2；
- 展开后148个点全部不同；
- 精确几何坏三元组：**40**；
- 40条坏直线，每条恰含3点，最大共线点数3；
- 斜率 `+1/-1` 坏三元组：0；
- 完整148点三元组暴力行列式计数：40；
- 第二次独立加权 Ising/CP-SAT：`OPTIMAL 40`。

这里的 `OPTIMAL 40` 仍指该固定2-因子的方向子问题，不是全体 m=37 因子的全局最优性。

相对最初可信最佳64，真实几何缺陷减少24，即下降37.5%。

## 2. 40构型的结构

40个坏三元组在 C4 作用下组成10个缺陷轨道。10个缺陷轨道全部涉及三个不同的 C4 点轨道，没有二轨道缺陷；因此旧无权模型在这个因子上不再受到35倍二轨道重复惩罚：

| 指标 | 数值 |
|---|---:|
| 真实几何最优 | **40** |
| C4缺陷轨道 | 10 |
| 三轨道 / 二轨道缺陷 | 10 / 0 |
| 对角缺陷 | 0 |
| 旧条款总数 | 1068 |
| 该取向的旧违例 | 10 |
| 旧模型固定因子最优 | **10 OPTIMAL** |

这再次证明外层“最低条款数”方向错误：1068条的因子得到40个真实缺陷，而404/408条因子只能得到68/64。

## 3. 48到40是怎样找到的

48构型有12个缺陷轨道。其缺陷—因子边超图的覆盖前沿为：

| 可改因子边数 | 最多覆盖旧缺陷轨道 |
|---:|---:|
| 1 | 5 |
| 2 | 8 |
| 3 | 9 |
| 4 | 11 |
| 5 | 12 |

直接追求覆盖全部12个缺陷失败：

- 最小覆盖数为5，并存在5条互不相邻边的覆盖；
- 大小5的独立最小覆盖集只有6个；
- 其全部5670种端点配对中只有3个保持对角安全；
- 三个安全因子的最好可行值为72。

加入第六条缓冲边后：

- 125个独立边集；
- 1,299,375种端点配对；
- 977个对角安全配对、706个不同安全因子；
- 706个因子全部用增量加权模型扫描，最好仍为52。

真正成功的策略不是覆盖全部旧缺陷，而是“最大覆盖减1”：允许少保留一个旧缺陷，换取较少新冲突。

在2–4边修复中，覆盖阈值从最大值 `(8,9,11)` 放宽为 `(7,8,10)` 后：

- 148个候选边集；
- 9180种端点配对；
- 36个对角安全配对、23个不同安全因子；
- 找到只改3条边、覆盖8个旧缺陷的 **`OPTIMAL 40`** 因子。

完整覆盖需要至少6条独立因子边，比48构型的5条更分散。

完成的局部检查包括：

1. 原40因子的全部53个对角安全一步二交换，最好为 `OPTIMAL 48`。
2. 按“最大覆盖减1”枚举：379个边集、31161种配对、56个不同安全因子，最好为 `OPTIMAL 48`。
3. 按“最大覆盖减2”枚举：2424个边集、210096种配对、386个不同安全因子，找到第二个 `OPTIMAL 40` 和一个 `OPTIMAL 44`，但没有36。
4. 第二个40因子的全部80个对角安全一步邻居，最好为 `OPTIMAL 52`。

因此40不是孤点，但当前两个40盆地都没有一步到36的出口。

## 5. 负结果边界

以下路线在当前48/40邻域内已充分测试，不值得继续简单加样本：

- 随机选择2–5条互不相邻热边重配：200个远邻，最好52；
- 连续2-switch并最终修复对角：30个远邻，最好52；
- 48缺陷的五边全覆盖重配：全部5670种配对，安全结果很差；
- 48缺陷的六边缓冲重配：全部1,299,375种配对，706个安全因子无低于52；
- 40缺陷的2–4边最大覆盖、最大减1、最大减2修复：合计二十多万配对，没有36。

这些结果不是 m=37 的下界证明，只是明确排除了围绕当前缺陷超图做浅层直接修补的若干大类。

## 6. 新的理论认识

### 6.1 过度覆盖与FDR冲突

覆盖越多旧缺陷，保持对角安全的端点配对越少。48的五边全覆盖5670种配对只有3个安全，且几何值很差；稍微少覆盖一个旧缺陷，反而直接降到40。

所以外层修复目标不能是“击中尽可能多旧缺陷”，而应优化

```text
消失的旧缺陷轨道数 - 新产生的缺陷轨道数
```

并把FDR/对角安全作为硬约束。

### 6.2 改进使缺陷更分散

48的单条热边可触及5/12个缺陷；40的单条热边最多只触及3/10。下降到40后，残余缺陷分布更加均匀，这解释了为什么继续局部修复变难。

### 6.3 当前正确的状态空间

搜索节点应为“对角安全2-因子 + 其加权几何基态”，边为多边重配；节点代价是 C4 缺陷轨道数 `bad_triples/4`。当前已知平台包括：

```text
16轨道(64) -> 14轨道(56) -> 13轨道(52)
-> 12轨道(48) -> 11轨道(44) -> 10轨道(40)
```

其中40至少有两个不同盆地，但36尚未发现。

## 7. 下一步建议

1. 维护全部40/44/48精确档案点，做禁忌/路径重连，而不是只从最低40继续贪心。
2. 构造40盆地之间的最短安全路径，允许经过44/48山口，寻找第三类40盆地及36出口。
3. 将增量加权评估用于大规模beam：本轮706个六边候选的全量扫描已从数分钟降到88秒。
4. 理论上研究“缺陷超图覆盖与对角占用约束”的联合交换界，解释为什么完整覆盖通常破坏FDR。
