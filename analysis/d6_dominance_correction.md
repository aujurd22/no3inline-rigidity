# 纠错报告：D₆ 主导（Empirical Fact 1）是代码 bug 产物，并非事实

日期：2026-07-09
关联脚本：`analysis/d6_dominance_rigorous.py`（行枚举法，几何正确，brute-force 交叉验证）

---

## 0. 一句话结论

原"**≥89% 的超边涉及 D₆**"（hypergraph_theory.md 的 Empirical Fact 1，
以及由此支撑的"稀疏约束集中在 D₆""锋利杠杆头 = 稀疏性"等叙事）
**完全是 `collinear3` 函数的一个 bug 产物，不是真实的数学现象。**

正确测量后：D₆ 占比随 n **单调下降**（63%→28%，n=12→32），
**高斜率共线三元组反升至 72% 并成为主导**；低斜率(L) 恒为 0（由奇偶定理解析保证，与 bug 无关）。

---

## 1. Root cause：只查了 6 个点中的前 3 个

`hypergraph_structure.py` 与 `danger_hypergraph.py` 里的 `collinear3(six)`：

```python
def collinear3(pts):                 # pts = six，长度 6
    for a in range(3):            # ← 只遍历 0,1,2
        x1, y1 = pts[a]
        for b in range(a + 1, 3):
            ...
                if (x2-x1)*(y3-y1)==(x3-x1)*(y2-y1): return True
    return False
```

`six = [p_i, q_i, p_j, q_j, p_k, q_k]`（6 个轨道点）。
`range(3)` 只检查了 **(p_i, q_i, p_j)** 这 3 个点，**完全忽略了
q_j, p_k, q_k**。

后果：任何被判为"超边"的三元组，其实只要求 {p_i, q_i, p_j} 共线。
而 {p_i, q_i} 是一对**过中心的 Antipodal 点**，它们所在的直线必过中心、
方向必属 D₆（斜率 ±1 的对角）。于是被检出的"超边"几乎 100% 含 D₆——
这正是原代码报出"≥89% D₆ 主导"的唯一原因，**它测的是过中心的 antipodal
共线，根本不是真正的"三轨道共线约束"**。

### 用同一 bug 复算，得到与原报告一致的假象
| n | 残破 `collinear3` 检出的超边数 | 其中含 D₆ |
|----|----|----|
| 12 | 691 | **100.00%** |
| 16 | 2,746 | 94.39% |
| 20 | 6,325 | 96.68% |
| 24 | 14,456 | 94.18% |

→ 这串"94%~100% D₆"正是"≥89% 主导"声称的数值来源。假象完全可复现。

---

## 2. 正确测量（真超边 = 三不同轨道各出一点共线）

真超边定义：轨道三元组 {O_i, O_j, O_k}（三轨道互异），存在各自一个轨道点
共线于同一条网格线。用**线枚举法**计算（几何正确，独立于残破函数），
并用 brute-force（n=12 得 4,978，与线枚举完全一致）交叉验证。

| n | 真超边总数 | D₆ 占比 | 低斜率(L) | 高斜率(S) 占比 |
|----|----|----|----|----|
| 12 | 4,978 | **62.96%** | 0.00% | 37.04% |
| 16 | 18,760 | 52.90% | 0.00% | 47.10% |
| 20 | 51,386 | 41.50% | 0.00% | 58.50% |
| 24 | 116,080 | 36.71% | 0.00% | 63.29% |
| 28 | 230,070 | 32.74% | 0.00% | 67.26% |
| 32 | 414,712 | **27.87%** | 0.00% | **72.13%** |

- **D₆ 占比单调下降**，从约 63% 跌到约 28%；按趋势（方向总数 ~n²，
  D₆ 仅为固定 6 个，真超边分散到所有大斜率方向）**随 n→∞ 趋于 0**。
- **高斜率(S) 占比单调上升并主导**（n≥20 已超 50%，n=32 达 72%）。
- **低斜率(L) 恒为 0**：这不是 bug 假象，而是由**奇偶定理**解析保证的
  （偶数 n 的中心方向向量两坐标皆奇 → 归约后仍两坐标奇 → 不可能落在
  低斜率方向集 L；该定理不依赖任何代码，独立成立）。
- 过中心(cener-line)的真超边 100% 含 D₆，但数量极小（n=32 仅 1,160 / 414,712）。

---

## 3. 纠错后的正确定理陈述

**修正定理（D₆ 非主导）.** 在偶数 n 的 R180-归约超图 H_n^dir 中，
随 n 增大，真超边中涉及 D₆ 的方向占比 **严格趋于 0**；绝大多数约束来自
**高斜率（|a|>3 或 |b|>3）方向**，且其绝对数量随 n 增长。

这与旧的"稀疏约束集中在 D₆（故整体稀疏）"叙事**恰好相反**。

## 4. 对研究叙事的连锁影响（必须同步修正）

1. **推翻 Empirical Fact 1**：从 hypergraph_theory.md 撤回"≥89% D₆ 主导"。
2. **"锋利杠杆头 = 稀疏性（D₆ 主导 + 低斜率空性）" 是错的**：
   低斜率空性是真定理（但归因于奇偶定理，非 bug 代码）；D₆ 主导是假的。
   所以"约束稀疏"这一重构**不成立**——真实约束既稠密又分散于高斜率方向。
3. **讽刺性反转**：bug 曾被人用来支撑"约束稀疏 → 易解"的乐观叙事；
   **正确结论反而支撑"相变/阈值"悲观叙事**——约束压力随 n 增长且分散，
   这正与 n=58–72 的 C₄ 真空（解数塌缩）方向一致。
4. **连带失效的资产**：所有基于残破 `collinear3` 的"危险度""最危险方向"
   "cross-edge 阻断""超图密度缩放"等数值**全部无效**，需以真超边重算或弃用。
5. **低斜率空性（Empirical Fact 2）仍为真**，但应明确其证明来自奇偶定理，
   而非任何超图脚本的"验证"。
