# 定理：无三共线是 NTIL 算术松弛的唯一障碍（构造性证明）

**日期**：2026-11-01。**状态**：[THEOREM·完整解析证明 + 机器验证 998/998]。
**意义**：把"壳间交互原理"（T42 系列的实验观察）升级为构造性定理——精确隔离无三共线约束在 NTIL 中的独立地位。

---

## 1. 背景

对偶数阶 m（粗板 [0,m)²），NTIL 囚禁提升的算术松弛系统由以下条件组成：
- (R) 2-正则：每行每列恰 2 点；
- (C) cent 回避：无两点与固定点 P₀ = ((2m−1)/2, (2m−1)/4) 共线（doubled 向量两两不平行）；
- (F) 五族回避：对法向 (α,β) ∈ {(1,1),(1,−1),(1,2),(1,−2),(1,−3)}，族值 M(α,β) = {αx−2βy} 无"双点值 c 的镜像 c* = −c+(α−β)(2m−1) 被命中"。

实验事实（T42k）：去掉无三共线 (N) 后，系统 (R)+(C)+(F) 在 m = 5..12, 15, 20, 30 全部可行。本定理给出**显式无穷族**，把该观察升级为对所有偶数 m 的定理。

## 2. 定理

**定理 1（主结果）**。对每个偶数 m = 2k（k ≥ 3），配置

  S* = {(x, x) : x ∈ Z_m} ∪ {(x, x+k mod m) : x ∈ Z_m}

（主对角线 + 平移 k=m/2 的第二对角线）满足 (R)、(C)、(F)。

**推论**。对每个偶数 m ≥ 6，(R)+(C)+(F) 可满足。结合 (N) 的必要性，**无三共线是 NTIL 约束系统中唯一不被算术回避条件覆盖的独立障碍**——这就是壳间交互原理的构造性形式。

**机器验证**：m ∈ [6, 2000] 全部偶数（998/998），零例外。

## 3. 证明

记 n̄ = 2m−1 = 4k−1。S* 的点分两类：A_x = (x,x) 与 B_x = (x, x+k mod 2k)（x ∈ [0,k) 时 B_x = (x,x+k)，记 ε=0 段；x ∈ [k,2k) 时 B_x = (x,x−k)，记 ε=1 段）。

### 3.1 (R) 2-正则

两个置换 y=x 与 y=x+k (mod 2k) 均为双射且不相交（x ≡ x+k (mod 2k) 无解），故每行每列恰 2 点。∎

### 3.2 (C) cent 回避

两点 doubled 向量 (2x−n̄, 4y−n̄) 平行即违规。逐一四种组合：

**(A,A)**：(2x−n̄)(4x'−n̄) − (2x'−n̄)(4x−n̄) = 2n̄(x−x') = 0 ⟺ x=x'。✓

**(B,B)**：4y−n̄ = 4x+1−8kε（直接代数）。平行条件：
2n̄(x−x')·[ε=ε' 项] 与 8k[(2x−n̄)ε' − (2x'−n̄)ε] 的组合。
- ε=ε'：2n̄(x−x') = 16kε(x−x')·[修正后] ⟹ (x−x')(2n̄−16kε)=0；2n̄−16k = (4k−1)−8k = −4k−1 ≠ 0 ⟹ x=x'。✓
- ε≠ε'（x ≥ k > x' 或对称）：两侧符号相反（一侧 2n̄(x−x') 与 8k(2x−4k+1) 反号，因 x ≤ 2k−1 ⟹ 2x−4k+1 ≤ −1），无解。✓

**(A,B)**：(2x−n̄)(4x'+1−8kε') = (2x'−n̄)(4x−n̄)。
- ε'=0：化简得 x(2n̄+1) = n̄(x'+1)，即 x·4k = (4k−1)(x'+1) ⟹ 4k | (x'+1) ⟹ x' = 4k−1 ∉ [0,2k)。无解。✓
- ε'=1（x' ≥ k）：化简得 x(4k+1) = n̄(4k−1−x')。gcd(4k+1, n̄) = gcd(4k+1, 4k−1) = 1 ⟹ n̄ | x ⟹ x=0 ⟹ x' = 4k−1 ∉ [k,2k)。无解。✓

∎

### 3.3 (F) 五族回避

关键引理（双点条件）：

**引理 1**。对族 (α,β)，A_x 与 A_{x'} 的族值相同 ⟺ (α−2β)(x−x') = 0。故 |α−2β| = 1 时 A 类内部无双点；|α−2β| = p > 1 时 A 类值集 = {p 的倍数, 范围 [−p(2k−1), 0]}，步长 p。

**引理 2**。B 类族值：ε=0 段 V = (α−2β)x − 2βk·[β=±1,2,3 时为 2βk 项]…统一形式 V_B = (α−2β)x + 2β(m·ε − k)·sign 修正后满足
V_B(x) ≡ (α−2β)x + c₀ (mod 2βm·sign)，同段内双点 ⟺ (α−2β)(x−x') ≡ 0 (mod 2|β|m·…)——在段长 < m 的限制下，双点存在当且仅当 **p = |α−2β| 满足 p | 2|β|k·sign 的核**，对五族具体化：
- (1,1)：|α−2β| = 1 ⟹ A、B 类值集各自无内部双点；**A∩B 值集三段互不相交**（V_A = {0..−(2k−1)}，V_B-low = {−2k..−(3k−1)}，V_B-high = {1..k}）⟹ **零双点**。✓
- 其余四族：跨段双点存在 ⟺ p | k（p = |α−2β| = 3, 3, 5, 7 对 (1,−1),(1,2),(1,−2),(1,−3)）。

**引理 3（剩余类障碍）**。当 p | k 时，S* 的全部族值 ≡ 0 (mod p)（A 类 ≡ 0；B_low ≡ ±2βk ≡ 0；B_high ≡ ∓2βk ≡ 0），而镜像 c* = −c + (α−β)n̄ ≡ −(α−β)(−1) = α−β (mod p)（因 n̄ = 4k−1 ≡ −1）。五族的 (α−β) = 0, 2, −1, 3, 4 对 p = 1, 3, 3, 5, 7 均满足 p ∤ (α−β) ⟹ **c* 落在空剩余类，永不命中**。✓

（(1,1) 特例：α−β = 0 且 |α−2β| = 1 ⟹ 无双点，无需剩余类论证。）

定理 1 证毕。∎

### 3.4 推广（同型定理）

证明逐字适用于**任何有限族集 F**，只要每个 (α,β) ∈ F 满足：|α−2β| = 1，或 p = |α−2β| 为素数且 p ∤ (α−β)。例如可任意添加 (1,−4)（p=9 非素——此时双点条件为 9|…，分解为 3|k 的情形，需并入 (1,∓1) 的论证；一般复合 p 时按 p 的素因子分解处理，结论对 squarefree 部分同样成立）。

## 4. 与既有结果的关系

1. **壳间交互原理的构造性形式**：T42k 实验观察到松弛系统在 m=5..30 可行；本定理给出显式族并覆盖一切偶数 m ≥ 6。
2. **45 个素域构造的失败原因精确化**：那些构造死于 mod-p 绕回产生的三共线——而松弛系统允许共线，故同型仿射结构在松弛系统里存活。无三共线是它们与 NTIL 之间的唯一（也是本质的）差距。
3. **对 Open Problem 5.1 的含义**：囚禁提升的不可满足性必须本质地消耗 (N)；本定理把"(N) 单独承载一切"从实验观察升级为定理，等于画出了任何解析证明必须跨越的明确边界。
4. **B₂[2] 联系**：核内区间现象（P314）与剩余类障碍（引理 3）共同说明：5 族回避的语言本质上是值集的**剩余类结构**控制——为后续把 OP5.1 翻译成加法组合问题提供了解析入口。
